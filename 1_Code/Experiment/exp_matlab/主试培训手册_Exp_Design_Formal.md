## 1. 实验是什么

本实验是**自我联结匹配任务（Self-Matching Task，参照 Sui et al., 2012）**：
被试先花 60 秒记忆「几何形状 ↔ 身份标签」的配对（正方形/圆形 ↔ 自我/生人），
然后在电脑上快速判断「屏幕上同时出现的形状与标签是否符合刚才学的配对」。

实验操纵的设计参数（D4 定稿）：

- **P（额外练习试次数）**：**被试间** 4 组 = 0 / 8 / 32 / 120；**实际练习试次 = `max(4, P)`**
  ⇒ 组 1 也有 4 个兜底练习（不是「组 1 没有练习」，v2.8 更正）。
  （所有被试都先做 60 s 联结学习 ⇒ P=0 不等于「零暴露」，它只是「没有额外练习」。）
- **T（刺激呈现时长）**：**被试内** 4 档 = 33.33 / 83.33 / 149.99 / 249.98 ms（= 2/5/9/15 帧 @60 Hz）。
- **W（反应窗口）**：**被试内** 3 档 = 799.98 / 1199.9 / 1799.9 ms（= 48/72/108 帧）。
- **掩蔽（M）**：所有 12 个 (T,W) 单元**全部带** 200 ms 噪声掩蔽图（旧的「无掩蔽组」不存在）。

- **每名被试只完成 1 个组（P 条件）**，一次跑完 4 档 T × 3 档 W 的全部组合。
- **正式试次固定 576 个** = 12 个 (T,W) 单元 × 4 类刺激 × 12 次重复，分成 **3 个 block**（每块固定一个 W = 192 试次）。
- 练习试次 = `max(4, 本组的 P)`：组 1 为 **4 个兜底练习**（先走通一遍完整流程再进正式），
  组 2/3/4 为 8 / 32 / 120。`P` 仍是组参数，CSV 第 8 列组 1 写 0（练习行数与它不是同一个量）。
- 程序会自动完成全部试次与保存；主试的职责是**填对信息、盯住流程、处理异常、核对数据**。

### 1.1 单个试次的流程（主试必须理解，用于向被试解释）

```
注视点 + (500 ms)
   ↓
形状 + 标签同时呈现（T 秒 = 33/83/150/250 ms；★这一阶段就可以按键，按键会被记录）
   ↓
掩蔽图（固定 200 ms；★这一阶段按键同样被记录）
   ↓
空白屏（继续等待按键，直到「刺激出现后 W 秒」为止）
   ↓
反馈（正确 / 错误 / 过慢，500 ms）→ 下一个试次
```

> ★ **D5**：若被试在刺激还在屏幕上时就按键，**刺激会立刻结束**（实际呈现时长 = min(T, RT)），
> 掩蔽段仍固定 200 ms。因此 `stimulus_dur_actual` 可能小于名义 T —— 这是设计内行为，不是缺陷。

### 1.2 每个组的时间参数

| 组别 | 掩蔽 | P(练习) | T 档位数 | W 档位数 | 正式试次 | 单个被试预计时长 |
|---|---|---|---|---|---|---|
| 1 | 有 | 4（兜底） | 4 | 3 | 576 | ≈ 25–30 分钟 |
| 2 | 有 | 8 | 4 | 3 | 576 | ≈ 25–30 分钟 |
| 3 | 有 | 32 | 4 | 3 | 576 | ≈ 26–32 分钟 |
| 4 | 有 | 120 | 4 | 3 | 576 | ≈ 29–35 分钟 |

> 估计口径：每试次 ≈ 注视 0.5 s + 反应窗（均值 1.27 s）+ 反馈 0.5 s ≈ 2.27 s ⇒ 576 试次 ≈ 22 分钟；
> 再加 60 s 联结学习、练习（P 个试次）、3 次 block 间休息与指导语。实际常落在 25–35 分钟。

## 2. 三个必须背下来的关键口径（回答被试提问、排查异常都用得上）

1. **反应时（RT）从「刺激（形状+标签）第一次出现在屏幕上的那一帧」开始计时**，到被试按键为止。
   RT 记录在数据文件 `RT` 列，单位秒。
2. **按键自刺激出现那一刻起就被采集**：刺激呈现期、掩蔽期、掩蔽之后的空白屏，程序全程都在检测键盘
   （v4 起用 KbQueue 事件队列，按键发生的那一刻就打时间戳），取「最早的 f / j 按键」作为本次反应。
   - 被试在刺激还在时就按键 → **同样会被记录**（RT 可能只有几十毫秒），不再丢失；
   - 若直到截止时刻都没有按 f / j → 记为无反应（`Response = NA`、`Correct = NaN`、`timeout = 1`）。
3. **W = 「从刺激出现算起的最晚可反应时刻」**，即 `截止时刻 = 刺激 onset + W`。
   其中 T + 200 ms 被刺激段与掩蔽段占用，**真正留给「掩蔽之后」的按键时间 = W − T − 200 ms**。
   - 最紧的单元 = 最大 T（249.98 ms）+ 最小 W（799.98 ms）⇒ 掩蔽后只剩约 **350 ms**；
   - 最松的单元 = 最小 T + 最大 W ⇒ 约 **1350 ms**。

> 这意味着：**RT 的下限不再是 T+200 ms，而是接近 0**（刺激期内按键被如实记录），上限为 W。
> 分析时若要排除「抢按」，用 `premature_press`（注视期就按）或 `RT` 阈值统一裁定，
> **采集现场不要干预、不要提示被试重做**。

## 4. 编号规则（填错 = 数据作废，必须遵守）

被试编号不是随便取的流水号，它承担两个平衡功能，规则是**组内从 1 起连续递增、不跳号、不重复**：

| 编号的什么 | 决定什么 | 规则 |
|---|---|---|
| 奇偶 | 联结阶段学习哪条配对 | 偶 → 正方形=自我、圆形=生人；奇 → 圆形=自我、正方形=生人 |
| 编号 mod 4 | 匹配键是 f 还是 j | 余 1 或 0 → 匹配按 **f**；余 2 或 3 → 匹配按 **j** |

- 程序会自动根据编号处理这一切，主试**不需要**自己算，只需要保证编号顺序正确。
- 每组的编号互相独立：组 2 的第 1 个人和组 4 的第 1 个人都叫「1 号」，不冲突（文件名带组别）。
- **若中途某被试作废**：优先用同一编号重跑（先删旧文件，见 6.3）；若必须顺延，请在登记表备注，
  并尽量保持每组内奇偶数量均衡。

## 5. 单个被试的完整操作流程（SOP）

### 5.1 运行与填写弹窗

1. 在登记表写下：日期、组别（**1–4**）、编号（该组第几个人就是几号）、预计开始时间。
2. MATLAB 命令行输入 `Exp_Design_Formal`（或在编辑器中打开该文件后按 F5 / 运行）。
3. 弹出「实验信息」对话框，逐项填写（**全部填数字**）：

| 字段 | 填什么 | 示例 |
|---|---|---|
| 被试组别 | **只能是 1 / 2 / 3 / 4**（见第 0 节） | 2（P=8 组）|
| 被试编号 | 该组内流水号（≥1 的整数） | 3 |
| 性别[1=女, 2=男] | 1 或 2 | 2 |
| 年龄 | 实际年龄（10–100 的整数）| 21 |
| 惯用手[1=左, 2=右] | 1 或 2 | 2 |

4. 点确定后，MATLAB 命令行会回显本次信息（**组别 → 本组 P**、编号、性别、年龄、惯用手）。
   - 与登记表一致 → 按回车继续；
   - 不一致 → **直接输入 `r` 再回车**，程序会重新弹窗让你重填（不必 Ctrl+C 重开）。
5. 若五项里有非法值（例如组别填 7、编号填 0、性别填 3、年龄填 5），程序会弹出
   「填写有误，请重新填写」逐条说明，关掉后自动回到信息窗 —— **不会整场退出**。
   只有点「取消」/关窗才会终止（那一次不会产生任何数据文件）。

### 5.2 联结阶段（60 秒记忆配对）

- 程序先显示指导语，按回车进入「记忆规则 60 秒」页面。
- 屏幕上会显示类似「正方形 是 自我，圆形 是 生人」的规则（内容由编号奇偶自动决定）。
- 主试职责：
  - 确认被试看得到、看得懂中文与图形；
  - 60 秒内可以口头带被试复述规则（这正是学习阶段），但**不要替被试做判断**；
  - 若被试说没记清，在下一屏（「如果未记清楚…请咨询实验员」）出现时，主试可以再次口头讲解，
    被试按回车才进入练习/正式，**讲解不占用试次**。

### 5.3 练习阶段（4–120 试次；组 1 为 4 个兜底）

- 练习试次 = `max(4, P)`：组 1（P=0）**4 个兜底**、组 2 为 8、组 3 为 32、组 4 为 120。
  组 1 的这 4 个试次同样给正确/错误/过慢反馈，目的是让被试在正式前走通一遍完整流程。
- 练习用固定 T/W（83.33 ms / 1199.9 ms），有反馈（正确/错误/过慢），主试可借此确认被试已理解任务。
- 若被试在练习中错误率极高（如 <60%），停下来重新讲解配对规则，再继续。
- **对被试的关键话术（务必在练习前说）**：
  - 「屏幕中央先出现 +，随后上方出现形状、下方出现一个词。」
  - 「你要尽快判断：形状和词是不是和刚才学的配对一致。匹配按（程序会显示 f 或 j 键），不匹配按另一个键。」
  - 「**注意：从刺激一出现就可以按键了，不必等画面变化；但一定要先看清刺激再按，越快越准越好。**」
  - 「尽量又快又准；如果偶尔没来得及反应，不要纠结，直接做下一个。」

### 5.4 正式实验（3 个 block，每块一个反应窗口 W）

- 每个 block 开始前有提示屏，写明「第 b / 3 组」和「本组反应窗口：W 毫秒」，被试按空格开始。
  3 个 block 的 W 依次为 **799.98 / 1199.9 / 1799.9 ms**（由短到长，组内固定顺序）。
- 每个 block = 192 试次（4 档 T × 4 类刺激 × 12 次，顺序随机）。
- 每个 block 结束，屏幕会显示该 block 的正确率和平均反应时——**这是给主试看的参考，不要念给被试**。
- 之后程序提示按回车 → 出现「休息中，请按空格键继续」。
- 主试职责：利用 block 间休息让被试放松手腕、眨眼；**不要与被试讨论任务表现**；
  观察被试是否疲劳（全程约 25–35 分钟），必要时中途可多休息一次（不按空格就不继续，程序不超时）。

### 5.5 结束与收尾

- 最后屏幕显示感谢语，按回车后程序自动保存并关闭。
- 主试立刻做**数据当场核对**（第 8 节），通过后在登记表勾选「已核对」。

## 6. 异常处理（按优先级）

### 6.1 被试抢按 / 反应时机不对

- 处理：属于正常现象，不要打断。若反复出现（遗漏很多），在 block 间再次强调 5.3 的话术。
- 说明：本版程序**会如实记录刺激呈现期间按下的键**（RT 可能很短；`premature_press` 专门标记注视期抢按）。
  这类行为由分析阶段统一裁定，**采集现场不要干预、不要提示被试重做**。

### 6.2 中途按了 Esc（程序直接关屏退出，本次不保存）

- 若发生在练习或正式早期：本次作废，**让被试休息后同编号重跑**。
- 重跑前必须删除该 (组别, 编号) 已生成的两份文件（见 6.3），否则 txt 会追加旧行。
- 若发生在最后一个 block 快结束时：可让被试坚持做完后正常保存，数据仍可用（是否保留由主试+分析方决定，需记录）。

### 6.3 程序崩溃 / 断电 / 误关窗

- 文件可能不完整：先看是否生成了 CSV（完整结束才会有）。若只有半截 txt、没有 CSV → 作废重跑。
- **同编号重跑流程**：删掉数据文件夹里该 (组, 号) 的 `EXP_data_group*_*.csv` 与 `exp_group*_subject*.txt`，
  从 5.1 重新开始，登记表备注「重跑」。
- 若来不及同号重跑而顺延新号：登记表记录原因，分析时该组奇偶平衡需人工检查。

### 6.4 弹窗填错

- 回车前发现 → 输入 `r` 回车重填；不想继续就 `Ctrl+C` 终止。
- 回车后发现（例如联结阶段屏幕显示的配对方向与编号奇偶不符）→ 立即 `Ctrl+C`，同编号重跑（先删文件）。
- **填了旧组号 7** → 程序现在会告诉你「D4 只有 4 个 P 组」并让你重填；按第 0 节的 4 组表改填 1–4 即可。

### 6.5 被试中途不适 / 明确要求停止

- 尊重被试意愿立即停止，按 Esc 退出，数据作废并记录原因；不纳入有效样本。
### 6.6 跑到某一试次突然崩，报「赋值右侧的值的宽度错误」

- 症状（v4.3 及更早）：先刷出若干条「警告: 赋值时将各行添加到了表格中，但并未对表格中所有现有的变量赋值」，
  随后 `错误使用 Exp_Design_Formal / 赋值右侧的值的宽度错误。赋值需要宽度为 1 的值。`
- 这是**已知缺陷，v4.4 已修**（D78）：旧版用 `table()` 逐行累积，第一行按键 `f`（1 字符）把该列宽度锁死，
  第一个**未响应**试次要写 `NA`（2 字符）就崩。所以它**只在被试第一次超时的时候**才出现。
- 现场处理：本次作废（数据只在正常结束才写 CSV），升级到 v4.4 后同编号重跑。
- 怎么确认你跑的是新版：执行 5.1 前输入 `type Exp_Design_Formal.m | findstr "v4.4"`，应打印 v4.4 段头注。

## 7. 数据文件的保存与归档

程序会在 MATLAB 当前文件夹生成两个文件（每个被试一份）：

| 文件 | 内容 | 用途 |
|---|---|---|
| `EXP_data_group{组别}_{编号}.csv` | 全部试次（练习 + 正式）汇总表，**25 列** | **正式分析用** |
| `exp_group{组别}_subject{编号}.txt` | 逐试次追加的原始记录（同一套 25 列表头） | 过程备份/复核用 |

**建议的本轮目录结构**（示例，日期自定）：

```
2_Data/Real_Data/Round202609XX/
├── emp_data/          ← MATLAB 当前文件夹设在这里，收完数据全部在这
└── README.md          ← 记录：轮次、起止日期、各组实际人数、异常备注
```

- 4 个组的文件名规则完全相同（`EXP_data_group2_3.csv`），靠 CSV 里的 `groupID` 列区分组别。
- 一个被试的完整会话约产生：CSV 约 **576 + max(4, P)** 行（组 1 = 580 行）、txt 同量行。
- **单位提醒**：`T`、`W`、`RT`、`stimulus_*_actual` 一律**秒**（T=0.08333 ⇔ 83.33 ms）；
  v4.1 起以 `%.6f` 写出，四档 T（0.033333 / 0.083333 / 0.14999 / 0.24998）各自可辨。

### 7.x 高刷新率屏的症状（v2.4 新增，2026-10-18）

在 165 Hz 的屏上跑一场，事后用 `1_Code/Experiment/exp_Check/check_stage1_acceptance.py` 检查会看到：

- 反推 FlipIntv ≈ **6.06 ms**（165 Hz）而不是 16.67 ms；
- `stimulus_frames` 变成 **5 / 14 / 25 / 41**（按毫秒取整），不再是 2 / 5 / 9 / 15；
- 一部分试次的 `stimulus_dur_actual − T` 超出 +1 帧（本机实测 44/576 行多停 2–25 帧 = 12–152 ms）。

**这不是程序坏了，是这块屏不在设计口径里**。检查器会自动打印「证据降级」，此时
这份数据只能证明「程序能跑通、能写出 25 列」，**不能**用来回填技术验证记录 §6 的表。
### 7.y 「个别试次刺激一闪就没了、被记为漏答」（v2.5 新增，2026-10-18）

跑在 **59–60 Hz 的实验室屏**上也可能看到：576 行里有 **5 行左右** stimulus_dur_actual 只有
0–1 帧（6–14 ms）、premature_press = 1、Response = NA、	imeout = 1。

- **成因**（v4.5 及更早）：注视期抢按是在 kqCountPresses() 处读的，而它离真正 onset 还隔着一次
  Screen('Flip') 的 vsync 等待；这条缝隙里按下的第二个键不会被抢按计数看到，却被刺激期的
  kqFirstPressUntil 立刻取走 ⇒ 刺激在 0–1 帧内被敲掉，试次变成漏答（实测 5/576 = 0.87%）。
- **v4.6 已修**：kqFirstPressUntil(deadline, tFloor) 只接受 `tFloor` < 时间戳 ≤ deadline 的按键，
  四个调用点（练习/正式 × 刺激期/反应窗）都传 stimulusFlipTime。
- **怎么确认跑的是 v4.9**：`type Exp_Design_Formal.m | findstr "v4.9"`，应打印 ★★ v4.9 本次修正 段头注。
- **已生成的数据怎么办**：这 5 行**不改判据去迁就**；若在 v4.5 上跑过技术被试，用 v4.6 复跑一场再回填 §6。

### 7.z 「块首指导语一闪而过、没按空格就进了正式实验」（v2.6 新增，2026-10-18）

- **现象**：每组开始前那张「本组反应窗口：800 毫秒 / 准备好后按空格键开始本组」的指导语只闪一下，被试还没读完就进了第一个试次；被试因此不知道本组窗口是多少，那一个试次通常白丢。
- **成因**（v4.6 及更早）：相邻两处「按空格继续」都用 `KbCheck` 忙等「此刻空格是否按着」，没有「按下沿」的概念。上一屏（练习结束休息屏）确认用的空格若还按着，下一屏的循环立刻被穿透——两屏之间只隔一次 `Screen('Flip')` 与几十毫秒建表时间，**按住 50 ms 就够**。
- **v4.7 已修**：新增 `waitForSpaceRelease()`，8 处空格等待之前都先等一次「所有键都松开」（最多等 5 s，防键卡死）再等新的按下。
- **怎么确认跑的是 v4.9**：`type Exp_Design_Formal.m | findstr "v4.9"`，应打印 ★★ v4.9 本次修正 段头注。
- **已生成的数据怎么办**：v4.6 及更早的场次里，若某组的第一个试次是 `timeout` 或 `premature_press=1`，可能就是这条造成的。不用作废整场，但在分析里备注「该组首个试次的反应窗口可能未被读到」；v4.7 起不再出现。

### 7.w 把整个文件夹拷到实验室机（v2.7 新增，D92）

- **只拷 `exp_matlab` 这一个文件夹**（含 `test\`、10 张掩蔽 PNG、`setup_paths.m`）到任意位置即可，不必拷整个仓库。
- **程序资源跟着程序目录走**（v4.8 起）：10 张掩蔽纹理按 `fileparts(mfilename('fullpath'))` 解析，
  所以 MATLAB 的当前文件夹**不需要**是程序目录；数据仍然写在**当前文件夹**（照本文第 7 节把当前文件夹设成本轮数据文件夹）。
- 启动会打印两行自检，**每次开机扫一眼**：
  `[路径] 程序目录（掩蔽纹理） = …` 与 `[路径] 输出目录（CSV/txt） = …`。
  若报「掩蔽纹理缺失（程序目录 = …）：xxx.png」，说明 PNG 没拷全（缺哪张会一次列全），当场补上再跑。
- 数据必须落在你设的那个数据文件夹里；如果打印的「输出目录」不是它，说明当前文件夹设错了，**当场停下改好再重跑**。

## 8. 数据当场核对清单（每名被试结束后 5 分钟内完成）

打开刚生成的 CSV（用 Excel 或 MATLAB），逐项检查：

- [ ] 表头 **25 列**齐全：`groupID subjectID gender age handedness stage trialID P T W Shape Label CorrectKey Response RT Correct block premature_press timeout responded_by_deadline stimulus_onset_actual stimulus_offset_actual mask_onset_actual stimulus_dur_actual stimulus_frames`
- [ ] `stage = "formal"` 的行数 = **576**；练习行数 = `max(4, P)`（组 1 应为 **4** 行练习，不是 0）
- [ ] `block` 列：练习行 = 0；正式行 ∈ {1, 2, 3}，每块 **192** 行
- [ ] 每行 `groupID` 与登记表一致（**只能是 1–4**）；`P` 列 = 该组的 0 / 8 / 32 / 120
- [ ] `T` 列只出现四档（0.033333 / 0.083333 / 0.14999 / 0.24998），**四档都能区分开**
      ——若看到四档塌成 2–3 个值，说明打印精度退化（v4.1 已修，务必回报）
- [ ] `W` 列只出现三档（0.79998 / 1.1999 / 1.7999），且每个 block 内 W 恒定
- [ ] 抽查 `RT`：绝大多数落在 (0, W] 内；**出现几十毫秒的短 RT 属正常现象**（刺激呈现期按键已被记录）
- [ ] 无反应行：`Response = NA`、`Correct = NaN`、`timeout = 1`、`responded_by_deadline = 0`
- [ ] 粗算遗漏率：若某被试遗漏率 >50%，记录在登记表，是否剔除由分析阶段统一裁定
- [ ] 登记表勾选：日期 / 主试签名 / 已核对
