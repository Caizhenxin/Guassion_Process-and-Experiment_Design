读法与限定
================================================================================================================
  1. 这是 **Cramér–Rao 下界**：真实 MLE 的精度只会更差，不是更好。
  2. 组层 SE ≈ 单人 SE / √n_subj（固定 n_subj 下，比较单人 SE 即等价）。
  3. 信息量用 OPG（逐试次得分外积）而非 Hessian，理由见模块 docstring：
     二阶差分的噪声 ~1e−13 会淹没小曲率参数（δa 的 a 跨度只有 0.13），
     导致 pinv 输出 1e113 量级的垃圾。OPG 噪声平方进入，实测 cond ~1e5。
  4. ⚠️ 当前生成器是**恒定漂移（M-T3）**；因决策 D5，严格应换 M-T1
     （漂移在 t = T 处从 d_stim 阶跃到 d_mask）。M-T1 列为 Stage 4 待办。
