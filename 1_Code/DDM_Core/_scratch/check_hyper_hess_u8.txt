解析超参数 Hessian（Louis 恒等式）的校验
========================================================================

A 组：闭式高斯层级（内层拉普拉斯精确 ⇒ 解析式必须与闭式差分吻合）
  ✅ A0 闭式基准自洽：subject_map_laplace 的模式 = (y + mu/sigma²)/(1+1/sigma²)
       max|Δmode| = 1.022e-08；C_00 = 0.26470588 vs 闭式 0.26470588
  ✅ A1 解析 Hessian == 闭式真边际的差分 Hessian（相对化到 max|H|）
       max 相对差 = 1.881e-08（最差元素 H[1,3]）；max|H_true| = 3.576403；闭式差分自身的步长误差 = 2.111e-07
  ✅ A2 有限差分版（拉普拉斯边际）在此也与闭式真边际一致，残差随步长单调下降（⇒ 它是**离散/优化残差**，不是定义差异）
       step = HYPER_STEP = 0.05: max 相对差 = 3.132e-04（最差 H[3,3]）；step = 0.005: 3.168e-05 ⇒ 步长缩 10× 让残差降 10×，实测幂律指数 ≈ 0.99（不是理想的 2 —— 与优化器收敛噪声同量级）
  ✅ A3 解析版 vs 有限差分版（默认步长）：精确情形下应当同量
       max 相对差 = 3.132e-04（最差元素 H[3,3]）；其中大部分来自上面那条步长截断
  ✅ A4 代价：解析版 0 次众数搜索，差分版 4n(n+1)/2·N 次
       解析 n_evals = 0（墙钟 0.31 ms）vs 差分 n_evals = 40（墙钟 0.173s，N = 4）
  ✅ A5 判据有牙齿：放大 C 与平移 x* 都必须改变解析 Hessian
       放大 C ×1.6 ⇒ max|ΔH|/max|H| = 2.756e+00；x* + 0.30 ⇒ 9.248e-01
  ✅ A6 形状守卫：modes/covs 不合法必须 ValueError（三条各报一次）
       触发：modes 维数不符、covs 个数不符、cov 形状不符

B 组：真实 DDM（解析版算真边际、差分版算拉普拉斯边际 ⇒ 允许有差，只报告）
      构造：N = 2，48 试次/人，被试内参数 d_ref/beta_T
       · EM 拟合 8 轮、25.9s；mu = [-1.1983 -0.2267]、sigma = [0.2171 0.272 ]、n_flipped = 0
  ✅ B1 解析版的 A = −∂²log post 正定（C 为合法协方差时应当如此）
       min eig = 9.013e-02、非正 0 个；后验 SD = mu_d_ref 0.9764、mu_beta_T 0.6971、ls_d_ref 3.1912、ls_beta_T 0.9117
       · 差分 step = 0.05  : min eig = -1.3824e-01、非正 1 个、墙钟 96.4s；SD = 58.51、1.67、196.4、0.9182
       · 差分 step = 0.02  : min eig = -1.3466e-01、非正 1 个、墙钟 94.5s；SD = 58.47、1.682、196.4、0.9332
       · 差分 step = 0.005 : min eig = -1.2233e-01、非正 1 个、墙钟 87.6s；SD = 58.3、1.535、196.3、1.31
  ✅ B2 差分版若不正定，其失真必须被**如实报告**（n_flipped = 该 Hessian 非正特征值个数，不得静默抬地板后照常抽样）
       `hyper_draws(method='fd', step=0.05)` 报 n_flipped = 1；同一步长 Hessian 的非正特征值 1 个（⇒ 失真被暴露，调用方可拒绝该后验）
       · B3 跳过：没有任何差分步长给出正定 Hessian ⇒ 两版 SD 在该点**无法比较**；解析版是唯一可用的后验，SD = mu_d_ref 0.9764、mu_beta_T 0.6971、ls_d_ref 3.191、ls_beta_T 0.9117
       · ❗实测缺陷（记录，不是判据）：差分版在 step = 0.05 处**不正定** —— min eig = -1.3824e-01、非正 1 个，而 `hyper_draws` 会把负特征值抬到地板后照常抽样 ⇒ 该配置下差分后验 SD 不可用（见上面 B2：**但它是被如实报告的**）
       · 解析版同点 min eig = +9.0126e-02（正定）⇒ 解析版不只是快：它**不可能**因为差分噪声丢掉正定性；代价是它算的是真边际的 Hessian，内层拉普拉斯误差必须如实报告（见上面那条逐元素差）
  ✅ B5 代价：解析版 0 次搜索 vs 差分版 npair·N 次温启动众数搜索
       解析：n_evals = 0、墙钟 0.3 ms；差分（step = 0.05）：n_evals = 40 × 2 人 = 80 次众数搜索、墙钟 96.4s ⇒ 加速 354647×
       · 正式规模换算：M-T3（K=7, n=14）差分需 420·N 次搜索；M-T1（K=8, n=16, ρ 自由）需 544·N 次搜索；解析版两项都是 **0**
