⚠️ **两个区间的区别是关键**：
   · 「条件区间」把观测到的经验分布**当成总体** ⇒ 只反映重抽噪声，**假性精确**；
   · 「Dirichlet 区间」先对观测抽 Dirichlet(1) 权重（后验 over 分布）再重抽 ⇒
     把「LRT 的**均值本身**也不确定」传了进去。**引用效力时用这一列。**
   例：ρ=1.25 的逐被试 LRT 均值 2.388，其 SE = 2.770/√30 = 0.506 ⇒ 「均值 − 55.8/30」距 0 只有 +1.0 个 SE，
       故 n=40 的效力区间必须很宽（见上表），不能报成单点。
⚠️ bootstrap 不覆盖 M-T2（斜坡），也不覆盖真值族（只跑了 exp/lin 少数的 ρ 档）。

结论（写进 README §9 第 4 项）
====================================================================================================
① 标定行（ρ=1，真值就是 M-T3）：逐被试 LRT 规则 3%、BIC 规则 3%、组层 ΣLRT 18.90 vs 43.77 ⇒ **无假阳性** ✅
② 逐被试规则下 ρ=0/0.5/0.75 的 M-T1 命中率：LRT 规则 97%/40%/17%，BIC 规则 87%/20%/3%
   ⇒ **LRT 规则系统性偏乐观**（ΔBIC 罚 6.36）；论文若报检验力必须写明规则
③ 组层聚合（n=30）：ρ=0.75 逐被试只有 17%，但 ΣLRT 57.50 vs 43.77 → 拒绝 M-T3 ✅；
   ρ=1.25：ΣLRT 71.63 vs 43.77 → 拒绝 M-T3 ✅（逐被试 20%）；ρ=1.5：ΣLRT 210.91 vs 43.77 → 拒绝 M-T3 ✅（逐被试 33%）
④ 投影到 n=40/组（Dirichlet 区间，含分布不确定性）：ρ=0/0.5/0.75 效力 100%/100%/86%（下界 100%/100%/0%），ρ=1.0 3%
   ⚠️ **ρ>1 是关键不确定项**：ρ=1.25 效力 95%（区间 [0%, 100%]，逐被试 20%）、ρ=1.5 效力 100%（区间 [100%, 100%]，逐被试 33%）
   ⇒ 观测样本量 n=30/档。n<30 时 ρ>1 的**中心值**不可当结论（分布均值没被钉住）；
     n≥30 时中心值可报，但**必须同时给 Dirichlet 区间**——它通常仍是 [0%, 100%]。
     ⇒ 论文若报 ρ>1 的效力，写法是「中心值 X%（区间 [0%, 100%]，n=30/档 模拟）」，不是单点。
⑤ ρ̂ 组层偏差：ρ=0.5 时 0.5703（真值 0.50，偏差 +0.0703）；ρ=1.0 时 1.0635
⑥ ❌ 矩阵只有 2 个模型：M-T2（斜坡）缺失，见 §9 第 16 项
