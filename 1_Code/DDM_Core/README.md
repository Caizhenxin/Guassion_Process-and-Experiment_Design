## 2. 模型约定

```
dX_t = v·dt + dB_t,     X_0 = z,     0 < z < a        （σ = 1 固定，设定尺度）
观测 RT = 首次通过时间 τ + 非决策时间 t0
反应编码：上边界(τ→a) = Match ｜ 下边界(τ→0) = Nonmatch
```
* `z` 是**绝对**起点；中心起点 = `a/2`（研究计划第一版约定）。
* 抽样得到的是 `τ`（首次通过时间），`t0` 由调用方加。

### ⚠️ 两个必须记住的口径陷阱

1. **`sim_utils.simulate_trials` 的 z 是"比例优先"**：它把 `0 < z ≤ 1` 解释为**边界比例**，
   否则解释为绝对起点。本模块一律用**绝对起点**，所以两边互验时必须传 `z/a`。
   （开发期在这里踩过一次，导致 `v=+0.5` 与 `v=−0.5` 的路径模拟结果不对称。）
2. **`wfpt_cdf_grid(v, a, z, ...)` 与 `flux(d, v, a, ...)` 的参数含义不同**：前者收"起点"，
   内部做 `z → a−z` 的映射；后者收"到目标边界的**距离**"。在抽样里手上已经是距离，
   混用会让上边界用错距离。（开发期第二次踩坑。）

## 4. ⚠️ 重要副产品：路径模拟器本身有约 3% 的 CDF 偏差

上表第二行说明：**`sim_utils.simulate_trials` 在 dt = 0.002（项目默认）下，其经验 CDF 与真实 DDM 分布的最大偏差约 0.031**。

这一点值得单独记录，因为：

* 论文配置 C 的**全部**参数恢复、PPC、模型比较数字都由该模拟器产生；
* Euler 离散化在固定边界处需要**边界修正**（约 `0.583·σ·√dt` 量级）；当前实现未做；
* 偏差随 dt 缩小（0.052 → 0.016）→ 可归因于离散化，而非逻辑错误。

**建议**（Stage 3 起执行）：
1. **下游一律改用本模块的 WFPT 抽样**（更快且无步长偏差）；
2. 若仍需路径模拟，**加边界修正**或把 dt 降到 ≤ 0.0005；
3. 在论文方法部分说明模拟器的这一已知偏差（这是一条诚实且加分的方法学交代）。

### 6.1 映射结构

```
d(P,T) = d_ref + β_P·[f_P(P)−f_P(P_ref)] + β_T·dqt
         + I_self·{ β_S + β_SP·[f_P(…)] + β_ST·dqt }
a(W)   = a_ref + δa·dqW                        (W1) ｜ a_ref (W0)
v      = +d（Match 试次，上边界） ｜ −d（Nonmatch 试次，下边界）
z      = z_ratio·a

形状函数由 MappingParams.shape_model 选择：
  "exp"（默认）  dqt = Q_T(T,τ_T) − Q_T(T_ref,τ_T)      ← 带自由时标
                 dqW = Q_T(W,τ_a) − Q_T(W_ref,τ_a)
  "lin"          dqt = T − T_ref                        ← 无时标，β_T 单位 = drift/秒
                 dqW = W − W_ref                        ← δa 单位 = a/秒
```

**为什么要 `"lin"`**：`τ_T` / `τ_a` 在本设计上不可识别（D18/D19，见 §8）。
`shape_model="lin"` 时 `tau_T` / `tau_a` 被忽略，自由参数集改用 `WITHIN_FREE_LIN`（7 个）：
`["d_ref","beta_T","beta_S","beta_ST","a_ref","delta_a","t0"]`。

### 6.2 ⚠️ 参考点锚定（`d_ref` / `a_ref`）不是风格问题，是识别性问题

初版把参数写成 `d0`（T→0 处的漂移）与 `A_min`（W→0 处的边界）。但设计里
T ∈ [33, 250] ms、W ∈ [800, 1800] ms，**数据从不接近 T=0 或 W=0** →
这两个"截距"是**纯外推**，MLE 直接把它们推到参数边界，并带偏其余参数。

实测对比（同一设计、同一真值结构，只改参数化）：

| 参数 | 外推参数化（初版） | **参考点锚定（现行）** |
|---|---|---|
| 漂移截距 | `d0` 估 0.05 vs 真值 0.80（撞下界） | `d_ref` bias −0.047、RMSE **0.059** |
| 边界截距 | `A_min` 估 0.30 vs 真值 0.90（撞下界） | `a_ref` bias −0.020、RMSE **0.041** |
| t0 | bias +0.016 | bias +0.004、RMSE **0.007** |
| 自我主效应 | `beta_S` RMSE 1.84 | `beta_S` bias −0.025、RMSE **0.108** |

## 7. Stage 3b：跨被试 P 参数恢复

| 文件 | 作用 |
|---|---|
| `recover_group.py` | 两阶段恢复：逐被试拟合 → 组间非线性回归（回收 β_P / τ_P / β_SP），含 **oracle** 对照 |

### 7.1 两阶段方法的正确做法（踩过的坑）

⚠️ **必须把 P 的组间效应移进被试层参数，并令每名被试的 `P_ref` = 他自己的 P。**

初版让 `P_ref` 保持公共参考点，于是被试内似然要用 `β_P/τ_P` 去算 P 偏移——
但这两个参数**不在被试内自由参数里**，会用起点的错值（0.60/60 vs 真值 0.35/30）。
估计出的 `d_ref_s` 吸收了这份不匹配，组间回归必然错：

| 版本 | β_P 估计 | 真值 | Bias |
|---|---|---|---|
| 错误版（`P_ref` = 公共参考点） | **−0.476** | +0.35 | −0.826（**反号**） |
| **修正版（`P_ref` = 被试自己的 P）** | **0.325** | +0.35 | **−0.025** |

**判据**：错误版的 **oracle 也错**——这说明问题不在估计噪声，而在方法本身。
oracle 只有在被试层参数**确实携带了 P 效应**时才有诊断意义。

### 7.3 ❗ P 水平设计的纯识别力（`oracle_power.py`，oracle = 上界）

| P 水平设置 | 水平数 | n/组 | β_P 相对 RMSE | **τ_P 相对 RMSE** | 判定 |
|---|---|---|---|---|---|
| 当前推荐 (0, 8, 32, 120) | 4 | 6 | 0.38 | **1.67** | ❌ 均不可识别 |
| 当前推荐 | 4 | 12 | 0.24 | 1.07 | 🟡 仅 β_P |
| 当前推荐 | 4 | 20 | 0.15 | 0.51 | 🟡 仅 β_P |
| **当前推荐** | **4** | **30** | 0.12 | **0.40** | ✅ 两者可识别 |
| 当前推荐 | 4 | 50 | 0.09 | 0.25 | ✅ |
| P 加密（7 水平：0,4,8,16,32,64,120） | 7 | 20 | 0.13 | 0.44 | ✅ |
| **P 加宽（5 水平：0,8,32,120,240）** | **5** | **20** | 0.11 | **0.36** | ✅ **最省被试** |
| 文献常见 3 水平（0, 32, 120） | 3 | 20 | 0.16 | 0.49 | ✅ 几乎不损失 |
| 文献常见 3 水平 | 3 | 30 | 0.13 | 0.34 | ✅ |

**三条可执行结论**：

1. **人数是主杠杆，不是水平数**：n 从 6 → 30，`τ_P` 相对 RMSE 从 **1.67 → 0.40**（4 倍）；
   而水平数从 4 → 7 只从 1.67 → 1.33（20%）。
2. **P=8 那一档几乎不贡献信息**：3 水平（0/32/120）在 n=20 时 τ_P 相对 RMSE 0.49，
   与 4 水平（0/8/32/120）的 0.51 基本持平 → **可以省掉一档，减少总被试量**。
3. **加宽到 P=240 性价比高**：5 水平（0/8/32/120/240）在 n=20 就把 τ_P 压到 0.36，
   优于 7 水平的 0.44。

⚠️ **这些是 oracle 上界**：真实分析还要叠加被试内估计噪声
（`d_ref` 的 SE 均值 0.092 vs 被试间 SD 0.15，二者量级相当）→
有效 SD 变为 `√(0.15² + 0.092²) = 0.176`，约**再差 17%**。
所以「n=30/组」应视为**下限**而非充分条件。

## 8. Stage 4：识别性诊断与设计处方（2026-10-14）

完整结论见 `5_Reference/08_工作流/Stage4_识别性结论与设计处方.md`；决策见主计划 D16–D21。

### 8.1 走错的三条路（都被实测否证）

| 方法 | 为什么放弃 |
|---|---|
| 模拟→拟合→看恢复 | 单个设计数十分钟，无法做设计网格 |
| Hessian 数值二阶导 + `pinv` | `rel_step=1e-4` 下曲率信号 `C·h²≈1e-8` 沉到浮点噪声 `1.3e-13` 之下，被伪逆放大成 **1e+113 级相关系数** |
| OPG（BHHH）边缘 SE | `delta_a` 方向**乐观约 10 倍**；信息矩阵 `λ_min = −118.2` ⇒ **真值处非正定（是鞍点）** |

**最终判据**：条件曲率（其余参数钉在真值）+ 剖面 2 单位区间。直接用网格评估，不依赖优化器。

### 8.2 两个工具缺陷（都曾污染数字）

- **`profile_se` 区间参考点错误**：从真值格点出发找 ΔlogL 穿越；真值远离剖面极大值时
  真值格点本身已低于阈值 → 首轮即判"已穿越" → 返回 `lo == hi` 的**零宽区间**（伪精确）。已改为从 argmax 出发（D17）。
- **多起点过窄**：见 §6.3 警告框（D16）。
- **`~om` 是按位取反，不是逻辑非**（测量脚本的坑，**库本身没有此问题**）：
  `simulate_subject` 返回的 `omission` 是 **int** 数组，`~om` 得到 `[−1,−2,…]`
  而不是布尔掩码，于是 `side[~om]` 变成 `side[[-1,-2,…]]`（**只取末尾几个元素**），
  正确率会虚高成 `1.000`、平均 RT 变成末尾两试次的均值。**必须写 `om == 0`。**
  → 凡是要按"已响应试次"取子集，一律用显式比较，不要用 `~`。

### 8.4 决定性发现：错的是 `tau_a`，不是 `tau_T`

- **`tau_a` 被系统性推到上界**：联合 MLE 在 **D4 与 low6 两个独立设计**里都给出
  `tau_a = 4.9998 ≈ 5.0`（误差 **+4.30**）。含义：`tau_a→∞ ⇒ Q_T(W,τ_a)→0`，
  等价于**数据偏好"边界根本不随 W 变化"**。
- **钉住 `tau_a` 立刻救活 `delta_a`**：D4 下 `x_hat = 0.5500`、**偏差 0.0000**、CI `[−0.195,+1.296]`。

  （1.7167 vs 0.55），low6 固定后 `beta_T` 从**含真值退化为有偏**（−1.2000）。
- `tau_T` 自由估计时 `x_hat`：D4 = **0.0050**、low6 = **0.1728**（**方向相反**）⇒ 纯噪声。

**根源**：`Q_T` 是**饱和**函数。真值 `τ_T = 0.08 s` 时 T=150/250 ms 已给出 Q=0.847/0.956
⇒ 高两个 T 水平几乎不携带 `τ_T` 信息；`τ_T→0` 时 `dqt→0`，整条 T 通路消失。
`a` 同理：`a` 在 W∈[0.8,1.8] s 上只变 **6.7%**（1.924→2.057），因为 `τ_a = 0.7 s` 在 W=0.8 已近饱和。

**处方**：**去掉时标参数**，而不是钉住它 —— 见 §6.1 的 `shape_model="lin"`。

### 8.9 M-T1（两阶段时变漂移）已实现并验证（2026-10-14）

决策 D5（按键即结束试次）意味着漂移在 `t = T` 处从 `d_stim` 阶跃到 `d_mask`，
恒定漂移的 M-T3 不再成立。已在 `wfpt.py` 加入四个函数：

| 函数 | 内容 |
|---|---|
| `green(x, T, v, a, z)` | killed 转移密度 `G(x,T;z)`，含 Girsanov 因子 `e^{v(x−z) − v²T/2}` |
| `density_step(t, v1, v2, a, z, T)` | `f_up/f_lo`；`t ≤ T` 用单阶段 `flux`，`t > T` 用 `∫G·flux` |
| `survival_step(v1, v2, a, z, T, t)` | 解析存活，用于 deadline 未响应项（**无时间积分**） |
| `p_upper_step(v1, v2, a, z, T)` | 最终到上边界的概率，闭式卷积 |

`validate_step.py`（`_scratch/validate_step_u8.txt`，57.6 s）**5/5 通过**：

| 检验 | 内容 | 结果 |
|---|---|---|
| W1 | `v1 == v2` 时逐点退化为单阶段公式 | ✅ 相对误差 ≤ 9.6e-10 |
| W2 | `T→0` 退化为单阶段 `v2` | ✅ 见下 |
| W3 ★ | `∫G dx == survival_series`（**两条独立推导的交叉点**） | ✅ n_x=161 时 2.0e-5–3.6e-5；n_x=801 时 8.0e-7–1.4e-6 |
| W4/W5 | 质量守恒 `∫f_up == p_upper_step`；密度积分 ↔ 解析存活 | ✅ `∫f_up` 与 `p_upper` 六位小数一致；`max\|ΔS\| ≤ 5.5e-5` |
| W7 | 细步长 Euler 路径模拟独立复核（dt=2e-4, n=6000） | ✅ 遗漏概率差 ≤ 0.008 |

W3 是**决定性**检验：`green` 由 Girsanov 推出，`survival_series` 由 killed
半群的解析级数推出，两者对 `x` 积分必须相等——它们独立成立且数值吻合，
才排除"两边犯同一个错"的可能。W7 再用第三种方法（路径模拟）封口。

#### ❗ 我自己的诊断代码里找到并修掉的三个缺陷

三个都**先被误读成公式错误**，记下来因为误读方式会重演：

1. **"恒定的 0.0155 质量亏损"其实是时间网格截尾。** W4 原本把
   `∫_0^{3s} f_up dt` 与**未截尾**的 `p_upper_step` 相比，两者本来不可比。
   `a = 2, z = 1, v = 0` 时 3 s 处的解析存活是 `(4/π)e^{−π²·3/8} = 0.0315`，
   其一半正是 **0.0157** —— 与"亏损"逐位吻合。修法：`t_max` 提到 15 s
   （尾部 ~9e-9），并把截尾质量**单独列一列**，防止再次误读。
2. **`s ∈ [1e-4, 1e-3]` 的掩蔽后格点落在正弦级数的灾难性相消区**，密度本应
   ≈0 而截断级数给出 O(1) 假值，被梯形权重积进去造成**与参数无关的质量亏损**。
   修法：`_S_FLOOR = 1e-3`，`t ≤ T + 1 ms` 一律用阶段 1 公式（代价 O(1 ms)）。
3. **`T ≤ _T_FLOOR` 的单点 δ 把起点量化到格点**，起点 `z` 偏离最近格点
   O(dx) 会让密度在**错误的起点**上求值（实测 `a=1.5, z=0.4` 偏 4e-3）。
   修法：改成线性（cloud-in-cell）分配，同时精确保持 `∫G dx = 1` 与
   `∫x·G dx = z`，误差降到 O(dx²)。

#### 两条方法论教训（写给以后的自己）

- **误差量与参数无关而"恒定"，是网格/离散化伪影的特征，不是公式错误的特征。**
  公式错误会随参数缩放；0.0157 在 7 个不同参数组合里几乎不变，当时就该
  直接怀疑积分网格而不是 Green 因子。
- **粗网格上的逐点比较抓不到窄区间伪影，质量守恒（积分）检验抓到了。**
  W1 在 `t ∈ [0.01, 2]` 的 60 个点上完全通过，却没有一个点落进
  `[1e-4, 1e-3]` 那个坏区间；W4 的积分立刻暴露了它。
- 因此 W2 的判据现在是**两条一起**：绝对误差 `< 1e-5`（n_x=801）**且**
  `n_x` 161→801（dx 缩小 5×）时误差至少降 5×。只卡绝对阈值无法区分
  O(dx²) 离散化与公式错误。实测 `a=1.5, z=0.4` 下降 **24.9×**（理论 25×），
  正是 O(dx²) 的签名。

### 8.10 M-T1 敏感性实测：ρ 偏离 1 是**一阶效应**（2026-10-14）

`_scratch/check_twophase.py` → `_scratch/check_twophase_u8.txt`（EXIT=0）。

对 D4 的 4×3 个 T×W 单元用解析机器算三个可观测行为量，比较 `d_mask = ρ·d_stim`：
`acc = P(上边界 ∧ 未遗漏)`、`om = P(τ > deadline)`、`RT = t0 + E[τ | τ < deadline]`。

**自检**：ρ=1.0 时两阶段机器在全部 24 个单元（含自我）**逐位复现**单阶段 M-T3
结果（acc 与 om 差 < 1e-6）✅ —— 这既是一个敏感性点，也是整套两阶段机器的
**行为量级封口**，与 W1 的密度级检验相互独立。

相对 M-T3（ρ=1）的最大绝对偏差：

| ρ | max\|Δacc\| | max\|Δom\| | max\|ΔRT\| | acc 相对 |
|---|---|---|---|---|
| 0.0 | **0.2742** | 0.0804 | 43.1 ms | **34.3%** |
| 0.5 | 0.1329 | 0.0522 | 25.3 ms | 16.6% |
| 1.5 | 0.1127 | 0.0594 | 37.8 ms | 14.1% |
| 2.0 | 0.2016 | 0.1200 | 85.8 ms | 25.2% |

四条结论：

1. **RT 几乎不敏感**（最大 43 ms），**正确率与遗漏率高度敏感**（10–34%）。
   ⇒ "M-T1 要不要紧"**只能由选择/遗漏数据回答，不能由 RT 回答**。我此前只看 RT
   左尾（§8.8），这正是错误的来源。
2. **M-T1 是一阶效应**：ρ=0.5（掩蔽把漂移砍半）就足以让正确率改变 **13 个百分点**。
   ⇒ Stage 3/4 的数值**不能不加复核地直接用于定稿**（§9 第 7 项据此改写）。
3. **但 ρ ≈ 0 与已观察到的数据模式不符**：ρ=0 时最难单元（T=33 ms, W=800 ms）
   正确率仅 **0.233**、遗漏率 **0.55**；ρ=1 时同单元为 0.374 / 0.511。
   掩蔽若真截断累积，被试在长 W 条件下不可能维持远高于随机的正确率。
4. ⇒ **这反而使论文更强**：ρ（掩蔽后漂移残留比例）本身是**可从数据估计**的，
   "长 T + 长 W 单元的正确率"就是它的探针。**"ρ ≈ 1（掩蔽不截断证据累积）"
   不再是一个建模假设，而是一个由 H2/H3 检验的实证命题。**

⚠️ **口径提醒**：本表 `acc` 是**所有试次**口径（含遗漏）；`design_grid` 报告的是
**条件正确率（仅反应试次）且含自我试次**。两者绝对水平不可直接对齐，

### 8.12 ❗ 病态拟合判定的第一版是**错的**：贴界 ≠ 拟合失败（2026-10-14）

§8.11 的结论 4 要求「一个明确的病态拟合处置规则」。第一版规则实现了，跑完冒烟测试
（`recover_group.py 2 lin`）却暴露出**规则本身**的缺陷——而且这次是**我的推理**错，
不是数值代码错。

**第一版规则（布尔）**：`SE ≤ 0 / 非有限 / < 1e-4×max(|x|,1)`，**或参数距边界
< 0.1% 界宽** ⇒ 判「病态」，先按 2 → 8 → 32 提高起点数重试，仍病态则剔除。

**它抓到了什么**：8 名被试里剔除 1 名，理由

```
P=0/subj0: d_ref=0.2 贴下界 0.2
```

**问题**：为验证它，我写了 `_scratch/check_bounds.py`，用与 `recover_group.py`
**完全相同的种子与抽样顺序**（`seed = BASE_SEED + int(P)*1000 + s`）重放被试层真值，
逐参数检查真值是否落在 `PARAM_BOUNDS` 内。结果是决定性的：

```
  P  subj        参数         真值        界      余量%
  0     0     d_ref     0.2000     0.20    0.00%  ← 下界
```

**该被试的真值恰好就是 0.2000 = 下界本身。** 于是拟合落在 0.2000 **不是失败，是答对了**；
把它剔除等于从 P=0 组里删掉一个合法的低漂移锚点，**反而引入偏差**。

根因在 `simulate.py:39`：

```python
kw[k] = float(np.clip(getattr(p_group, k) + rng.normal(0.0, s), lo, hi))
```

`np.clip` 把抽到箱体外的真值**压在界上**，于是在边界产生一个概率堆。
（注释原文写「截断到物理边界内」——那是 truncation 的语义，而 `np.clip` 是 clipping，
两者不是一回事。）副作用：任何落在界上的拟合都会看起来像算法失败。

**`d_ref` 的贴界风险是可量化的**（`_scratch/check_bounds_u8.txt`，40 人）：

| P | 真值均值 | 真值 SD | 最小 | z = (均值 − 下界)/SD | 预计越界 |
|---|---|---|---|---|---|
| 0 | 0.4902 | 0.1473 | **0.2000** | **1.97** | **2.4%** |
| 8 | 0.5719 | 0.1402 | 0.3637 | 2.65 | 0.4% |
| 32 | 0.6964 | 0.0901 | 0.5202 | 5.51 | 0.0% |
| 120 | 0.7878 | 0.1084 | 0.6163 | 5.42 | 0.0% |

P=0 是唯一 z<2 的组——它的下尾被下界 0.20 切到。

**修正后的规则（三值判决，`fit_diagnostics.pathology()`）**：

| 判决 | 判据 | 处置 |
|---|---|---|
| `degenerate` | `SE` 非有限/≤0/`< 1e-4×max(\|x\|,1)`，或拟合失败 | 起点数 **2 → 8 → 32** 重试；仍退化 ⇒ **剔除** |
| `bound` | 距边界 < 0.1% 界宽，**但 SE 健康** | **保留，只报告**（真值可能就在界上） |
| `ok` | 两者皆无 | —— |

判决取最严重者。`is_excludable(verdict)` 只对 `degenerate` 返回 `True`。
两套脚本现在都会分别打印「Hessian 退化、剔除」与「参数贴界、保留」两个清单。

**判据自检**（7 个构造用例，全部通过）：

| 输入 | 判决 | 剔除？ |
|---|---|---|
| 健康、在箱体内 | `ok` | 否 |
| SE 健康、`d_ref = 0.20`（下界） | `bound` | **否** |
| SE 健康、`d_ref = 6.00`（上界） | `bound` | **否** |
| `SE = 0` | `degenerate` | 是 |
| `SE = nan` | `degenerate` | 是 |
| `SE = 1e-6`（相对过小） | `degenerate` | 是 |
| `SE = 0` 且贴界 | `degenerate` | 是（退化优先） |

**两个真实个案因此被正确分开**：

* `P=0/subj0`（`d_ref = 0.2`，SE 健康）⇒ `bound`，**保留**。第一版把它剔除了。
* `P=8/subj7`（`d_ref = 4.8009`，撞上界 6.0，**`SE = 0.0000`**）⇒ `degenerate`，
  重试后仍退化 ⇒ **剔除**。这才是 §8.11 结论 3 里真正污染回归的那个点。

#### 三条方法论教训

1. **「估计贴界」是箱体信息，「SE 退化」是曲率信息。** 用一个布尔把两者合并，
   必然在其中一侧犯错：要么漏掉真退化，要么删掉合法点。判据有几个语义不同的
   失败模式，判决就该有几档。
2. **给诊断规则加新判据时，必须先用真值检验它抓到的到底是不是失败。**
   我的第一版判据说「贴界 = 病态」，而真值就在界上——**判据本身**是错的，
   但只有把真值重放出来才看得见。只看估计值永远看不出这一点。
3. **确定性种子是可检验性的来源。** 被试生成的种子是 `BASE_SEED + int(P)*1000 + s`，
   完全可重放，所以我能在秒级内算出「该被试的真值究竟是 0.2000 还是只是拟合失败」。
   若种子不可重放，这个 bug 会以「组层结果不稳定」的形式长期潜伏。

#### 已知遗留

* `np.clip` 造成的边界概率堆仍在（本轮 40 人里有 **1** 人，P=0）。它不影响
  真值落在箱体内这一好性质，但会让边界的 profile likelihood 变成单边。
  可选修法：改成真截断正态（越界重抽），或把 `d_ref` 下界从 0.20 放宽到 ~0.05。
  **本轮不修**，理由：与判据修正同时改动会让组层重跑无法归因。
* ~~组层的真正瓶颈仍是 **P 只有 4 个水平**（oracle 天花板已只能 13%），
  这与参数化、与判据都无关。~~ ⚠️ **已被 §8.13 推翻**：瓶颈是**每组人数**，不是水平数。

### 8.13 ❗ 组层瓶颈的诊断被推翻：不是「P 只有 4 个水平」，而是每组人数（2026-10-14）

§8.11 读法 1 与 §8.12 的遗留项都写了「组层的真正瓶颈是 P 只有 4 个水平，
oracle 天花板只允许 13%」。**这是一句我没有验证过的话**，而它决定了两件事：
要不要为组层增加 P 水平、以及组层能不能靠加人数改善。
`_scratch/check_plevels.py`（200 次重复）直接检验它。

#### A. 无噪声 oracle：组模型在 4 个水平下**完全可识别**

| 水平集 | `tau_P` | `beta_P` | `d_ref` | `beta_S` | `beta_SP` | 残差 RMS |
|---|---|---|---|---|---|---|
| L4 现行 0/8/32/120 | 30.0000 | 0.3500 | 0.6481 | 0.1506 | 0.0600 | 1.9e-15 |
| L7 +4/16/64 | 30.0000 | 0.3500 | 0.6481 | 0.1506 | 0.0600 | 1.6e-16 |
| L9 +2/90 | 30.0000 | 0.3500 | 0.6481 | 0.1506 | 0.0600 | 6.8e-15 |
| **真值** | 30.0000 | 0.3500 | 0.6481 | 0.1506 | 0.0600 | — |

直接喂**组模型期望值**（完全不带被试抽样噪声）时，最小二乘**精确**返回真值到机器精度。
⇒ 「oracle 偏差 13%」**不是天花板，是抽样噪声**。我此前把它写成设计限制是**错的**。

#### B. 有噪声 oracle，200 次重复：误差按 1/√n 下降

|---|---|---|---|---|---|---|---|
| 10 | 40 | 37.95 | +7.95 | **29.77** | 0.0884 | 0.0367 | 0.0453 |
| 20 | 80 | 34.17 | +4.17 | 18.32 | 0.0604 | 0.0298 | 0.0338 |

关键读数：**n=10/组时 `tau_P` 估计量的 SD 是 29.77，而真值只有 30.00——相对 SD ≈ 99%。**
一个 40 人实验对 `tau_P` 的估计**几乎不携带信息**，这直接解释了 §8.11 里
lin 撞下界（1.00）与 exp 给出 14.85：两者都在 30 的 1 个 SD 之内。
`beta_P` 好得多：n=10 时 SD 0.088（真值 0.35 的 25%），n=40/组 降到 10%。

#### C. `tau_P` 的方差不是撞界撑出来的

n=10 只有 1.0% 撞上界，中位数 28.84 已很接近 30 ⇒ **这是真实的估计方差，不是撞界伪影**。

#### D. 线性 P 通道：**不能照搬 T 通道的做法**（重要反例）

D22 对 T 通道用「去掉时标、改线性」，BIC 还偏向线性。同样的手法**不能**搬到 P 通道：

无噪声最小二乘直线（拟合 exp 形状的真值，4 个水平）给出
`beta_P = 0.0025`、`d_ref = 0.5652`（真值 0.3500 / 0.6481）——**斜率被压掉 140 倍**。
原因：`P` 在 0–120 ms 上、`P_ref = 30` 居中，`f_P` 的响应是**S 形**（中间陡、两端平），
直线的正负残差互相抵消。逐点残差 `[+0.063, −0.002, −0.086, +0.020]`，最大 0.086，
是 d 跨度 0.34 的 25%。

线性 P 的**精度**极好（n=10 时 `beta_P` 的 SD 只有 0.0005），但那是**估错了量**：
`beta_P = 0.0025` 与 `0.3500` 不是同一个参数。⇒ **P 通道必须保留 exp 形状**，
这与 T 通道的结论相反。

#### E. 可行的处方：**先验固定 `tau_P`**，只估 `beta_P`

`beta_SP`（自我效应随 P 的变化）即使固定 `tau_P` 仍然很噪（67%），
在 4 个水平下基本不可用。

#### F. 换水平集救不了 `tau_P`

| 水平集 | n=10 相对SD | 误差≤25% | n=40 相对SD | 误差≤25% |
|---|---|---|---|---|

| L5 上升段 0/5/10/20/40 | **257.8%** | 13.5% | 191.6% | 31.5% |

| L8 0/2/4/8/16/32/64/120 | 79.2% | 42.0% | 25.8% | 71.5% |

把水平**集中在上升段**（L5rise）反而**严重变差**（257.8%）——因为没有任何水平接近
或超过饱和点，`tau_P` 完全没有约束。最宽、最多水平的 L8 只比现行 L4 好 ~20%。
⇒ **`tau_P` 的不可识别是被试间方差相对人数的问题，不是水平集选择的问题。**

#### 结论（修正 §8.11 与 §8.12 的遗留项）

1. **组层不存在「4 个水平」造成的信息天花板。** 无噪声 oracle 精确；误差随 n 按 1/√n 缩。
2. **真正的瓶颈是每组人数。** 现行 n=10/组（40 人）下：`d_ref` 可用（SD 0.037）、
   `beta_P` 勉强（25%）、`beta_SP` 差（75%）、`tau_P` **不可用（99%）**。
3. **`tau_P` 应当先验固定**（或干脆不报告）——这与被试内层 D18/D19/D24
   「去掉不可识别的时间常数」是**同一条原则在组层的再现**，但实现方式**不同**：
   T 通道可以改线性（BIC 支持），**P 通道不能**（D 段）。
4. **要把 `beta_P` 估到 10% 需要 ~40 人/组**；`beta_SP` 需要更多。这是**被试预算**问题，
   可直接写进论文的被试量论证。

#### 重跑后的组层数字（修正判据 + 起点重试，exp/lin 配对）

修正判据并加入「起点数 2 → 8 → 32 重试」后重跑 lin
（`recover_group.py 10 lin`，661.8 s）：**0 名退化、1 名贴界保留**
（`P=0/subj0: d_ref=0.2 贴下界 0.2`，即 §8.12 那个真值就在界上的合法个案）。
§8.11 那个 `SE = 0.0000` 的 P=8/subj7 **被重试救回**，两套口径因此相同：

| 参数 | 真值 | 修正前(实际) | 修正后(实际) | Bias | oracle | oracle Bias |
|---|---|---|---|---|---|---|

#### 方法论教训

**「贴界」在真实数据里永远是坏消息，只有在模拟里才能判定它是好是坏。**
仿真知道真值，所以能区分「真值就在界上」（`P=0/subj0`，保留）与「估计逃逸」
（exp 的 14 次，应为失败）。真实数据没有真值，`bound` 只能当作
**「该参数未被数据约束」的警告**：单个参数反复贴界，就意味着它在当前设计下不该被估计。

实现要点：

- 新常量 `GROUP_FIT_NAMES_FIXED_TAU = ["d_ref", "beta_P", "beta_S", "beta_SP"]`；
  固定模式下拟合 4 个参数，返回的 dict **仍含 `tau_P` 键**（值为固定值），
  使汇总表的统一打印无需分支。
- `fit_between(..., fit_names=None, tau_p_fixed=None)`：`tau_p_fixed` 非 None 时
  `resid` 里的 `reg` 用固定值算，且该值不进入 `least_squares` 的优化向量。
- **固定值 ≠ 真值**。用 `tau_P = 30`（恰好等于本轮仿真真值）只是最好情形；
  真正的用法是取文献/先验值，并做**误设敏感性**（如 20 / 50）。
  脚本会在表头显式打印「固定值与真值的偏离本身是误设」这一警告，
  以免把固定值模式误读成 oracle。
- 结尾「读法」段已改写：删掉旧的「瓶颈在 P 的水平设置」，
  改为「无噪声 oracle 在 4 个水平下精确（~1e-15）；有噪声时按 1/√n 缩；
  n=10/组 时 `tau_P` 相对 SD ≈ 99% ⇒ 必须先验固定」。

⚠️ **逆方差加权（WLS）已实现**：`fit_between(..., se_d, se_s)` 给定逐被试的被试内
SE 时，残差按 `1/SE` 缩放（`least_squares` 解的就是加权最小二乘），返回值扩为
三元组 `(out, rms, wrms)`——`rms` 始终是**未加权**残差 RMS（两种模式可比），
`wrms` 是加权残差均方根。`recover_group.py` 对每个可运行的组层回归
（含 oracle）**同时跑 OLS 与 WLS** 并并排打印，另附判定规则：
**WLS 若让 `oracle` 列更接近真值 ⇒ 等权确实在浪费精度；若反而更差 ⇒
数值 Hessian 给出的 SE 太噪，不该拿它当权重。**

### 8.14 Stage 5 开工：M-T1 的似然 / 拟合 / 生成三件套（2026-10-14）

**为什么 Stage 5 的第一件事是「问 ρ 能不能估」，而不是「比较三个模型」**

Stage 3 的全部恢复率、Stage 4 的全部设计比较，用的都是**单阶段** WFPT
（漂移 `d(T)` 在刺激期内恒定，`T` 只作可用性上界）——那正是 **M-T3**。
若真实生成过程是 M-T1（掩蔽后漂移降为 `ρ·d(T)`），那些数值就全是设定错误。

★ **结构性事实**：**M-T3 是 M-T1 在 `ρ = 1` 处的严格嵌套特例**。
所以 Q1 不需要另建模型比较框架，只需问：**ρ 在 D4 里可估吗？**
——这也意味着 Stage 5 的核心产物是一个**单参数**问题，而不是三个并列模型。

**四项必须先钉死的事实（都实测过）**

1. **嵌套一致性通过，但"逐位相等"是错误的验收目标**。
   `_scratch/check_twophase_lik_u8.txt`：`rho=1` 时 M-T1 与单阶段逐试次对数密度
   最大相对差 **2e-6**。我自己第一版判据要求更紧因而"失败"——但 `wfpt` 文档化的
   `_S_FLOOR = 1e-3` 边界效应本来就是这一量级。正确表述是
   **「差在库自身的离散化精度内」**，不是「相等」。
2. **生成的 dt 必须标定，不能沿用直觉**。以解析单阶段生成器为基准
   （6 次重复均值：正确率 0.8254、遗漏 0.3197、RT 759.2 ms），Euler 的 `|Δacc|`：

   | `dt` | `\|Δacc\|` | 秒/被试 |
   |---|---|---|
   | `2e-4` | 0.0174 | 1.6 |
   | `1e-4` | 0.0046 | 3.1 |
   | **`5e-5`（默认）** | **0.0022** | **6.1** |
   | `2.5e-5` | 0.0003 | 12.4 |

   偏差**单调收敛到解析值**。首次通过问题的 Euler 弱阶低于常说的 1 阶——
   所以早先看到的 0.0306 是「`dt=2e-4` 偏差 + 抽样噪声」，**不是实现错误**。
3. **解析抽样反而不能用**：`wfpt.flux` 的 `kmax` 由**批次内最小 `t`** 驱动，
   均匀细网格会把 kmax 顶到 ~167 ⇒ **70 s/被试**；Euler 只要 6 s。
   这是「数学上更干净 ≠ 工程上可用」的具体例子。
4. ⚠️ **两个必须分开写的比例**（曾被我混为一谈）：
   `design_grid.py:209` 算的是 `sim["rt"][keep] < T_arr[keep]`，而 `sim["rt"]` **已含 `t0`**
   ⇒ 那是 **`P(RT < T)`**（D5「按键即结束」是否触发），**不是** `P(τ < T)`。

   ——即约 30 次试次的**积累过程本身**在刺激期内结束。

   但文档必须同时写两个数，否则「`RT < T` 全 0%」会被误读成「掩蔽后漂移几乎不生效」。

### 8.18 被试层真值的**边界概率堆**：`np.clip` 是 clipping 而不是 truncation（2026-10-14）

README §9 第 10 项的落地。`simulate.draw_subject_params` 原来只有一个实现：抽正态、
越界者 `np.clip` **压到界值本身**。这不是截断而是**压边**，后果必须量化而不能靠猜。

**新增 `mode` 参数**（`simulate.py`）：`"clip"`（**默认，与历史日志逐位一致**）与
`"truncate"`（界内截断正态，**逆 CDF** 抽取，`_truncated_normal`）。
`recover_group.make_subject_truth` 也透传 `mode`。探针 `_scratch/check_bounds_trunc.py`
（`python _scratch/check_bounds_trunc.py [n_big] [n_sub]`），日志 `_scratch/check_bounds_trunc_u8.txt`。

**表 A：压到界上的概率（解析式：`Φ((lo−μ)/σ) + 1 − Φ((hi−μ)/σ)`）**

⚠️ **只有 `d_ref` 会压边，且只在低 P 水平**——其余三个随机效应参数（`beta_S`/`a_ref`/`t0`）
的界距 μ 都在 4 SD 以上，压边概率 < 1e-4。

|---|---|---|---|---|

❗ **两条新事实**：

1. **`lin` 的堆是 `exp` 的两倍**（6.53% vs 3.16%）——因为 lin 的组层 `d_ref = 0.4268`

⇒ **判决**：堆是真的、可测的、有方向的（系统性抬高最低 P 水平），但**小到不足以推翻任何
已锁定的结论**；既然修法免费且精确，**新工作改用 `mode="truncate"`**，而**默认保持 `clip`**
——改默认会让 `_scratch/` 里所有历史日志无法复现。

**四条自检（全部通过，日志 D 段）**：

1. ✅ `mode="clip"` 与手写 `np.clip` 老实现**逐位相同**（50 个种子）⇒ 历史日志仍可逐位复现；
2. ✅ `mode="truncate"` 在 4 个 P 水平 × 20000 次抽样里**堆占数 = 0**；
3. ✅ `truncate` 的边际 SD 与解析截断公式吻合（P=0 `d_ref` 实测 **0.1376** / 解析 0.1390 /
   设定 0.1500；`beta_S` 0.0997/0.1000；`a_ref` 0.2497/0.2500；`t0` 0.0299/0.0300）；
4. ✅ 组层 `d_ref` 均值的两模式差只在 P=0 系统性。

**为什么不用「越界重抽」**：重抽的抽数随机 ⇒ 同一颗种子在不同平台上可能给出不同的被试参数；
逆 CDF 固定只抽 1 个均匀数，随机数流与平台无关。

⚠️ 本节只量化**生成侧**的堆。**拟合侧**的对应物是「贴界」，处置规则见 §8.12（只报告、不剔除）
——两者不是一回事：真值可以合法地落在界上（本节的 `clip` 就制造了这种被试），拟合也可以合法地落在界上。

#### 8.20.1 v4.1 修正：T/W 列的打印精度（2026-10-14，Stage 6 前置检查时发现）

❗ **一个会静默摧毁被试内因子 `T` 的缺陷**：v4 的数据行格式串里 `T`/`W` 用 `%.1f` 打印，而**它们的单位是秒**。

#### 8.22.2 新增 `1_Code/DDM_Core/loo.py`：零依赖 PSIS-LOO（Vehtari/Gelman/Gabry 2017 算法 1）

* API：`psis_loo(log_lik: (S,N))`、`psis_one`、`waic`、`loo_compare(models: dict -> Markdown 表)`；
  `gpd_fit` 用**一维剖面似然（Grimshaw 技巧）**——给定 `k`，`a = k/σ` 由
  `Σ_i 1/(1+a·y_i) = m/(1+k)` 唯一确定（左端关于 `a` 单调递减 ⇒ 二分），再对 `k` 做一维有界搜索。
* `loo_compare` 的差值 SE **必须用配对差**算，不能把两个 SE 相加。
* ⚠️ **单观测的 `k̂` 噪声很大，不得逐点解读**：`_scratch/diag_gpd_bias.py`（2000 次重复、S=4000、
  `M = int(min(S/5, 3√S)) = 189`）实测——Pareto(α=3)（真值 `k=0.3333`）`E[k̂] = 0.3248`（偏差 −0.0086）、
  **单观测 SD = 0.103**；Pareto(α=1.2)（真值 `k=0.8333`）`E[k̂] = 0.8200`（偏差 −0.0134）、
  **SD = 0.143**。⇒ 是否该换 `k`-fold CV 要看 `n_k_gt_bad / N` 这个**比例**与 `k_max`。
* **解析基准**（`_scratch/check_loo.py`，17 项判据）：一元高斯 `mu ~ N(0,1)` 的闭式 LOO 与
  PSIS-LOO 相差 **0.015**（逐点最大 0.006）、`p_loo = 1.248`（真值 1）、`max k = 0.169`、
  WAIC 与 PSIS-LOO 完全一致 ⇒ **估计量核心正确**。
  ❗ 第一版 B 组判据（`±0.08` 覆盖率 ≥90%、α=1.2 要求 100% 被报警）**9/12 不过**，
  根因是**判据本身定错**（容差凭感觉，没依据实测抽样分布），而不是估计量错——
  改按实测 SD 定容差（`max(0.035, 4·SD/√N)`）、N 50→200 后 **14/14 通过**。
  教训：**给自己写的估计量设容差时，容差必须来自实测的抽样分布**。

#### 8.22.3 新增 `1_Code/DDM_Core/stage8.py`：拉普拉斯后验抽样 + PPC

* `laplace_draws(log_post_x, x0, n_draws, ...)`：通用抽样器，目标协方差
  `(−∂²log_post/∂x²)^{-1}`；**非正定时把负/零特征值抬到 `eig_floor·max|λ|` 并如实报告
  `n_flipped`**——这个数不为 0 就说明该点不是可信的众数。
* `subject_laplace(tr, names, p_map, ...)`：把逐被试 WFPT 对数似然包成 `log_post_x` 再抽样，
  返回 `theta`（自然参数尺度）、`log_lik`、协方差与特征值谱。
* `sample_ppc` / `ppc_table` / `format_ppc`：后验预测抽样与 12 项检验统计量
  （未响应率、正确率、RT 分位、正确/错误 RT 中位、**`RT<T` 比例**、最差单元未响应率）。
* ⚠️ `sample_ppc` 必须把**设计列**（`T`/`W`/`is_match`…）与观测列合并——`simulate_subject`

## 8.23 层级耦合与「以被试为单位的 leave-one-participant-out」（2026-10-14，D42）

兑现主计划 §3 Stage 8 里的 **层级 DDM 拟合** 与 **leave-one-participant-out**（那句"不用 trial-level LOO 冒充跨被试泛化"）。方案文本见 [`5_Reference/08_工作流/Stage8_建模与验证方案.md`](../../5_Reference/08_工作流/Stage8_建模与验证方案.md)。

### 1. `hier.py`：拉普拉斯-EM 层级拟合

群体模型：`x_s ~ N(mu, diag(sigma²))`（`x` = 被试参数的**无约束**坐标）、`y_s ~ p(y | theta_s)`、`(mu, log sigma)` 带弱信息先验。常量 `POP_MU_PRIOR_SD = 2.0`、`POP_LOGSIGMA_PRIOR_MU = log(0.5)`、`POP_LOGSIGMA_PRIOR_SD = 1.0`、`SIGMA_FLOOR = 1e-3`、`MAX_MODE_ITER = 80`、`HYPER_STEP = 0.05`。

* **拉普拉斯边际**：`log_marg = g(x*) + (K/2)·log 2π − 0.5·logdet(−∂²g/∂x²)`，其中 `g = log p(y|x) + log N(x; mu, sigma²)`。非正定特征值个数 `n_flipped` **如实传出**。
* **M 步是闭式的**（零额外似然评估）：
  `mu = Σ_s x*_s / n`、`sigma_k² = mean_s[(x*_{s,k} − mu_k)² + Cov_s[k,k]]`。
  ❗ 那个 **`+ Cov_s[k,k]` 是标准修正，漏掉会让 σ 系统性低估**：自测实测只用众数离散度 **0.4029** < 含修正的 **0.4499**（真值 0.5）。
* **为什么不直接数值优化 `(mu, log sigma)`**（`_scratch/_probe_stage8_timing.py` 实测，576 试次/人、K=4）：单次 `log_likelihood_step` **84.02 ms**、`hessian_x` **3.43 s**、冷启动 LBFGS ≤60 步 **9.32 s** ⇒ 5 人一次外层评估 ≈ **64 s**，8 维 Nelder-Mead 要上百次 = 数小时；EM 8–15 轮即可。
* API：`hier_fit` / `subject_map_laplace` / `hyper_hessian` / `hyper_draws` / `loo_matrix` / `loo_bruteforce` / `fit_and_loo` / `compare_models`。
* ❗ **踩坑**：`likelihood._bounds_for` 写的是 `override.get(n, PARAM_BOUNDS[n])`，Python **先求值默认参数** ⇒ 即使 `override` 里有 `rho` 也会 `KeyError: 'rho'`（`rho` 只定义在 `twophase.MASK_RHO_BOUNDS`）。`hier.py` 因此自带 `_bounds_with_rho()` 合并 `{**PARAM_BOUNDS, RHO_NAME: MASK_RHO_BOUNDS}`。

## 8.24 数据→模型的桥：`1_Code/Experiment/read_formal_data.py`（2026-10-14）

Stage 8 之前缺一件东西：**把被试按过的键翻译成模型认的因子**。这件事最危险的地方是
**写错了不报错**——`is_match` 一旦反过来，整条 Stage 8 的模型比较都建在错的签上，
而每一份下游报告仍然自洽。

### 1. 映射不是显然的：程序存的是按键与标签，不是因子

`1_Code/Experiment/exp_matlab/Exp_Design_Formal.m` 的列语义（L1005–1035）：

| 列 | 名称 | 含义 |
|---|---|---|
| 11 | `Shape` | `square` / `circle` |
| 12 | `Label` | `self` / `stranger` |
| 13 | `CorrectKey` | 该试次的正确键 |
| 14 | `Response` | `respStr`，未响应写 `'NA'` |
| 15 | `RT` | `responseTime`，未响应 NaN |
| 16 | `Correct` | 未响应 NaN / 正确 1 / 错误 0 |
| 17–25 | 技术列 | `block, premature_press, timeout, responded_by_deadline, stimulus_onset_actual, stimulus_offset_actual, mask_onset_actual, stimulus_dur_actual, stimulus_frames` |

**没有 `is_self`/`is_match` 列**。推导是：

```

matchKey = {'f','j','j','f'}[(subjectID - 1) % 4]        # 程序 getMatchKey，L1176
is_match = (CorrectKey == matchKey)
side     = (Response   == matchKey)

```

### 2. 两条**独立**路径推 `is_match`，且必须一致

程序里还有 `getPairingRules`（L1155，`rules{mod(subjectID,4)+1}`，给出
`Shape → {Label → 正确键}`）。已核对四档 mod 情形与 `{f,j,j,f}` 循环**互相自洽**，
于是 `is_match` 有第二条独立推导路径。`validate()` 要求**两条路径逐行相同**——
这是这条映射最强的单条守卫。由它必然导出 **`Correct == 1` ⟺ `side == is_match`**，
也一并断言。

### 3. ❗ 两条**代码级**硬约束（不是数据问题）

**约束一：一条 `rt ≤ t0` 的已响应试次会让整份数据变成 `None`。**
`1_Code/DDM_Core/likelihood.py` 的 `per_trial_loglik`（L53–95）在
`t = tr["rt"][responded] - t0` 之后紧跟 `if np.any(t <= 0): return None`（L74–75），
`log_likelihood` 于是返回 `-inf`。合成数据里有 ~3% 的预期性抢按（RT 低到 ~16 ms），
默认 `t0 = 0.22`（`mapping.py:121`）⇒ 原表**必然**算不出来。
⇒ 新增 `RT_FLOOR = 0.15` 与 `fit_ready(tr, rt_floor) -> (tr_kept, rep)`，只剔
"已响应且 `rt < 0.15`"（未响应原样保留，它们走 `survival_series`，不受 `t > 0` 约束）。
依据：**设计本身就把 `RT < 0.15 s` 当预期性反应**，生成器的 `--rt-lt-t` 就是按它造的。

**约束二：`t0` 的可用上界比 `min(RT)` 更窄。**
库内 `t0` 的 bounds 是 `(0.05, 0.60)`（`mapping.py:84`）。探针
`_scratch/_probe_t0_wall.py` / `_probe_t0_wall2.py` 实测被试 1（剔除抢按后
min RT = **0.2370 s**）：

| `t0` | 结果 | 越界的试次 |
|---|---|---|
| 0.2300 | `None` / `-inf` | trial#220（rt = 0.2370，t = 0.0070）`f = **−7.77e−14**` |
| 0.2360 | 有限（−535.89） | 最小 `f` = **+6.01e−16**，**刚好没越界** |
| 0.2371 | `None` / `-inf` | `t<0` 墙 + trial#393（rt = 0.2430，t = 0.0059）`f = **−8.23e−15**` |

**非单调**（0.2300 挂、0.2360 过、0.2371 又挂）说明这不是一道 `t ≤ 0` 的墙。

### 4. ❗❗ `wfpt.flux` 在小 `t` 处的**灾难性抵消**——已根因修复

**机制**。`1_Code/DDM_Core/wfpt.py` 的 `flux` 原本用 [0,a] 上的特征函数级数

```
s   = Σ_{k=1..kmax} k · sin(kπd/a) · exp(−k²λt),   λ = (π/a)²/2
out = (π/a²) · exp(v·d − v²t/2) · s
```

**项幅 O(k)，而 `t→0` 时真值指数级小**。于是当真值降到级数的抵消地板以下
（约 `kmax·eps`）时，返回值就是双精度噪声、**符号随机**。
`per_trial_loglik` 的 `if not np.all(np.isfinite(f)) or np.any(f <= 0): return None`
（L81–82）随即把**整份**数据判死。实测的 −7.77e−14 / +6.01e−16 / −8.23e−15
全部落在该地板量级。

**实测地板**（`_scratch/_probe_flux_floor.py`）：
`wfpt._k_max(t_min = 0.020, a = 2.0, tol = 1e-15) = **39**` ⇒ 地板 ≈ `39·eps ≈ 8.7e−15`。

**修复（2026-10-14 本轮完成）**：`flux` 现在有**两条互为对偶**的级数，按 `t` 派发。
正弦级数在大 `t` 收敛，**镜像/反射级数**（由同一特征函数展开经 Poisson 求和互换得到）
在小 `t` 收敛：

```
f(t) = e^{v·d − v²t/2} / (√2·√π·t^{3/2}) · Σ_{n∈ℤ} (d + 2na) · e^{−(d+2na)²/(2t)}
```

- 新增 `_flux_series(d, v, a, t, tol=_TOL)`（旧级数主体，数学不变）与
  `_flux_dual(d, v, a, t)`（镜像级数，`n_max` 由 `_LOG_CUT = 700.0` 定），
  `flux` 做派发：`d_min = min(|d|, |2a−d|)`、**`cross = a·d_min/π`**；
  `t < cross` → `_flux_dual`，否则 `_flux_series`。交叉点取"两支首项衰减率相等"
  （`π²t/(2a²) = d_min²/(2t)`），该点两支都只剩几个有效项。
- **对偶式已解析核对**：`Σ_{k≥1}k·sin(kx)e^{−k²θ}` 的 Poisson 对偶为
  `√π/(4θ^{3/2})Σ_n(x+2πn)e^{−(x+2πn)²/(4θ)}`，代回后前置因子恰为
  `1/(√2·√π·t^{3/2})`；`n=0, v=0` 时退化为自由核密度 `d/√(2πt³)·e^{−d²/(2t)}` ✅
- **独立判据（关键）**：不靠"两条分支互相对一眼"（那只证明一致、不证明都对），
  而是用**解析积分恒等式** `∫_0^∞ f dt = (1−e^{−2v(a−d)})/(1−e^{−2va}) = p_upper(v,a,a−d)`
  与 scipy `quad` 积分两条**推导路径完全不同**的方式对 `1_Code/DDM_Core/wfpt.py:128–139`
  的闭式吸收概率。⚠️ 该逐项积分只在 `v > 0` 成立（`v < 0` 时几何和发散）

  >1e−3 的有 **184** 点、≤0 的有 **80** 点，最差 **2.16e+34**（a=2, z=0.5, v=0.5,

## 8.25 两处遗留 floor 的重新论证 + Stage 8 全量运行器（2026-10-14）

§8.24 第 4 节把 `flux` 的小 `t` 相消从「绕开」改成「算对」之后，**`_S_FLOOR` 与
`_T_FLOOR` 的原始理由被抽掉了**——它们当初是为「正弦级数在小 `t` 不可信」打的补丁
（§8.24 第 7 节的遗留项、§9 第 29 项的 ⚠️）。本节把这两处从**论证**改成本轮**实测**。

### 1. 探针与它需要的独立参考量

`1_Code/DDM_Core/_scratch/check_sfloor.py`（v2，9 项判据 A1–A2 / B1–B5 / C1–C2）。

❗ 关键困难是**没有独立参考量**：`density_step` 的两支（`pre` 用单阶段 `flux`、`post`
用 Green 卷积）互为"另一支"，只把它们对看只能证明**一致**、不能证明谁对。本轮找到的
闭式参考是 **Chapman–Kolmogorov 恒等式**（`v2 == v1` 时）：

```
∫ flux(a−x, v, a, s)·G(x, T) dx   ≡   flux(a−z, v, a, T+s)
```

它成立是因为 `flux` 里的 `sin(kπd/a)` 正是吸收边界上的 **Dirichlet 本征函数** ⇒ 卷积
只是把单阶段密度"续"到 `T+s`。这条恒等式**同时是 `green` 的第一次独立校验**。

⚠️ v1 的 B2 判据本身是错的：它取的 `s ≤ _S_FLOOR` 会被 `density_step` 判进 `pre`
分支、**根本没走卷积**（相对误差 0.000e+00）。v2 用 `conv_up(d, s, n_x)` **强制
`W._S_FLOOR = 0.0`** 才真的踩到它。

### 2. 实测结论（9/9 全过、exit 0、106.7 s）

| 判据 | 结论 | 关键数字 |
|---|---|---|
| A1 | `green` 的 δ 退化分支在似然路径上**不可达** | 正式最小 T = 0.033330 = **333×** `_T_FLOOR = 1e-4` |
| A2 | `np.maximum(t−T, _S_FLOOR)` **是死代码** | `np.nextafter` 逐位上探 **4 个 T × 100 000 步 = 0 命中**；紧邻上浮点的 `t−T` 超出量 **1.475e-17 s** |
| B1 | **缝是真的** | T=0.15/a=1.8 → pre 1.105728e+00 vs post 1.073330e+00，相对跳变 **2.930e-02**；T=0.25/a=3.0 → 1.990426e-01 vs 1.932767e-01，**2.897e-02** |
| B2 | **卷积对闭式参考的相对误差**（决定性测量） | s=1e-5 → **9.360e-01**、3e-5 → 1.555e-01、**1e-4 → 4.548e-05**、3e-4 → 6.079e-06、1e-3 → 9.622e-07、1e-2 → 2.821e-08、3e-2 → 4.886e-09 |

| C2 | 判定文本 | 见下节 |

### 3. 决策：两处都**保留**，但理由换成实测的

* **`_S_FLOOR = 1e-3` 保留**。真正绑定的约束**不是相消，而是卷积的 x 网格分辨率**：
  误差首次 < 1e-2 的最小 `s` 在 n_x=161 / `_X_EPS=1e-6` 下是 **1e-4**，把网格加细到
  n_x ≥ 801 或收紧 `_X_EPS = 1e-8` 后降到 **1e-5** ⇒ 现行 1e-3 **落在可信区内且有
  ≥10× 余量**（安全，但保守约 7×）。改成 f\* ≈ 1.4e-4 只能把最坏点误差由 ~3.1% 压到
  ~1.0%（对 loglik 约 0.19 nats），代价是**整条已验收套件**（`validate_step.py` 的
  W4/W5、`check_twophase.py`）必须重新验收。**结论：已重新论证 → 保留保守值；最优值
  ≈1.4e-4 记录在案但本轮不采纳。**
* **`_T_FLOOR = 1e-4` 保留**，但理由**仅限退化输入**（T = 0 或 T ≤ 1e-4 的合成/极限
  情形）；正式设计的最小 T 是它的 **333 倍**。
* `np.maximum(t−T, _S_FLOOR)` 的钳位**保留**（无副作用），但**不得声称它在防相消**：
  后分支条件 `t > T + _S_FLOOR` 已蕴含 `t−T ≥ _S_FLOOR`，对任何 `_S_FLOOR ≥ 0` 都成立。
* 两处**都不再列为遗留项**（§9 第 29 项据此改写）。
* ❗ **教训**：v1 的 8 项判据里 **5 项被实测推翻**（A2 / B2 / B3 / B4 / C1），其中
  B2 是测试自身写错、另外 4 条都是**我把预期当成了事实**（以为"1e-3 是内部最优"、
  以为"偏差是 O(s)"、以为"钳位在防舍入"、以为"floor 会污染似然"）。
  **一个"重新论证"的探针，如果所有判据都通过，多半是判据太松。**
