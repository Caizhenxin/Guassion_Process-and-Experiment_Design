# 生成数据（Generate_Data）：三个模型各自的模拟数据

> **这一整个目录里的数字都不是人类被试的数据。** 它们只用于三件事：
> ① 证明模型**能**生成结构合理的逐试次数据；② 做参数恢复 / 功效分析；③ 让流水线的每一步在拿到真数据之前先跑通。
> 论文里凡是引用这里的数字，必须标「模拟」并写清模型与真值（见 `5_Reference/08_工作流/Stage9_设计空间优化与论文整合方案.md` §13 与 D104 证据阶梯）。

## 0. 三个模型是什么关系

三条模型只在**一处**不同：掩蔽出现之后证据还积不积累。

```
M-T3（ρ=1，掩蔽无影响）  ←——  M-T1（阶跃 + ρ）  ——→  M-T2（斜坡 + ρ，τ_T→0 时退回 M-T1）
```

| 目录 | 模型 | 漂移轨迹 | 定位 |
|---|---|---|---|
| `M-T1/` | 两阶段**阶跃** | 刺激期内恒为 `d_stim`；掩蔽后 `ρ·d_stim` | **主模型**。把「掩蔽有没有打断积累」变成可估参数 `ρ ∈ [0,3]` |
| `M-T2/` | 两阶段**斜坡** | `d_stim(1 − e^{−t/τ_T})`，掩蔽时取当时值乘 ρ | **竞争解释**：T 的效应可能来自「爬升需要时间」，而不是漂移幅度本身 |
| `M-T3/` | 单阶段 | 全程 `d_stim`（即 `ρ = 1`） | **零假设**：M-T1 的严格嵌套特例，少一个参数，靠 ΔELPD / BIC 判，不靠「谁拟合得好」 |
| `_compare/` | — | — | 三条模型在同一真值下的横向对照（见 `fig7_model_compare.png`） |

`M-T2` **没有似然**：`1_Code/DDM_Core/ramp.py` 只能造数据、不能拟合（`twophase.py` 里只有一行注释定义了它）。因此 M-T2 目前只能作为「生成机制的可视化对照」，不能进入模型比较——这一点必须写进论文的局限性。

## 1. 目录内容

每个模型目录下：

| 文件 | 内容 |
|---|---|
| `trials_long.csv` | 逐试次，**含真值潜变量**（`d_stim`、`a`、`z`、`t0_ms`），用于参数恢复检验 |

| `figures/fig1..fig6.png` | 六张图（见 §3） |
| `figures/crf_table.csv` | CRF 逐分箱数值（可直接进论文表格） |

规模：4 组 × 4 人 = **16 名被试/模型**，每人 4T × 3W × 2 身份 × 2 匹配 × 12 重复 = **576 试次**，合计 **9216 行/模型**。

## 2. `trials_long.csv` 数据字典

## 3.1 自我 / 他人为什么在 RT 密度上「看不出差别」

`fig1` 的左图里两条曲线几乎重合，这不是 SPE 机制没有生效。以 M-T1 为例（16 名被试、9216 试次）：

| 量 | 数值 | 是否显著 |
|---|---|---|
| 真值漂移差 `Δd_stim` | **+0.320**（0.764 → 1.084，+42%） | 设计使然 |
| 正确率差（自我 − 他人） | **+8.0 pp** | 是，配对 95%CI [+0.06, +0.09] |
| RT 中位差（他人 − 自我） | **+13.6 ms** | 是，配对 95%CI [+0.5, +26.7] |
| RT 分布宽度（SD） | 289 ms | — |

**+13.6 ms 只占分布宽度的 4–5%**（Cohen's d ≈ 0.05）⇒ 在密度图上肉眼不可分辨。要在密度图上直接看出位移，至少需要 0.5 个 SD（约 145 ms）。所以判断 SPE 要看 **`fig5`（delta 图，逐分位 + 95%CI）** 与**正确率**，而不是看两条密度曲线是否分开。

真问题在别处：`ρ` 把掩蔽后的漂移差同样乘了 0.8 ⇒ **两阶段模型的 RT 侧 SPE 被二次衰减**。

| 模型 | W=800 | W=1200 | W=1800 |
|---|---|---|---|
| M-T1（ρ=0.8）ΔRT 中位 | +20.5 ms | +24.7 ms | **+9.3 ms**（非单调） |
| M-T3（ρ=1）ΔRT 中位 | +18.6 ms | +32.1 ms | **+43.3 ms**（单调放大） |

## 3.2 SPE 该建模在哪一层：`fig8_spe_locus.png`

`1_Code/Experiment/spe_locus.py` 用同一群人、同一真值，只改 SPE 的落点（两个条件共享同一条噪声流，配对比较）：

| 位点 | ΔRT 分位斜率（p90−p10） | Δ正确率 | 签名 |
|---|---|---|---|
| 漂移（**当前模型**） | 23 ms | **+0.073** | 更快 + 更准；慢试次受益更多 |
| 边界 | 73 ms | **−0.011** | 更快但**更易错** |
| 非决策时间 `t0` | **0 ms**（整体平移 20 ms） | **0.000** | RT 平移、正确率不变 |
| 漂移 + t0（混合） | 21 ms | +0.043 | 两者叠加 |

**判别规则（已写入方法章，可预注册）**：

1. 正 Δ正确率 + 陡的分位斜率 ⇒ **漂移型**（本模型）
2. RT 各分位近似等量平移、Δ正确率 ≈ 0 ⇒ **t0 型**
3. Δ正确率 < 0（更快却更错）⇒ **边界型**

**处置**：主模型保留漂移型（四种里唯一能同时给出「更快 + 更准」），但结果章必须同时报 **ΔRT 的分位斜率**，不能只报中位差；若真实数据呈「均匀平移 + 无正确率差」，则模型应改 `t0` 型并重跑。

## 3.3 六张图怎么读

| 图 | 看什么 | 什么算「不对」 |
|---|---|---|
| `fig1_rt_density` | 单峰、右偏、左端由 `t0` 卡住（≳180 ms） | 双峰 = 混了两个漂移；左峰贴 0 = 有提前按键没剔 |
| `fig2_rt_quantiles` | 9 个分位曲线基本平行；T 越长整体略降 | 曲线交叉 = 条件间不只是漂移差 |
| `fig3_accuracy_omission` | T ↑ 正确率 ↑；W ↑ 遗漏率 ↓ | 方向相反 = 映射写反 |
| `fig4_crf` | 本模拟里**下降**（快试次更准） | 见下面「一处必须写明的口径差异」 |
| `fig5_delta` | 他人 − 自我 的 RT 差；正 = 自我更快 | 全 0 = 自我效应没进模型；符号翻转 = 编码错 |
| `fig6_mechanism` | 只有这张在讲「三条模型差在哪」 | M-T2 曲线有折角 = 斜坡实现错 |
| `fig7_model_compare` | 同一真值下三模型的正确率-T 曲线、delta 形状、CRF | 三条几乎重合 = 设计无法区分它们（那才是真问题） |

### 一处必须写明的口径差异

本模拟的 CRF 是**下降**的：我们只加了「逐试次漂移变异」（`drift_sd=0.25`，对数正态），低漂移的试次既慢又错。
真实数据里 CRF 常常是**上升**的，那通常来自**边界波动 / 注意失效 / 非决策时间变异**，而不是漂移变异。

**不要用模拟图去硬凑真实数据的形状。** 这条差异本身就是方法章要写明的模型边界；把它当作「模型缺一项」的证据，而不是调参数藏起来。
