# 工作台纪律（宪法 v1）

> 日期 2026-10-30 · 状态 ✅现行 · 依据 `6_Workbench/审计-与淋雨家工作台差距-20261030.md` · 权威性 项目内纪律的唯一口径
>
> 来历：本文件是「记忆宪法」的**项目内落点**。跨项目共用的部分在总台 `DSH_Workbench\AGENTS.md`；
> 本文件只管本仓库里「谁能改、怎么改、改完怎么留痕」。与 `AGENTS.md` 冲突时以本文件为准（它是细则）。

## 一、只认机主

1. 规则落盘只认**机主本人**在对话里的原话；AI 自己总结的「规矩」不自动升级为规矩。
2. 会话内临时指令有效到本会话结束；要跨会话生效，必须写进本文件并注明日期。
3. 用户说「按我原来的说法」时，先回原文核对，不凭印象执行。

## 二、事实只存一处

| 什么 | 唯一落点 |
|---|---|
| 当前进度 / 下一步 / 卡点 | `_交接/当前交接.md` §〇（覆盖写，≤4096 字节，单次改 ≤10 行） |
| 版本流水 | `Log.md`（最新在上） |
| 项目事实与口径 | `5_Reference/AGENTS.md` §三 |
| 文档索引 / 已推翻结论 | `5_Reference/README.md` |
| 该做什么 | 总台 `DSH_Workbench\boards\待办板.md`（项目内不再维护第二块板） |
| 纪律（谁能改什么） | 本文件 |

禁止同一事实写两处。发现两处不一致 ⇒ 按上表定权威，另一处改成指针。

## 三、派单与回执（通道未接，先立规矩）

1. 派单 ≠ 公告：要对方动手，必须有**能把消息送到对方会话**的通道；只在板上写一行不算派单。
2. 干完必须投递回执：**活干完了但对方不知道 = 没干完**。
3. ⚠️ 现状（2026-10-30）：本仓库与总台之间**尚无自动投递通道**，跨会话唤醒只能靠人在 GUI 里点开对应会话。
   因此当前一律**人工中转**，不得声称「已通知对方」；待通道接通（服务端指令接口）后再启用自动回执。
4. 派单**必须登记在台账**（总台 `tools\派单.py` → `boards\派单台账.jsonl`，只追加）：
   `add` 四件套（现象 / 照做 / 验收 / 回句）缺一拒收 → 人真投递后 `deliver --via` → 对方回执后 `ack` → 收尾 `close`。
   只有 `add` 没有 `deliver` 的活 = 没投递；超 `ACK_TIMEOUT_H=24` 小时没 `ack`，总台体检标 ⚠（不阻断，供人看）。

## 四、禁止无限对话与会话超线

1. 给对方会话的留言 ≤200 字 / ≤10 行；首行写标记（本仓库统一 `【gp-experiment】`），末行写 `【结束】`。
2. 一次性说清要什么、交付什么格式、什么算完成；不做「反复确认式」来回。
3. 长内容走文件（给路径），不塞进消息正文。
4. **会话超线**：上下文 ≥80% 时先报一行，≥100% 前必须先写 §〇 / `Log.md` 再换会话。
   这条只能纪律化——判据（`acp_status`）只在会话内可见，做成体检工具就是假判据。

## 五、修改权分层

| 对象 | 谁能改 |
|---|---|
| 纪律（本文件）、`AGENTS.md`、`5_Reference/README.md` §五 | 只认机主授权后改 |
| 当前交接 §〇、`Log.md`、通知看板 | 当班会话可直接覆盖写 |
| 待办板 | 只在总台改；项目内只读 |
| 一手证据（`1_Code/`、`2_Data/`）、`5_Reference` 归档目录 | 不改；要改先问，归档目录一律保留原样（含失效引用） |

## 六、记忆分三层

1. **宪法层**：本文件 + 全局 `AGENTS.md`。谁都不能随手改。
2. **项目事实层**：`5_Reference/AGENTS.md` §三 + `5_Reference/README.md`。改要留日期与依据。
3. **会话私有层**：本会话的判断、草稿、试错。默认不进文件，除非被证实并落到上面两层。
4. 跨项目长期决策 → 灵枢 `cg` 记忆（可检索）；本仓库文档不重复存。

## 七、交接覆盖写 + 快照

覆盖写前必须先存快照：`python tools/交接.py write`（总台）或项目内脚本先拷 `_交接/归档/交接-YYYYMMDD-HHMMSS.md`。
快照保留最近 10 份，多余的删最旧——**先存后写，写失败就回滚**。

## 八、这些规矩靠什么自动抓

`python -X utf8 _交接\_tools\一致性.py`（含 `--selftest` 自证 4/4，不许空转报绿灯）：

| 判据 | 抓什么 |
|---|---|
| C1 | §〇 缺 下一步 / 卡点小标题 |
| C2 | 索引指向不存在的文件（死条目） |
| C3 | §〇 超过 4096 字节 |
| C4 | 覆盖写前没快照 |

工具抓不到的（只认机主、修改权、投递回执）靠人守，别假装有机制。
