基于高斯过程与漂移扩散模型的混合建模方法
GP-SPE 实验设计优化项目
范式：Self-Matching Task (Sui et al., 2012)
工具：DDM + Gaussian Process + HDDM
DDM Gaussian Process SPE HDDM

核心研究问题

实验设计参数——练习次数 P、刺激呈现时间 T、反应窗口 W——如何系统性地调控自我优势效应（SPE）？

能否用高斯过程（GP）在 DDM 框架下建模这一调控机制，从而优化实验设计？

项目背景与动机

  • 背景 1：Self-Matching Task (Sui et al., 2012) 是测量自我优势效应的核心范式
  • 背景 2：现有研究多为"效应检验"模式，缺少对实验设计参数的系统优化
  • 背景 3：漂移扩散模型（DDM）可揭示 SPE 背后的认知过程
核心动机：从"效应检验"走向"设计空间建模与优化"

项目核心目标与预期成果

  • 目标 1：建立 Sigmoid（理论先验）+ GP（经验残差）混合生成模型
  • 目标 2：通过 HDDM 提取 8 组真实数据的 DDM 参数，校准模型
  • 目标 3：利用 GP 响应面预测 SPE，指导新实验设计
  • 目标 4：证明 GP+Sigmoid 模型在捕捉真实 SPE 上优于纯 Sigmoid 模型

预期成果：可解释的生成模型 + 优化后的实验设计方案 + 论文产出

理论基础
SMT Paradigm & DDM Framework

Self-Matching Task 实验范式

Sui, He & Humphreys (2012)

  • 学习阶段：circle ↔ self, square ↔ stranger（或反向平衡）
  • 测试阶段：看到 stimulus+label 对，按 f 或 j 键判断是否匹配

Matching = (circle, self) 或 (square, stranger)

NonMatching = (square, self) 或 (circle, stranger)

SPE 定义：SPE = RT(self, Matching) - RT(stranger, Matching)

本项目仅建模 Matching 条件

漂移扩散模型（DDM）

Ratcliff & McKoon (2008)

  • v（漂移率）：信息累积速度，反映任务难度/被试能力
  • a（边界分离）：决策谨慎度，a↑ → 慢但准确
  • z（起始点）：先验偏向
  • t0（非决策时间）：刺激编码 + 反应执行

本项目固定 s=0.1（HDDM 默认），z=a/2（无偏向假设）

DDM 参数与 SPE 的关系

SPEv = vself - vstranger > 0 → 自我信息累积更快

研究假设体系

  • H1：实验设计参数 (P, T, W) 通过调节 DDM 参数 (v, a) 系统性影响 SPE
  • H2：Sigmoid 函数可提供合理的理论先验，描述 (P,T,W) → (v,a) 的宏观趋势
  • H3：GP 能够捕捉 Sigmoid 无法解释的系统性残差，提升拟合精度
  • H4：基于 GP 响应面的不确定性估计可以指导最优实验设计

参数校准方法

差分进化算法 (Differential Evolution)

  • 校准对象：7 个参数 (alaph1/2, beta1/2, gamma, base_scale_v/a)
  • 目标：最小化 Sigmoid 预测 vs HDDM 真实参数的 RMSE
  • v9 扩展：11 参数 (含 T_0, k_T, M_0, k_a)

关键代码：sigmoid_calibration.py + run_cleaned_validation_pipeline.py

GP 残差层的构建与训练

  • 核函数：ConstantKernel × RBF + WhiteKernel
  • 输入 X：归一化的 (Pn, Tn, Wn)，8 条件 → [-1, 1]
  • 目标 Y_v：真实 v - Sigmoid 预测 v
  • 目标 Y_a：真实 a - Sigmoid 预测 a

对 5 个 DDM 参数各训练一个独立 GP
最终：DDMtrue ≈ Sigmoidpred + GPresidual

三层验证体系 + 行为验证结果

  • Layer 1：训练集拟合 (in-sample)
  • Layer 2：LOCV 留一条件交叉验证
  • Layer 3：行为层面 DDM 试次级模拟验证
