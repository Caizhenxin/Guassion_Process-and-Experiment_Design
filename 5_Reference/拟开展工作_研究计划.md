# 拟开展工作：自我优势效应的实验设计空间优化

## 一、方向与意义

本项目属于**认知心理学与计算建模**的交叉领域。现有自我优势效应（SPE）研究多为"效应检验"模式，仅验证 SPE 是否存在，缺乏对实验设计参数的系统优化。本项目创新性地提出**从"效应检验"走向"设计空间建模与优化"**的新范式，利用高斯过程（GP）代理漂移扩散模型（DDM）参数响应面，在连续实验设计空间 Ω=(P,T,W) 中预测和优化 SPE，解决传统研究对实验设计参数选择缺乏理论指导的核心瓶颈。

## 二、国内外概况

Self-Matching Task（Sui et al., 2012）是测量 SPE 的核心范式，DDM（Ratcliff & McKoon, 2008）已被广泛用于从行为数据反推潜在认知参数。然而，GP 在心理学实验设计优化中的应用尚处于起步阶段（Schulz et al., 2018），将 Sigmoid 理论先验与 GP 经验残差结合的混合建模方法国内外未见报道。本项目首次将 GP 残差捕捉、Sigmoid 理论约束与 DDM 认知建模三者整合，形成可解释的生成模型框架。

## 三、主要内容与技术路线

**核心内容**：构建 **Sigmoid（理论先验）+ GP（经验残差）** 的混合生成模型，揭示实验设计参数 (P,T,W) 对 SPE 的系统性调控机制。

**技术路线**：
1. 基于 8 组（88 名被试）真实 SMT 数据，使用 Docker HDDM 层级贝叶斯模型提取各条件 DDM 参数 (v,a,t0,z)
2. 以差分进化算法校准 Sigmoid 理论函数的 7-11 个参数，建立理论先验
3. 训练 GP 学习 Sigmoid 预测与真实 DDM 参数的残差
4. 通过留一条件交叉验证（LOCV）和行为层面 DDM 试次级模拟进行双重验证
5. 基于 GP 不确定性估计推荐候选实验设计点

## 四、最终成果与预期目标

- **软件**：GPSigmoidHybridModel 混合生成模型、SPE 交互式可视化分析平台（WebApp + R）
- **论文**：SCI/SSCI 心理学或计算建模期刊 1-2 篇
- **技术创新**：首次提出 Sigmoid+GP+DDM 三层混合架构，实现 Omission 截尾数据的 GP 残差建模
- **预期目标**：行为层面验证指标 r>0.8（当前 Correct RT r=0.981, SPE r=0.843），新实验条件的外部验证误差 <20ms

## 五、团队与科研条件

课题组拥有 88 名被试真实数据（8 组条件、26,616 试次），已建立完整的数据预处理、HDDM 拟合和 GP 建模管线。现有科研条件包括 Docker 化 HDDM 计算环境、Python/R 分析工具链、交互式可视化平台。项目代码已开源管理，RoadMap 覆盖 Phase 0-5 全流程规划，具备从数据采集到论文产出的完整支撑能力。
