# 第 3 章 研究一：实验设计空间对 SPE 的系统性调控——行为与 DDM 参数层检验

## 3.1 研究问题与预期

- RQ0a：八个设计单元（G1–G8）之间，行为层 SPE（SPE_RT、SPE_ACC）是否存在差异？
- RQ0b：P/T/W 的线性连续模型能否解释 SPE 的变异？（预期：不能——为非线性建模提供依据）
- RQ0c：主口径（G3–G8）下，DDM 漂移率层面的 SPE（SPE_v）是否随设计单元变化？其稳健性如何？

## 3.2 方法

### 3.2.1 被试与实验设计

88 名健康成年被试（每组 10–12 人，总计 8 组）完成 SMT。刺激为几何图形（方/圆）与身份标签（自我/陌生人），试次分匹配（Matching）与不匹配（NonMatching），反应有截止时限。8 组条件构成设计空间 Ω = (P, T, W)，各组人数、遗漏率与质量分档见表 3-1（⚠️【表 3-1】数据=冻结设计表；P0 组无练习试次，P>0 组含对应数量练习试次，正式试次每人 520 个 = 260 Matching + 260 NonMatching）。

⚠️【数据声明，置于脚注或 3.2.1 末】行为数据由课题组前期采集（MATLAB + Psychtoolbox），作者负责全部数据处理与建模；数据使用已获授权。

### 3.2.2 变量定义

- **行为指标**（正式试次、Matching 试次）：SPE_RT_ms = 正确试次下 Self 平均 RT − Stranger 平均 RT（个体水平）；SPE_ACC = Self 平均正确率 − Stranger 平均正确率，其中 omission 计为错误。
- **参数指标**：HDDM 层级拟合后被试级 SPE_v = v_self − v_stranger（个体后验均值）。
- **omission 口径**：正式试次中 RT 缺失/超窗，文中凡报遗漏率均注明口径（本报告以"全部正式试次"为准；Matching 口径数值见附录）。

### 3.2.3 分析计划

单因素方差分析（ANOVA）＋η²；JZS 贝叶斯因子（组别哑变量回归形式，r = 0.5 与 1.0，实现与验证见 Rouder et al., 2009, 2012）；G*Power 敏感性分析（80% 功效下可检测最小 f）；多元线性回归 SPE_v ~ P + T + W 及其 JZS BF。全部结果由冻结脚本产出（`Basic_Hypothesis/BF_freeze_20260902.py`、`ANOVA/run_spe_anova_freeze_20260902.py`），数字见锁定表 S01–S05。

## 3.3 结果

### 3.3.1 行为层面：SPE_RT 与 SPE_ACC

八个设计单元间 SPE_RT 存在显著差异，F(7, 80) = 2.792, p = .012, η² = .196；而 SPE_ACC 差异不显著，F(7, 80) = 1.489, p = .183（表 3-2）。主口径六单元下 SPE_RT 差异稳健，F(5, 59) = 3.096, p = .015, η² = .208。⚠️【表 3-2】含 8 单元与 6 单元两行 ANOVA 摘要。

单元格均值显示（表 3-3 ⚠️）：SPE_RT 的组间差异主要由**长时限、低遗漏**的设计单元贡献——G5（P8, T100, W1100）为 −47.9 ms、G6（P120, T500, W1500）为 −65.9 ms，而短时限的 P0_T30_W300 单元 SPE_RT 为 +4.3 ms（方向反转）。即：SPE 的 RT 表现随设计参数呈非单调、强条件依赖的模式。⚠️【图 3-1】SPE_RT 单元格箱线/点图。

### 3.3.2 DDM 参数层面：SPE_v 的主口径检验

主口径（G3–G8）下 SPE_v 的组间差异显著：F(5, 59) = 2.948, p = .019, η² = .200（表 3-4），JZS BF₁₀ = 2.83（r = 0.5）/ 3.29（r = 1.0），证据强度处于"轶事级—实质性"之间；G*Power 显示 80% 功效下可检测的最小效应 f = .465，观察效应 f = .500，安全边际很窄。**稳健子集检查（G5–G8）**：F(3, 40) = 0.975, p = .414，不显著（观察 f = .270 < 可检测 f_min = .523，功效不足）——该结果表明"设计空间对 SPE_v 的效应"主要体现在跨更宽参数范围的条件比较中，高质量子集内部差异被个体间噪声稀释，须诚实报告。

### 3.3.3 线性模型的检验

以 P、T、W 为连续预测变量的线性回归对 SPE_v 几乎无解释力（R² = .051, BF₁₀ = 0.73，指向 H₀），且系数方向不稳定。该负结果与 §3.3.1/3.3.2 的显著组间差异形成对照，说明 (P, T, W) 对 SPE 的作用**并非线性可加**，支持引入非线性映射（Sigmoid + GP，见第 5 章）。⚠️【写作提示】回归系数字段请补入正文/附表；并说明 G7 坐标已按冻结口径（T=30）校正，此前的 R²=.055 为旧标注产物。

## 3.4 讨论要点（待扩写）

1. 效应存在但证据边际（BF≈3、G*Power 刚过线）——解释为中等组间效应被大幅个体差异稀释（组内 SD ≫ 组间差异）。
2. SPE 主要出现在"足够知觉时间 + 充分练习/宽松窗口"的设计区；极短窗口导致反应僵化甚至方向反转——为实验设计提供直接的实践启示。
3. 线性失败 → 非线性建模必要性论证（衔接第 5 章）。
4. 稳健子集不显著的两种解读：效应依赖于宽参数范围 OR 功效不足——需在局限中讨论并关联"可选验证实验"（见总讨论）。

# 第 4 章 研究二：Omission 处理方法对 DDM 参数估计的系统影响

## 4.1 研究问题

RQ1a：在真实 SMT 数据上，Censor 与 Drop 两种 omission 处理方案得到的 DDM 参数是否存在系统性差异？差异量级如何随遗漏率变化？
RQ1b：是否存在可接受的遗漏率边界？（本数据为描述性探索）
RQ1c（初步）：自研省略概率网络（OPN）能否近似 "参数→omission 概率" 映射，为显式 omission 建模铺路？

## 4.2 方法

### 4.2.1 Censor vs Drop 系统对比
- 8 组 × 2 方案 = 16 次独立的 HDDM 层级拟合（Docker hcp4715/hddm；MCMC 3,000 draws / 500 burn-in）。
- **Censor**：omission 试次 rt = deadline（T+W）、response = 0，作为带错误编码的观测参与拟合（p_outlier = 0）。
- **Drop**：删除 omission 试次（p_outlier = 0.05）。
- 比较指标：各参数（v_self, v_stranger, SPE_v, a, t, z）两种方案差异 Δ、95% CI 是否重叠、Cohen's d。
- ⚠️【补跑项】收敛诊断（R-hat/ESS）待基于既有 trace 计算或重跑后回填。

⚠️【措辞更正（写作时务必执行）】"Censor"在本实现中指"将 omission 编码为截止时刻的错误反应参与拟合"，并非严格的右截尾似然；论文中采用此准确表述，并把严格截尾建模列为未来方向（HSSM/OPN 路线）。

### 4.2.2 自研 OPN（第一版）
- 仿真器：带 deadline 的 DDM 试次生成器（Euler–Maruyama；批量版见 `simulate_ddm_batch_vectorized`）。
- 训练数据：在参数空间与 deadline 网格采样 4,699 组 (v, a, t, z, deadline) → 由仿真统计 omission 比例作标签。
- 网络：MLP（128-64-32，sklearn），输出 omission 概率；数据标准化。
- ⚠️【注】本版为"快速（fast）模式"小样本概念验证；正式路线为复用 Leng et al. (2026) 官方 `ddm_opn.onnx` 接入 HSSM（见 4.4）。

## 4.3 结果

### 4.3.1 遗漏率与偏倚模式
各组遗漏率（正式试次口径）：G1 71.6%、G2 54.0%、G3 38.0%、G4 39.2%、G5 11.0%、G6 5.3%、G7 15.2%、G8 15.5%（表 4-1）。偏倚集中于 v 的绝对水平：如 G1 的 v_self 在 Censor（−4.86）与 Drop（+1.95）间相差 Δ = 6.81 且 95% CI 不重叠；**须注意该"符号反转"仅发生在 v 的绝对水平（v_self 与 v_stranger 同向），SPE_v 在两种方案下均接近 0，未发生方向反转**（表 4-2、图 4-1 ⚠️）。95% CI 在遗漏率约 >35% 时普遍不重叠、约 <15% 时普遍重叠；介于 15%–35% 之间无数据组，故该边界为**按 8 组事后归纳的描述性结论**，不作为统计阈值推广。

### 4.3.2 OPN 第一版
模型在训练/测试集上 R² = .990/.986（测试 MAE = .017），预测的 omission 概率与仿真真值高度一致（图 4-2 ⚠️：预测精度与边缘效应图）。该结果说明"以小网络近似 (θ, deadline)→omission 概率"在本项目仿真器中可行，为第 4.4 的正式 OPN 路线提供了概念验证。

## 4.4 讨论要点与展望

1. Leng et al. (2026) 的偏倚机制在**真实数据**上得到印证——丢弃 omission 对 v 的绝对水平影响强烈，且影响随遗漏率增大而加剧。
2. 数据清洗决策（G1/G2 排除、G3/G4 谨慎、G5–G8 核心）由此获得实证依据，支撑全文主口径。
3. 自研 OPN 仅为【初步】；**LAN+OPN 端到端建模为【展望】**：官方 OPN（`ddm_opn.onnx`，Leng et al., 2026 开源仓库 github.com/Jasonleng/opn）+ HSSM 0.4.0 集成已有另一项目 synthetic 参数恢复的可行性验证（见 `OPN_training_summary.md`；注意 angle_opn 存在 θ 梯度冲突问题，本项目只用 ddm_opn）。触发条件：若时间允许（2026-11 前），补 synthetic 恢复小节；否则作为 future direction，并明确说明因工具成熟度与条件数限制而未实施（段落模板见 `Omission_v2.md` §8.2）。

# 第 5 章 研究三：Sigmoid + 高斯过程的混合生成模型——参数预测与行为重建

## 5.1 研究问题与定位

RQ2：在六条件（G3–G8）上，(a) Sigmoid 理论映射能否经差分进化校准拟合真实 HDDM 参数？(b) 校准后的混合模型（Sigmoid + GP 残差）能否在行为层重建被试的 RT/ACC/omission/SPE？(c) GP 预测不确定性能否提供下一轮实验的候选点？
**定位声明**：行为重建为模型有效性的核心证据；参数层外推（LOCV）受限于 6 个设计点，其结果作为"需更多设计点"的结构性证据，而非模型失败；候选点仅为探索性输出。

## 5.2 方法

### 5.2.1 建模输入
主口径六条件（G3–G8）的 HDDM 群体后验均值（v_self、v_stranger、a、t、z），每个条件对应约 10–12 名被试、每身份约 1,300–1,560 个 Matching 试次（表 5-1 ⚠️，数值见表 S11）。

### 5.2.2 Sigmoid 参数化
- v(T, P, condition) = v_T(T) × v_P(P) × base_scale_v × (1 + 条件调制 α₁/α₂)，其中 v_T、v_P 均为 Sigmoid（拐点/陡度取心理物理固定值，T₀=100 ms 等）；
- a(M) = Sigmoid(M; M₀=600) × base_scale_a × (1 + 边界调制 β₁/β₂)，M = T + W；
- t 与 z 在 Sigmoid 层取训练条件均值基线（t₀ = 0.420, z₀ = 0.550，冻结口径值），由 GP 学习其残差。
- 差分进化（DE）联合优化 7 个自由参数（α₁, α₂, β₁, β₂, γ, base_scale_v, base_scale_a），目标为预测与真实参数的 RMSE；边界设置见代码（`sigmoid_calibration.py`）。

### 5.2.3 GP 残差层
对 v_self、v_stranger、a、t、z 各训练一个独立 GP（核：ConstantKernel × RBF + WhiteKernel），学习目标 = 真实 HDDM 参数 − Sigmoid 预测；最终预测 = Sigmoid + GP 残差。

### 5.2.4 验证策略
- in-sample：训练条件上的 RMSE 与 Pearson r；
- LOCV：Leave-One-Condition-Out（6 折，每折在 5 个条件上重训）；
- 行为验证：用预测参数做试次级 Euler–Maruyama DDM 模拟（dt = 2 ms，deadline 判 omission），在身份×条件与条件层面对比模拟与真实的 ACC、omission 率、正确 RT 均值与 SPE_RT；
- 候选点：25×25×25 (P,T,W) 网格上的 GP 预测不确定性 top-N，剔除靠近已有设计点的区域。
- 复现：`run_frozen6_20260902.py`（seed = 42），产物目录 `GP_Sigmoid_Frozen6/`（与旧 8 条件产物 `GP_Sigmoid_Cleaned/` 分开存放，避免混用）。

## 5.3 结果

### 5.3.1 Sigmoid 校准（表 5-2）
冻结版（6 条件）最优参数：α₁ = 0.862、α₂ = 0.142、β₁ = +0.328、β₂ = −0.518、γ = 0.614、base_scale_v = 1.126、base_scale_a = 1.293；拟合 RMSE = 1.090，DE 收敛。
⚠️【叙述要点（据冻结"叙述冲击"记录，重要）】早期基于含 G1/G2 的 8 条件版本曾报告 α₁≈0.20、β₁ 符号反转、base_scale_a 触上界等结果；这些结论在排除高遗漏组后**不再成立**，属低质量数据导致的伪影。冻结口径下：(1) β₁ 为正值（+0.33），方向与"时间压力→边界"假设 H3 一致；(2) base_scale_a 不再触界；(3) α₁ = 0.86 说明"自我相对增强"约为 +86%，仍低于初始默认假设（1.5 倍）——结果定位为**对理论参数的实证校准**。正文与讨论一律以冻结版为准。

### 5.3.2 参数层拟合与交叉验证
in-sample：v_self/v_stranger/z 的 r ≈ 1.00（插值拟合，仅说明 GP 能吸收残差），a 的 r = 0.36（RMSE 0.42）——边界参数的 Sigmoid 拟合较弱（表 5-3）。
LOCV（6 折）：v_self r = −0.03、v_stranger = −0.13、a = −0.29、t = −0.17、z = −0.06、SPE_v = +0.26；v_self RMSE = 1.59（表 5-4，图 5-1 ⚠️）。**参数层外推不成立**：6 个设计点不足以支撑 GP 泛化——这是设计空间建模的公认小样本困境，也是"需要更多设计点/独立验证数据"的结构性论据。

### 5.3.3 行为层重建（核心证据）
身份层（12 格）：正确 RT 均值 r = .967（RMSE 61.6 ms）、ACC r = .904（RMSE .155）、omission r = .580（RMSE .155）；条件层（6 格）：ACC r = .902、SPE_RT r = .845（RMSE 19.7 ms）（表 5-5、图 5-2 ⚠️）。
解读注意：(1) 相关性高主要由跨条件的大尺度趋势驱动，**必须同时报告 RMSE 与逐格偏差**（部分格子偏差可达 ±50–100 ms）；(2) 验证为 **in-sample**（在训练设计点上预测并模拟）；(3) omission 率相关在移除 G1/G2 后由 0.92 降至 0.58，反映短窗条件对 omission 相关的驱动作用——讨论中如实说明。

### 5.3.4 候选设计点（探索性）
top 候选集中于 T ≈ 480–500 ms、W ≈ 300–350 ms 区域（rank 1: P≈0–5, T=500, W=300, M=800；总不确定性 ≈3.26，主要来自 v 分量），但 top-20 不确定性几乎相同（第 3–4 位小数才分序）（表 5-6 ⚠️）。因此候选输出仅用于指示"当前数据覆盖最差的高不确定区域"，不作为对最优设计的强推荐；结合预期遗漏率/可行性准则的改进版推荐列于未来方向（RoadMap Phase 4 遗留）。

## 5.4 讨论要点（据冻结口径重写，待扩写）

1. 理论校准价值：排除低质量组后映射方向与假设一致（H1：练习提升 v；H3：时间压力降低 a），但幅度低于默认先验——Sigmoid 参数化是可检验的"理论仪器"，本研究给出其经验取值。
2. 行为重建成功 = Sigmoid 理论先验提供了超出纯数据拟合的约束力（即使参数层 GP 泛化失败，行为层仍可复现）；
3. 局限与改进：6 点小样本（LOCV 失败）、恒定边界 DDM（未含塌缩边界与跨试次变异）、行为验证 in-sample；改进路径 = 更多设计点 +（可选）独立验证实验（见总讨论 §7 与可选研究五）；
4. 候选点与实验设计的衔接：本研究同时给出"何处信息最少"的量化指引，供下一轮实验设计参考（配合预期遗漏率约束，短 W 需谨慎，因为 W=300 区间在真实数据中与高遗漏相关）。
