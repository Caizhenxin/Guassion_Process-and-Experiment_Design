数据预处理建议

Clean 数据已过滤变量，但仍需根据分析目标自行预处理

排除 RT < 100 ms 的抢按键反应与 RT > 3000 ms 的注意涣散试次

剔除整体 ACC 过低的被试

按研究问题选择 Matching / Nonmatching 或特定 Identity 试次

查看 Codebook 了解各变量编码细节

常见问题 FAQ

Clean 数据是否可直接用于分析？
建议先根据分析目标自行预处理，排除无效 RT/ACC。

不同实验变量名不一致怎么办？
Clean 数据中已统一标准化，变量名一致。

如何找到适合我的数据集？
使用 Dataset_inf.xlsx 按国家、刺激类型、样本等筛选。

能否在自己的论文中使用？
可以，需引用 SPE Database 论文 + 原始数据来源论文。
