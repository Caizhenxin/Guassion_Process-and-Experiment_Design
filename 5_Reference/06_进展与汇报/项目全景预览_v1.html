021. 研究问题与假设

1.1 三个层次的问题

  1. 现象层：自我相关刺激（自己的字形/名字）相对他人刺激，反应是否更快、更准？
  2. 机制层：这个优势来自证据积累速率（漂移 d 变大）、反应阈值（a 变小，即更急）还是非决策时间（t0 变短）？
  3. 调制层：练习量 P 与刺激呈现时长 T 如何改变上述机制？掩蔽出现后证据是否继续积累（ρ）？

1.2 假设与判定标准

假设内容判定
H1自我刺激的漂移更大（β_S > 0）β_S 的 95% 区间不含 0；同时报 a、t0 的对比（排除"只是更急"）
H2练习提高漂移（β_P > 0）组间回归 β_P 的区间不含 0，并报效应量
H3呈现越久漂移越大（β_T > 0）被试内 β_T 的区间不含 0
H4掩蔽后证据未完全消失（ρ > 0）ρ 的区间不含 0，且 ρ ≠ 1（ΔBIC、ΔELPD 同向）
写作纪律：H1–H4 都用区间表述，不用"显著/不显著"作结论。样本量不足时明确写"本研究的区间宽度为 ±X，因此只能排除大于 Y 的效应"。

043. 计算模型

3.0 一张图看懂模型

3.1 三层结构

任务层   P, T, W, 身份, 匹配
   │  映射方程（§3.3）
被试层   v(漂移) · a(边界) · z(起点) · t0(非决策时间) · ρ(掩蔽后保留率)
   │  群体分布 mu ± sigma
组层     βP(练习) · τP(练习饱和) · βS(自我)

3.2 证据积累：两阶段漂移（M-T1）

漂移在刺激呈现期内为 d，掩蔽出现后（t > T）降为 ρ·d：

式 1 · 两阶段漂移
d(t) = { dstim,  0 ≤ t ≤ T ρ · dstim,  t > T
ρ ∈ [0, 3]：掩蔽后证据保留率。ρ = 1 时退化为单阶段模型 M-T3。
  • ρ ∈ [0, 3]：掩蔽后证据保留率。ρ = 0 = 掩蔽后停止积累；ρ = 1 = 掩蔽无影响（退化为单阶段模型 M-T3）；ρ > 1 = 掩蔽后加速。
  • M-T3 是 M-T1 的严格嵌套特例，所以"掩蔽有没有影响"是一个参数的检验，不是两个模型的取舍。
  • 判别性预测：对 RT < T 的试次，M-T1 下整个积累都在刺激期内 ⇒ RT 分布与 T 无关；M-T3 下这些快反应也会随 T 变。这是设置 4 个 T 水平的真正理由。

3.3 映射方程

式 2 · 设计变量 → 漂移
dstim = dref + βP [ fP(P; τP) − fP(Pref; τP) ] + βT [ QT(T; τT) − QT(Tref; τT) ] + 𝟙self ( βS + βSP ΔfP + βST ΔQT )
三项分别是：练习 / 呈现时长 / 自我（他人条件时 𝟙 = 0）。
式 3 · 两个饱和函数
fP(P; τP) = 1 − e−P/τP      QT(X; τ) = 1 − e−X/τ
练习量与呈现时长都按指数饱和：收益递减，τ 越大饱和越慢。
式 4 · 边界与起点
a(W) = aref + Δa [ QT(W; τa) − QT(Wref; τa) ]      z = zratio · a
期限越长边界越宽（更保守）；起点居中（z_ratio = 0.5）。
  • 参考点：P_ref = 120（最高练习组）、T_ref = 100 ms、W_ref = 1200 ms。
  • 估计用线性形式（ΔQ_T = T − T_ref），生成用指数形式；两者通过设计层行为最小二乘对齐（最大残差 0.045）。

4.4 三条必须写进论文的结论

  1. β_T 是唯一硬约束（被试内漂移敏感度，靠人数平均）；β_P 在 P=32 与 P=120 的漂移差约 0.49，信噪比高。
  2. τ_P 不可估，原因是模型口径：漂移幅度取 max(·, 0)，P=0/8 的漂移被截到 0，只有 {32, 120} 两个水平与组层模型自洽，两点定不出曲线的饱和常数。
  3. β_ST 需要 2248 人/组：任何"自我优势随时长变化"的说法都必须来自新设计。

076. 证据阶梯（防"数字乱用"）

否决层（任一环不过，则后面的数字全部作废）：

测量可信 → 可计算 → 可辨识 → 设计可承载

加权层（互不替代，只能综合判断）：

可区分 → 可复现 → 可检验 → 可解释

三条纪律：

  1. 合成/模拟结果进方法章，不进结果章；
  2. LOO 闸门未过时，ΔELPD 只作流程验证；
  3. 参数显著 ≠ 参数可估。
