### 1.4 Censor 方案的技术表述修正

- "右截尾（Censor）"在现实现中**无真截尾似然**：omission 行只是 rt=deadline、response=0 的普通观测参与 HDDM。
- 论文表述建议：方案一"将 omission 编码为截止时刻的错误反应参与拟合（近似截尾）"；方案二"直接删除"。若想声称真截尾，需换支持截尾似然的工具（HSSM/LAN，即 OPN 路线）——这正好是未来方向。
- "G1 符号反转（Δ=6.81）"仅发生在 **v 的绝对值**，SPE_v≈0 未反转 → 正文表述限定为"v 的绝对水平被严重偏倚"，不要写"对自我优势方向给出相反结论"。
- "遗漏率 >35% 不可接受 / <15% 可靠"是**按 8 组事后归纳的描述性分档**（15–35% 间无数据），正文需如实说明并配 CI 重叠判据；建议补一个基于仿真的阈值检验（可选，加分）。

## 2. 大纲 v3 写作要点（确认口径后我来出 v3）

### 2.1 章节结构建议（方法学型，7 章）

1. 绪论：研究问题链 + "为什么需要设计空间建模"；**明确作者贡献声明**（数据复用声明放方法或附录）。
2. 文献综述：SMT/SPE、DDM、omission 问题、GP 与实验设计优化、SPE 数据库现状。
3. 研究一（基本效应与假设检验）：88 人行为 ANOVA/BF + HDDM 参数模式 + 内部 RT 窗口分析（注明为内部数据）。
4. 研究二（Omission 方法论）：Censor vs Drop 全套（已完成）+ OPN 第一版（fast 模式，注明小样本）+ LAN+OPN **作为方法与展望**（不得写成已完成；除非 2026-12 前在 HSSM 路线跑通端到端并并入）。
5. 研究三（GP+Sigmoid 混合生成模型）：校准结果→**对四条理论假设的实证检验**（alaph1≈0.2 说明 self 优势远小于假设、beta1 反号、参数贴边界→可辨识性讨论）+ 行为重建（带误差）+ LOCV 失败作为"需要新数据"的论证 + 候选设计推荐（探索性）。
6. 研究四（多源整合与机制探索）：SPE 数据库（**实际样本量**）+ Mismatch/呈现时间关系的可复现分析 + CRF/Stim-Coding 机制探索 + 逆向推断**可行性分析**（无数值验证则不写"结果"）。
7. 总讨论：理论贡献收敛为"理论引导+数据校准的混合建模框架 + 真实数据方法学证据 + 设计空间基础设施"；局限（样本量、GP 外推、非本人数据、模型形式）。

## 3. 外部验证写作口径（v3 起执行）

1. **样本量如实报告**：本地 SPE 库实物为 63 个数据集 / 约 34 个首作者-年份 / 按文件求和约 3,327 人 / 约 99 万行（含 4.5% 重复键与脏 RT）。文中写"用于本文分析的数据集 N=x、被试 y 人、试次 z"，不要照抄"44 篇/70 数据集/3603 人/155 万+"（那是数据库全量自述）。如确用全量，需先补数据与清洗。
2. **透明声明**：SPE 库为本人所在课题组在研基础设施（Cai et al. 2026 in prep），在正文/致谢中声明作者角色与使用许可；注意与数据描述论文、Hu 组预注册元分析（OSF euqmf）划清边界。
3. **方向矛盾的处置**：内部数据（长刺激/长窗口 SPE 更强）与 v15.3（呈现时间越长 SPE 越小，ρ≈-.49）方向相反 → 论文中必须专门讨论（范式差异：有无 deadline、练习量、身份标签数、SPE 指标 RT vs ACC、操作化差异），把矛盾转化为"设计参数影响的边界条件"讨论，而不是回避。
4. **RT 0.3–0.8s 最强**：目前只有内部 88 人滑动窗口证据（`Visualization/V4/SPE_reaction_window_analysis_20250608.md`）。要么在文中明确是内部发现（放在研究一/研究四内部部分），要么用 SPE 库补做等价分析后才能称跨研究。
5. **可复现性**：v15.3 中 Mismatch/呈现时间两节目前只有文本+图、无代码结果文件；写进论文前请从 `4_Reports/Reference/SPE/SPE_Database/` 补齐分析脚本并本地跑通（或从数据库上游仓库获取）。v15.3 Table 1 存在重复行，引用前需核对版本。
