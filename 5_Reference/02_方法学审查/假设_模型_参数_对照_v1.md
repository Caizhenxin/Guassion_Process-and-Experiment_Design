## 0. 结论速览（先看这六条）

1. **三层是严格对应的**：每条心理假设都必须落到**一个具名参数**上，每个参数都必须能回答「若它变了，行为会怎样变」。落不到参数上的假设，在本项目里不算可检验假设。
2. **主检验只有两条**：`β_P`（练习 → 漂移，**组间**）与 `β_T`（呈现时长 → 漂移，**被试内**）。其余参数分三类：能估并报告（`d_ref`/`a_ref`/`t0`/`ρ`/**`Δz_S`**）、只能报方向（`β_S`/`τ_T`）、**结构上不可估**（`β_ST`/`Δa`/`τ_a`/`τ_P`/`β_SP`）。
3. **自我优势（SPE）有两个具名落点**：`β_S`（漂移 / 证据质量，`Δd′` 方向）与 **`Δz_S`（起点 / 判据，`Δc` 方向）**。这是主模型；「落在边界 / 非决策时间 / 加工速率上」仍是**竞争假设**，靠 **ΔRT 五分位斜率**判别，不靠中位差。加 `Δz_S` 的依据是实测 SDT 拆解：`Δd′ = +0.410` 的同时 `Δc = −0.239`（纯漂移通道预测 `Δc = 0`），见 `5_Reference/03_论文写作/论文_模型章_模板.md` §3.15。
4. **「掩蔽是否截断证据」由 `ρ` 承载**（M-T1 vs M-T3）。`ρ = 1` 时 M-T1 严格退化为 M-T3，所以这是一次嵌套比较，不是两套理论对撞。
5. **参数显著 ≠ 参数可估**。`β_ST` 要 **2248 人/组**、`Δa` 658、`τ_a` 1307、`λ`（40 人/组时 SE 0.162）——这些在本设计下只能进「限制」与「讨论」，不能进主结论。
6. **两套真值不要混用**：`GEN_TRUTH`（生成数据用，lin 形式，四档练习漂移全为正）**不是**论文的最终真值假设；论文的样本量论证用 `TRUTH_EXP` 的解析 CRLB。

## 1. 假设层：这个实验想说什么

### 1.1 自变量：五个操纵，576 试次/人

| 操纵 | 符号 | 水平 | 变异位置 | 它想代表的心理量 |
|---|---|---|---|---|
| 练习量 | `P` | 0 / 8 / 32 / 120 次 | **组间**（4 组被试各一档） | 记忆强度 / 联结巩固 |
| 刺激呈现时长 | `T` | 33.3 / 83.3 / 150 / 250 ms | 被试内（4 档） | 感觉编码深度 / 信息质量 |
| 反应期限 | `W` | 800 / 1200 / 1800 ms | 被试内（3 档） | 时间压力 / 决策动机 |
| 身份 | — | 自我 / 他人 | 被试内（平衡） | 自我参照加工 |
| 匹配性 | — | 匹配 / 不匹配 | 被试内（平衡） | 正确侧（上/下边界） |
| 重复 | — | 每单元 12 次 | — | 估计噪声 |

设计规模：`4 T × 3 W × 2 身份 × 2 匹配 × 12 重复 = 576 试次/人`。`P` 是**组间**维度，所以「练习效应」永远不能在单个被试内部被检验。

### 1.2 六条假设（H1–H6）与它们各自的竞争假设

| 编号 | 命题（一句话） | 心理过程 | 模型落点 | 方向预期 | 竞争假设 | 本设计能否检验 |
|---|---|---|---|---|---|---|
| **H1** | 练习越多，证据积累越快 | 记忆提取效率上升 | `β_P`（组间）→ 漂移 | `β_P > 0` | 练习只改策略/注意，不动漂移 | ✅ 主检验 |
| **H2** | 呈现越久，证据质量越高 | 编码深度→信噪比 | `β_T`（被试内）→ 漂移 | `β_T > 0` | T 只是「多给了一段可用时间」，不改漂移 | ✅ 主检验 |
| **H3** | 期限越长，反应阈值越高 | 时间压力↓ → 更审慎 | `Δa`（被试内）→ 边界 | `Δa > 0`（更慢更准） | 边界不随 W 变（`W0` 模型） | ⚠️ 方向可看，**幅度不可估** |
| **H4** | 自我条件下的优势落在**漂移**上（**并可同时落在起点上**） | 自我参照提升证据质量（并可能放宽判据） | `β_S`（漂移/`Δd′`）+ **`Δz_S`（起点/`Δc`）**（+`β_SP`/`β_ST` 交互） | `β_S > 0` 且更快更准；`Δz_S > 0` 且 `c` 更负 | 优势只落在边界 / `t0` / 加工速率上，或 `Δc = 0`（纯漂移） | ✅ 两条通道都可估（`Δz_S` 相对 SE 12.5%），机制仍靠分位斜率 |
| **H5** | 掩蔽**截断**了证据积累 | 感觉输入撤走后证据衰减 | `ρ`（M-T1 特有） | `ρ < 1` | 掩蔽无影响（`ρ = 1`，即 M-T3） | ✅ 组层 `ΣLRT` 双侧 |
| **H6** | 练习/时长的曲线是**饱和**的 | 收益递减 | `τ_P`、`τ_T`（+`lin` vs `exp` 形式） | `τ > 0` 有限 | 线性、无饱和 | ❌ `τ_P` 结构不可估、`τ_T` 需 169 人/组 |

> **与旧《毕业论文大纲 v3》的编号对照**：大纲的 H1=P→v、H2=T→v、H3=M(T+W)→a、H4=Sigmoid 形式，分别对应该表的 H1、H2、H3（但自变量已按 D48 从 `M=T+W` 改为 **`W`**）、H6。H4（自我）与 H5（`ρ`）是在大纲之后新增的两条——它们才是本项目的**核心命题**。

### 1.3 假设之间的依赖：一荣不俱荣，一损会俱损

```
H5 (ρ, 机制)  ─┐
H2 (β_T)      ─┼─→ 都以「漂移是主要载体」为前提 ─→ H1 (β_P)、H4 (β_S) 的解释才成立
H3 (Δa)       ─┘
```

- **共同前提**：决策由「噪声累积 + 阈值」产生。若实测显示效应是**均匀平移**（RT 整体移、正确率不动），则载体不是漂移而是 `t0`，H1/H2/H4 的**解释**要整体改判（模型不必推翻，参数归属要改）。
- **最脆的一环是 H3**：`Δa` 的解析 CRLB 已判死（658 人/组），所以「时间压力」这条线在本设计里只能以 **`W0` vs `W1` 的模型比较 + 遗漏率-正确率联合形态**来谈，不能报斜率。
- **H4 与 H1 共享同一通道**：若 SPE 落在漂移上，练习把漂移抬高时 SPE 的**绝对量**会自然变化（分母变小），所以「SPE 是否随练习收缩」不能只读毫秒差，必须区分「机制型收缩」与「尺度型收缩」（见 §3.3 的 8 支候选）。

## 2. 模型层：假设怎么变成可计算的东西

### 2.1 四层结构

| 层 | 内容 | 载体 |
|---|---|---|
| **设计层** | `P, T, W, 身份, 匹配` 逐试次取值 | `gen_model_data.build_design` |
| **映射层** | 设计变量 → DDM 参数 `v, a, z, t0` | `mapping.trial_params` |
| **决策层** | 随机过程：漂移扩散 + 阈值 + 两阶段 | `twophase.py`（M-T1/M-T3）、`ramp.py`（M-T2） |
| **统计层** | 被试层参数 `θ_i`、群体分布 `N(mu, σ²)`、组间参数 | `hier.py`、`recover_group.py` |

### 2.2 决策过程的三个版本

| 模型 | 漂移的时间结构 | 似然 | 角色 |
|---|---|---|---|
| **M-T1**（主模型） | 刺激期 `d_stim`；掩蔽后 `ρ · d_stim` | ✅ 闭式（`wfpt` 两段拼接） | 可拟合、可比较 |
| **M-T2** | 刺激期 `d_stim · (1 − e^{−t/τ_T})` 逐步爬升；掩蔽后 `× ρ` | ❌ **无似然** | **只用于生成**，不能拟合、不进比较表 |
| **M-T3** | 全程 `d_stim`（`ρ = 1`） | ✅ | M-T1 的**严格嵌套特例** |

**为什么必须两阶段**：若把 `T` 直接当成漂移的调节量（单阶段），那么对 `RT < T` 的试次，`T` 也在改变漂移。两阶段下，这些试次的整个积累都发生在刺激期内，`T` 只通过 `d_stim(T)` 起作用而非通过「衰减」。这就是 **576 试次里 4 档 `T`** 的价值：用「刺激期内就完成的反应」去分离「时长改变了漂移」与「时长只决定积累能用多久」。

> ⚠️ **实测提醒**：本设计（`t0 ≈ 220 ms`、`T ≤ 250 ms`）在模拟中 `P(RT < T) = 0.0000`，而 `P(τ < T) = 0.052`。也就是说，**「RT < T 的试次」这条判别线在真实时间轴上几乎不存在**——判别必须走 `ρ` 的组层检验，不能指望"切出一个子样本"。

### 2.3 映射方程（`mapping.py`，现行 `lin` 形式）

```
(1)  f_P(P; τ_P) = 1 − e^(−P/τ_P)                练习饱和：P=0 → 0，P→∞ → 1

(2)  d_stim = d_ref                                        ← 参考点处的漂移幅度
            + β_P · [ f_P(P) − f_P(P_ref) ]                ← 练习（组间）
            + β_T · [ T − T_ref ]                          ← 呈现时长（lin：无时标）
            + 1_self · ( β_S + β_SP·Δf_P + β_ST·ΔQ_T )     ← 身份：加性偏移
            ，最后取 max(d_stim, 1e-6)

(3)  a(W) = a_ref + Δa · [ W − W_ref ]        （W1）      ← 期限 → 边界
     a(W) = a_ref                              （W0）      ← 固定边界对照

(4)  v = +d_stim（匹配试次，正确答案=上边界）  /  −d_stim（不匹配试次）
     z = ( z_ratio + 1_self · Δz_S ) · a   （起点；`z_ratio` 固定 0.5 不估，`Δz_S` 自由，判据通道）
     RT = τ + t0                （τ = 首次通过时刻，t0 = 非决策时间）

(5)  观测：RT ≤ W 记为响应；RT > W 或未吸收记为**遗漏**（不建 lapse 参数）
```

三个关键选择，每个都是踩过坑之后定下的：

| 选择 | 备选 | 为什么不选备选 |
|---|---|---|
| **加法**叠加 `d_ref + β_P·Δf_P + β_T·ΔQ_T` | 乘法 `v_P × v_T × (1+α)` | 乘法所有分量 ∈ (0,1)，**造不出负漂移**（实测 `v_base` 从 −1.81 到 +2.68）；且似然里只有比值进入，`α` 与基准尺度**不可识别**（旧口径 α₁ 在 1.5→0.199→0.862→0.153 间乱跳就是这个原因） |
| **参考点锚定**（`P_ref/T_ref/W_ref` 取域内值） | 截距写成 `d0`（T→0）与 `A_min`（W→0） | 数据从不接近 T=0 / W=0，截距是**纯外推**，MLE 会推上边界并带偏别人（实测 `d0` 估 0.05 vs 真值 0.80、`A_min` 估 0.30 vs 0.90） |
| **`lin` 形状估计**（`ΔQ_T = T − T_ref`） | `exp` 形状（自由 `τ_T`/`τ_a`） | `τ_T`、`τ_a` 在本设计上不可识别；两套形式用 `match_lin_to_exp` 做**设计层行为最小二乘对齐**（最大残差 0.045，`d` 跨度 0.262 vs 0.277） |

### 2.4 观测层口径（容易错，必须写进方法章）

| 量 | 现行口径（v4.1） | 注意 |
|---|---|---|
| `RT` 起点 | **刺激 onset** | 不是掩蔽结束 |
| 反应窗口 | **自 onset 全程采集** | 刺激期内按键也有效（实际呈现时长 = min(T, RT)） |
| 期限 | `deadline = onset + W` | **不是** `T + W`（那是 v2 口径，见 D48） |
| 似然里的时间 | `t = RT − t0`，`t_max = W − t0` | 与 `likelihood.py` / `twophase.py` 一致 |
| 遗漏 | `RT > W` 或未吸收 | 不建 lapse 参数（三次否证） |

> ❗ **历史教训**：`AutoRA_SPE/spe_design_model.py` 编码的是 v2 口径（`deadline = T+W`、窗口在 `T+200` 才开），与 v4.1 相差恰好 `T + 200 ms`；同一对数字在 D4 网格上 deadline 相对误差 **1.85%–31.25%**，且**固定 W 时随 T 严格单调** ⇒ 纯口径错误会伪装成 **T 的主效应**。换算一律走 `1_Code/AutoRA_SPE/spe_timing_convention.py`，不得跨代套用 W 数值。

### 2.5 统计层：谁在哪里被估

| 参数类别 | 估计方式 | 代码 | 要点 |
|---|---|---|---|
| 被试层 `θ_i`（7 个 + `ρ`） | 经验贝叶斯 MAP + 拉普拉斯近似，L-BFGS-B 求众数 | `hier.hier_fit`（EM 12 轮） | 零第三方依赖；`n_x = 31/41` 是似然网格分辨率 |
| 群体超参 `mu`、`σ` | 拉普拉斯-EM 交替更新 | `hier.hier_fit` | 先验：`mu ~ N(0, 2²)`（无约束坐标）、`log σ ~ N(log 0.5, 1²)`、`σ` 下限 `1e-3` |
| 组间 `β_P, τ_P, β_SP` | **两步法**：先用被试层 `d_ref`、`β_S` 的估计做加权非线性最小二乘（两条方程共用 `τ_P`） | `recover_group.fit_between` | ❗ `mapping.BETWEEN_FREE` 里的 `β_P/τ_P/β_SP` **不进入 `hier` 的 `theta`**（D100 机制更正），所以它们没有后验区间，只有回归区间 |
| 模型比较 | PSIS-LOO（`k̂`、`p_loo`、超参 Hessian 三道闸门）+ ΔBIC + 嵌套似然比 | `loo.py`、`twophase.bic` | LOO 闸门未过时 ΔELPD **只作流程验证**，不作结论 |

**为什么是两步法而不是联合估计**：`P` 只有 4 个水平且是**组间**的，把它塞进被试层 `theta` 会让每个被试独自去估一个他根本没有的维度（每人在单一 `P` 下只有一套参数）——`d_ref` 与 `β_P·f_P(P)` 在单个被试内部完全共线。所以「练习效应」只能在**组这一层**从 4 个组的均值里回归出来。代价是：`β_P` 的不确定性只反映组均值回归的误差，不含被试层参数估计误差的传播（写作时必须作为限制说明）。

### 2.6 模型比较能问什么、不能问什么

| 比较 | 判据 | 能得到的结论 | 不能得到的结论 |
|---|---|---|---|
| M-T1 vs M-T3 | `ρ` 的组层 `ΣLRT`（双侧，阈值 43.773）；ΔBIC | 掩蔽是否打断证据积累 | ❌「两阶段模型为真」 |
| 有 `β_T` vs 无 | ΔBIC | 时长是否改变漂移（而非只改可用时间） | ❌「T 只作用于漂移」 |
| `W0` vs `W1` | ΔBIC / ΔELPD | 期限是否改变边界 | ❌ 边界斜率的数值（不可估） |
| 有 `β_S` vs 无 | ΔBIC | SPE 是否体现在漂移上 | ❌「SPE 只在漂移上」（分位斜率才能说） |

> `ρ` 的检验力（`check_rho_power.py`，n=30/档）：`ρ=0/0.5/0.75` 的逐被试拒绝率 96.7% / 40.0% / 16.7%，但组层 `ΣLRT` 为 473.1 / 151.9 / 57.50（阈值 43.773）⇒ **双侧可写，且必须报组层**；标定行干净（`ρ=1` 时 3.3% 拒绝）。

## 3. 参数层：一个一个说清楚

### 3.1 总表（论文正文直接可用）

**被试层（每个被试一套；`lin` 形式 8 个，M-T1 加 `ρ` = 9 个）**

| 符号 | 数学位置 | 含义 | 单位 | 方向约定 | 生成真值 `GEN_TRUTH` | 是否估计 | 可估性 | 承载假设 |
|---|---|---|---|---|---|---|---|---|
| `d_ref` | 式(2) 截距 | 参考条件（`P=30, T=100 ms`）的漂移幅度 | drift | 正 = 证据更强 | 0.80 | ✅ | ✅ 3 人/组即 <10% | H1/H2/H4 的共同基线 |
| `β_T` | 式(2) `ΔT` 斜率 | 呈现每多 1 s，漂移增加多少 | drift/s | 正 = 越久越准 | 0.95 | ✅ | ✅ 主检验；41 人/组到 10% | **H2** |
| `β_S` | 式(2) `1_self` | 自我相对他人的漂移加性偏移 | drift | 正 = 自我更准 | 0.30 | ✅ | ⚠️ 51 人/组到 10% | **H4** |
| `β_ST` | 式(2) `1_self·ΔT` | 自我优势随呈现时长变化 | drift/s | 正 = 时长放大 SPE | 0.12 | ✅（形式如此） | ❌ **2248 人/组** | H4 的交互（**不可估**） |
| `Δz_S` | 式(4) `1_self·a` | 自我相对他人把起点向「匹配」边界推移多少（`z/a` 的偏移） | 无量纲（占 `a` 的比例） | 正 = 更倾向按匹配键 ⇒ SDT `c` 更负 | **0（`GEN_TRUTH` 未设，故生成数据可当“无误报”检验）** | ✅ | ✅ **相对 SE 12.5%**；`corr(β_S, Δz_S)=+0.12` | **H4 的判据通道**（§3.15） |
| `a_ref` | 式(3) 截距 | 参考期限（`W=1200 ms`）处的边界间距 | — | 大 = 更慢更准 | 1.52 | ✅ | ✅ 1 人即 <10% | H3 的基线 |
| `Δa` | 式(3) `ΔW` 斜率 | 期限每多 1 s，边界升高多少 | 1/s | 正 = 压力小→阈值高 | 0.30 | ✅（形式如此） | ❌ **658 人/组** | **H3**（只能谈方向/模型比较） |
| `t0` | `RT = τ + t0` | 非决策时间（编码+运动） | s | — | 0.19 | ✅ | ✅ 1 人即 <10% | 所有假设的**竞争落点** |
| `ρ` | 掩蔽后 `ρ·d_stim` | 证据保留率（M-T1 特有） | — | `<1` = 截断；`=1` = 无影响 | 0.8（`M-T1/2`） | ✅（仅 M-T1） | ✅ 组层可判 | **H5** |
| `τ_T` | 式(2) 的 `exp` 版 | 时长饱和常数 | s | 越小越早饱和 | 0.080（exp 用） | 仅 `exp` 形式 | ⚠️ **169 人/组** | H6（**探索性**） |
| `τ_a` | 式(3) 的 `exp` 版 | 期限饱和常数 | s | 同上 | 0.70（exp 用） | 仅 `exp` 形式 | ❌ **1307 人/组** | H6（**不可估**） |

> `lin` 形式下 `τ_T`/`τ_a` **不存在**（`WITHIN_FREE_LIN` 只有 8 个）；`exp` 形式下才有（`WITHIN_FREE` 10 个）。当前的估计与生成**默认 `lin`**。
>
> **`Δz_S` 加入之后（2026-10）**：`z = (0.5 + 1_self·Δz_S)·a`，`z_ratio = 0.5` 仍固定、只有自我偏移自由（否则与 `z_ratio` 公共平移、不可识别）。`Δz_S = 0` 时逐位退化为旧的 `z = 0.5·a`，所以此前所有拟合与产物仍然有效。「有/无 `Δz_S`」用 `hier_fit(..., free=[…])` 的子集做嵌套比较，不需要模型开关。立项依据、方向约定、量级换算与恢复结果见 `5_Reference/03_论文写作/论文_模型章_模板.md` §3.15。

**不参与估计的设计常数**

| 常数 | 值 | 作用 | 为什么固定 |
|---|---|---|---|
| `P_ref` | 30 次（`GEN_TRUTH`）/ 120（CRLB 口径） | 练习参考点 | 必须是域内值，否则截距外推（见 §2.3） |
| `T_ref` | 100 ms | 时长参考点 | 同上 |
| `W_ref` | 1200 ms | 期限参考点 | 同上 |

| `dt` | 5e-5 s | Euler 步长 | 已标定：`dt=2e-4` 时正确率偏差 0.0174，`5e-5` 时 0.0022（6 s/被试） |

### 3.2 三个最重要的读法

1. **看 `β_T` 的单位**：`lin` 形式下它是「drift / 秒」。本设计 `T` 从 0.033 到 0.25 s，跨度 0.217 s，所以 `β_T = 0.95` 意味着**最长与最短呈现之差约 0.21 个 drift 单位**——这才是「T 效应有多大」的正确读法，不是 0.95 本身。
2. **`β_S` 要和 `d_ref` 一起读**：`β_S = 0.30` 在 `d_ref = 0.80` 上等于 **+37% 的相对漂移增益**。绝对量 0.30 没有意义（旧口径「+15%」的错误就在于把不可识别的基准尺度当成了分母）。
3. **`ρ` 不是「记忆衰减率」**：它是**掩蔽后证据积累的保留比例**，作用在**漂移**上、不作用在已积累的证据上。`ρ = 0.8` 的含义是「掩蔽后的积累速度是刺激期的 80%」，不是「忘了 20%」。

### 3.3 两套真值，不要混用

| 用途 | 变量 | 形式 | 关键值 | 谁在用 |
|---|---|---|---|---|
| **生成数据 / 可视化** | `GEN_TRUTH` | `lin` | `d_ref=0.80, β_P=0.35, τ_P=30, β_T=0.95, β_S=0.30, β_ST=0.12, a_ref=1.52, Δa=0.30, t0=0.19` | `gen_model_data.generate`、`gen_viz`、`stage8` 的合成自测 |
| **样本量 / 可辨识性论证** | `TRUTH_EXP` | `exp` | `d_ref=0.70, β_T=0.55, β_S=0.16, β_ST=0.10, a_ref=2.00, Δa=0.55, τ_T=0.08, τ_a=0.70, t0=0.22` | 模型章 §3.8 的解析 CRLB、`design_frontier` |

> **为什么会有两套**：`TRUTH_EXP`（以 `P_ref=120`、`β_P=1.5` 为锚）在 `P=0/8/32` 处把漂移**截断到 0**（`max(·, 1e-6)`），用它生成数据会得到三组零漂移被试（正确率 0.50、无 T 效应），既不可视化也不可检。所以生成数据另用一套「四档漂移都为正」的中段参数（D109），**它只保证行为量级像这个范式，不代表论文的最终真值**。

## 4. 对照矩阵：假设 → 参数 → 判据（本文档的核心）

| 假设 | 承载参数 | 期望符号 | 检验统计量 | 数据要满足什么 | 通过后能说什么 | **不能**说什么 |
|---|---|---|---|---|---|---|
| **H1** 练习 | `β_P` | `> 0` | 两步法组间回归的 95% 区间（4 组 × 每组 10–15 人） | 各组 `d_ref` 估计先要稳（`d_ref` 3 人/组即 <10%） | 「练习提高了漂移率，区间为 …」 | ❌「练习通过记忆改善了证据质量」（`β_P` 只说明漂移变了，不说明中介） |
| **H2** 时长 | `β_T`（+ `W0/W1` 对比做隔离） | `> 0` | 层级拟合的组均值区间 + ΔBIC（有/无 `β_T`） | 组层样本 ≥ 41 人/组才到 10%；10–15 人/组折算后 ±30% | 「时长改变了漂移，且方向为正」 | ❌「T 只作用于漂移」（`β_T` 与被 `T` 吸收进 `t0` 的可能是混淆关系，见下） |
| **H3** 期限 | `Δa` | `> 0` | `W0` vs `W1` 的 ΔBIC/ΔELPD + 遗漏率-正确率的**联合形态** | 边界效应的方向必须与遗漏率、正确率同时一致 | 「边界随期限变化的方向与模型一致」（**方向级**） | ❌「边界斜率为 0.30」（658 人/组才可估） |
| **H4** 自我 | `β_S`（漂移）+ **`Δz_S`（起点）**（交互 `β_SP/β_ST` 为扩展） | `β_S > 0`；`Δz_S > 0`（⇒ `c` 更负） | `β_S`/`Δz_S` 各自区间 + **Δd′ 与 Δc 的模型隐含值** + **ΔRT 五分位差** + ΔBIC（有/无） | 更快**且**更准（`β_S`）；判据右移（`Δz_S`）；分位斜率 ~23 ms（漂移型） | 「自我优势体现在漂移上（区间 …），并伴随判据右移（`Δz_S` 区间 …）」 | ❌「SPE 只在漂移上」（除非 `Δz_S` 区间含 0 **且**分位斜率排除了速率型） |
| **H5** 掩蔽 | `ρ` | `< 1`（双侧检验） | 组层 `ΣLRT`（阈值 43.773）+ ΔBIC | 必须报**组层**（逐被试对 `ρ=0.75` 只有 16.7% 拒绝率） | 「掩蔽打断了证据积累，`ρ̂` 区间为 …」 | ❌「两阶段模型为真」（这是机制检验，不是模型确证） |
| **H6** 饱和 | `τ_P`、`τ_T` | 有限正值 | 仅作探索性报告 | `τ_P` 结构不可估；`τ_T` 需 169 人/组 | 「未观察到与线性形式显著偏离的饱和迹象」 | ❌「练习曲线是饱和的」 |

**H4 的机制判别规则（`spe_locus`，模拟读数）**：同样的 SPE 中位差，四种落点的 **ΔRT 五分位斜率**完全不同——

| 落点 | 机制 | ΔRT 分位斜率 |
|---|---|---|
| 漂移 | 证据质量 | **≈ 23 ms** |
| 加工速率 | 单位时间采样数 | ≈ 6 ms |
| 边界 | 阈值 | **≈ 73 ms** |
| `t0` | 非决策时间 | ≈ 0 ms |

> 所以结果章必须**强制报 ΔRT 的五分位差**，只用中位差无法区分漂移型与速率型（两者中位差几乎相同）。这是 D117 之后写进模型章 §3.14 的判别条件。

**H4 的第二套判别（SDT，与分位斜率正交）**：分位斜率区分**漂移 vs 速率 vs 边界 vs `t0`**；SDT 的两个数区分**证据积累（`d′`）vs 判据（`c`）**。实测参考：自我 `H=0.834/FA=0.318`、他人 `H=0.701/FA=0.306` ⇒ `Δd′ = +0.410`、`Δc = −0.239`；纯漂移通道预测 `Δc = 0`，故必须加 `Δz_S`。两套判别要一起报：分位斜率说“落在哪个机制”，`(Δd′, Δc)` 说“落在这个机制的哪个参数上”。

**H4 能不能显著区分 Self / Other（嵌套 LRT，`_scratch/check_dz_S_power.py`，10 人/组 × 576 试次）**

| 场景 | `β_S` 检验 `χ²(1)` | `Δz_S` 检验 `χ²(1)` | 逐被试拒绝率（`β_S`/`Δz_S`） |
|---|---|---|---|
| 双通道（`β_S=0.19, Δz_S=0.085`） | ΣLR 39.6，`p = 2×10⁻⁵` | ΣLR 363.5，`p = 6×10⁻⁷²` | 30% / 80% |
| 纯漂移（`Δz_S≡0`） | ΣLR 39.7，`p = 2×10⁻⁵` | ΣLR 6.4，`p = .78` | 20% / **0%** |
| 纯判据（`β_S≡0`） | ΣLR 6.9，`p = .73` | ΣLR 519.9，`p = 2×10⁻¹⁰⁵` | **0%** / 80% |

> 三条读法：① 两条通道**互不冒名**（假阳性率 0%）；② `Δz_S` 的检验力比 `β_S` 强一个量级，
> 10 人/组就能答「有没有 SPE」，但要答「漂移分量多大」仍需 §3.8 的 51 人/组；
> ③ **显著 ≠ 可定量**——`β_S` 组层 `p = 2×10⁻⁵` 与相对 SE 75% 同时成立。详见模型章 §3.15.5。

## 5. 五个最常见的误读（写作纪律，随结果一起写）

1. **把 `β_P` 当被试内效应**。它来自 4 个**不同人组**的均值回归，个体内部没有 `P` 的变化。任何「某个被试练习后变快」的表述都是错的。
2. **把「参数显著」当「参数可估」**。显著只说明区间不含 0，不说明区间窄到能做定量陈述。`β_ST`、`Δa`、`τ_a`、`τ_P` 都属于「算得出一个数、但这个数没有信息量」。
3. **把 `ρ ≠ 1` 写成「证明了双阶段模型」**。它证明的是「掩蔽确实改变了积累」，不是「模型结构正确」。
4. **把模拟数字写成结果**。合成/模拟的读数（`λ` 族、8 支候选、设计前沿）只能进**方法章 / 识别性与功效章**，不得进结果章。
5. **把 λ 家族当主模型**。`λ`（自我优势的天花板）是**讨论章的扩展**，与主模型严格嵌套（`λ=1` ⇔ `β_SP=0`），不参与模型比较表。40 人/组时 `SE(λ) = 0.162`：**够做方向检验，不够区分 0.5 与 0.75**。

## 6. 从数据到结论：六步与每步的产物

| 步 | 做什么 | 关键产物 | 判据 / 闸门 |
|---|---|---|---|
| 1 | 读原始 CSV → 模型认的因子（`is_self`、`is_match`、`side`、`omission`） | `read_formal_data.py` 的 `rec` | 两条独立路径推出的 `is_match` 必须逐行一致；`Correct == 1 ⟺ side == is_match` |
| 2 | 拟合前清洗：剔除抢按（`RT < 150 ms`）、给 `t0` 设逐人上界 | `fit_ready`、`t0_bounds` | 任一已响应试次 `rt − t0 ≤ 0` 会让**整份**似然为 `−inf` |
