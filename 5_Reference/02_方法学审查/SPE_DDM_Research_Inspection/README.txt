SPE–DDM Research Summary and Experimental Design Package

Contents
1. SPE_DDM_Conversation_Summary_and_Research_Plan.md
   Authoritative Markdown version. Figures are linked relatively from ./figures/ and will display when this package is extracted intact.
2. SPE_DDM_Theory_and_Functions_Guide.html
   Single HTML guide with embedded figures and MathJax for equations. Open in a modern browser; internet access is needed to load MathJax unless a local MathJax bundle is configured.
3. figures/
   Seven schematic diagrams covering practice functions, T-to-encoding-to-drift, static and dynamic W boundary functions, example DDM paths, trial timing, mixed design, and the model validation workflow.
4. guide.css
   CSS source used to style the HTML. The HTML already embeds its styles, so the CSS file is included for optional future editing.

Important interpretation note
The function curves and diagrams are schematic. Parameters shown in diagrams are illustrative and have not been fitted to empirical SPE data. Proposed mappings from P/T/W to DDM parameters are candidate hypotheses, not established psychological laws.

Scope
The package summarizes the discussion through 13 October 2026, including candidate functions, coding conventions, legacy MATLAB timing issues, candidate designs, parameter/model recovery, fitting-to-behavior workflow, and APA-style references.
