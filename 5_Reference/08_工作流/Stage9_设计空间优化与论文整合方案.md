## 4. 设计变量的参数化与约束

### 4.1 决策变量

| 变量 | 类型 | 现状（D4） | 是否进本方案的搜索 |
|---|---|---|---|
| `T` 水平 × 4 | 连续，被试内 | 33.33 / 83.33 / 149.99 / 249.98 ms（≈2/5/9/15 帧） | ✅ 四个位置都搜 |
| `W` 水平 × 3 | 连续，被试内 | 799.98 / 1199.9 / 1799.9 ms | ✅ 三个位置都搜 |
| 每格重复 `n_rep` | 整数 | 12（总 576 试次/人） | ✅ 搜，总试次固定 576 |
| `P` | **离散被试间**，4 水平 | {0, 8, 32, 120}（D7，**已拍板，不搜**） | ❌ 只作为分层 |
| 每组人数 `N` | 整数 | 目标 ~40 | ✅ 搜（进 (B) 判别项） |

⇒ **每个 `P` 水平一个独立 GP**（3 维输入 `(T_1,T_2,T_3)` 的打包 / 或 2 维 `(T, W)` 的两阶段搜索），**不建含离散维的 GP**——历史数据里每个 P 组都是固定 P，一个混合 GP 会把这个结构抹掉。

### 4.2 时序口径（D48，**强制**）

- 进内环的 `T`/`W` **一律是 v4.1 口径**：`deadline = W`（自刺激 onset 起算），`W > T + 200 ms`。
- 每个候选点先过 `1_Code/AutoRA_SPE/spe_timing_convention.py::assert_current_design(T_ms, W_ms)`；**被拒的点不进表**。
- **禁止**把 `1_Code/AutoRA_SPE/README.md` §3 的历史 `W_legacy` 列直接喂进内环；必须先用 `legacy_to_current_W(T, W_legacy) = T + W_legacy` 换算，并同时用 `misuse_distortion()` 把"若误用会差多少"写进附录（该函数已实测：偏差 = `T`，网格内 **1.85%–31.25%**，且随 `T` 单调增长）。
- **D2 闸门（`min RT − T ≈ 203 ms`）在 v4.1 数据上不存在**，不得当验收判据（`check_timing_convention.py` 的 B4 组已给出证据）。
- `design_fim.check_validity(T_levels, W_levels)` 已实现 `W > T + 0.2`（秒制）✅ 与 D48 一致。

### 4.3 可行使域是**梯形**，不是矩形

约束 `W > T + 0.2 s` 意味着在 `(T, W)` 平面上可行域是 `T ∈ [0.03, 0.60]`、`W ∈ (T+0.2, 2.5]` 的梯形。⇒ **改坐标**：

```
t = T                     ∈ [0.03, 0.60]
u = W − T − 0.2（后掩蔽可按键时长）  ∈ (0, 2.3]
```

`(t, u)` 上可行域是**矩形**，GP 与网格都干净得多，而且 `u` 恰好是 `Exp_Design_Formal.m` L22 那个"真正可按键时长"，物理意义直接。**内环一律在 `(t, u)` 上搜索，输出时换回 `(T, W)`。**

## 5. 内环：为什么不能用 Stage 8 的完整拟合，以及生成器分支的真实状态

### 5.1 完整拟合的成本（D46/D47 实测）

M-T3 **420·N** + M-T1 **544·N** 次内层众数搜索；`N = 40` 时单模型一次全量拟合是**小时级**（D46：4 组 × 40 人的正式投影 256 h/组，不可行；D47 的解析 Hessian 把**超参数 Hessian 项**从 38 560 次降到 0，但**被试层拟合本身仍是 420·N / 544·N**）。

一个 BO 循环要几百到上千次设计评估 ⇒ **完整拟合不可能进内环**。

### 5.2 改用期望信息量（这是本方案的核心工程决定）

**选择**：内环的评估器 = `1_Code/DDM_Core/design_fim.py::design_se(T_levels, W_levels, n_rep, truth=TRUTH, n_fim=N_FIM, seed=0)`。

它返回（实测）：

| 键 | 含义 | 在 Objective 里的角色 |
|---|---|---|
| `se` (9,) | 平均信息矩阵求逆后的 Cramér–Rao SE（参数自然单位） | **(A) 参数恢复精度** |
| `se_sd` (9,) | 逐份模拟 SE 的标准差 | **CRN 噪声带**（§5.4、§8 判据） |
| `corr` (9,9) | 参数相关矩阵 | 诊断（`delta_a~tau_a` 的补偿） |
| `cond`, `n_bad` | 信息矩阵条件数 / **不可识别方向条数**（`likelihood.py::fim_diagnostics`：特征值 `< max(ev_max*1e-8, 1e-300)` 的个数；**不是「坏试次」**） | **可用性闸门**（`cond > 1e10` 或 `n_bad > 0` ⇒ 相关与 SE 都不可信） |
| `omission`, `acc`, `rt_ms` | 行为诊断 | **(C) 遗漏率约束** + **(D) 负担** |
| `T`, `W`, `rep`, `n_trials` | 设计本身 | 表的键 |

- **为什么这不是"偷懒"**：`design_fim.py` 的模块 docstring 已论证（Myung & Pitt；Cavagnaro et al.）——设计比较真正需要的是**预测精度**，它可以用信息量在**不到一秒**内算出；实测 `design_se` ≈ **0.08 s**，而同一份 D4 数据用 Hessian 要 **28.5 s**，用"模拟→拟合"要**几分钟**。
- **这正是 `AutoRA_SPE/README.md` §6 处方 ⑤ 的落地**：**充分统计量 = 平均信息矩阵**，表 = `(design, truth) → (se, se_sd, omission, acc, rt_ms, cond)`，内环退化为**查表**。
- ⚠️ **三个必须随结果一起报的限定**（`design_fim.py` 自己写的）：① 这是 **Cramér–Rao 下界**，真实 MLE 只会更差；② 逐被试设计比较用的是**"聚合被试"**（N 名被试的试次合并、**不含随机效应**）；③ 组层 SE ≈ 单人 SE / √N 是大样本近似。

### 5.3 ❗ 缺口：内环生成器只接了 M-T3（**但 M-T1 仪器已存在于 `_scratch`，2026-10-14 更正**）

`design_fim.py` 第 281–282 行自己写明：

> ⚠️ 当前生成器是**恒定漂移（M-T3）**；因决策 D5，严格应换 M-T1（漂移在 t = T 处从 d_stim 阶跃到 d_mask）。M-T1 列为 Stage 4 待办。

### 6.2 三个分项

设 `relSE_p = SE_p / |truth_p|`（`design_se` 的 `se` 除以真值绝对值）。

**(A) 参数恢复精度** —— 与 `design_fim` 的总名次口径一致（相对 SE 的**几何平均**），但参数集换成 `C6`：

```
A(design) = exp( (1/6) · Σ_{p ∈ C6} ln relSE_p )        # 越小越好
```

锚点：`A(D4) = 0.268`；判定沿用 `design_fim` 的既有分档（`< 0.30` ✅ / `< 0.60` ⚠️ / 否则 ❌）。

**(B) 模型判别信息** —— 用**组层检验的期望 |t|**，`rho` 在 M-T1 下是被试层参数（`rho_free=True` 时 `k = 8`，M-T3 时 `k = 7`），所以判别是**群体均值的检验**：

```
SE_s(rho)         = OPG 信息下 rho 的逐被试 SE（M-T1 生成器，ρ 进参数向量）
SE_group(rho)²    = [ σ_ρ² + mean_s( SE_s(rho)² ) ] / N
B(design, N)      = |μ_ρ − 1| / SE_group(rho)              # 期望 |t|，越大越好
```

**事前登记的真值（必须冻结，不得事后调整）**：`μ_ρ = 0.6`、`σ_ρ = 0.25`（来源：`twophase.py` 的 `MASK_RHO_BOUNDS = [0,3]`、`rho = 1` 内点；`0.6` 对应"掩蔽后证据积累降到 60%"，是本项目 D5 假设的**保守中值**）。`μ_ρ/σ_ρ` 的敏感性必须作为一个**网格**报（建议 `μ_ρ ∈ {0.5,0.6,0.8}` × `σ_ρ ∈ {0.15,0.25,0.40}`），**并标明结论对该网格的依赖**。

**(C) 遗漏率约束** —— 靶子来自 Stage 7/6 的实测（未到手前用**事前登记带**）：

```
target band = [0.05, 0.20]        # 事前登记；Stage 6 Pilot 到手后必须替换为实测区间
penalty_C(design) = 0                          , if omission ∈ band
                  = ((omission − bound)/0.05)² , otherwise      # 越界 5 个百分点罚 1
```

**(D) 行为负担 / 可行性闸门**：

```
reject if cond > 1e10        # design_fim 自己写的"矩阵病态，相关不可信"
reject if n_bad > 0
reject if rt_ms > RT_CAP     # 事前登记，建议 RT_CAP = 1000 ms
reject if n_trials != 576    # 总试次固定
```

### 6.3 合成与"不做任意加权"的处置

**主口径（标量，事前登记权重）**：

```
J = A_norm − 0.5 · B_norm + penalty_C      # A/B 各自按 D4 的值归一化
```

**稳健性口径（避免权重任意）**：同时报 **(A, B) 的 Pareto 前沿** + 权重的敏感性曲线。**论文主表用 Pareto 前沿，标量 `J` 只作为优化器的驱动函数。**

## 7. 优化器与采集函数

### 7.1 代理模型

- `sklearn.gaussian_process.GaussianProcessRegressor`，kernel = `ConstantKernel(1.0) * Matern(length_scale=[0.2,0.2], length_scale_bounds=(1e-2,1e1), nu=2.5)`，在 `(t, u)` 归一化到 [0,1]² 后拟合；
- `alpha = (MC 噪声带 / 尺度)²` 必须设成**实测的 `se_sd` 折算值**，而不是默认 `1e-10`——否则 GP 会把 CRN 抖动当信号插值。**这是本方案最容易做错的一处。**

### 7.2 采集函数

sklearn 不提供 EI ⇒ 自实现：

```
EI(x) = (μ* − μ(x)) Φ(z) + σ(x) φ(z),   z = (μ* − μ(x)) / σ(x)
```

`μ*` = 到当前为止的**观测**最优（含随机臂的最好值），不设"目标值"参数（避免引入一个任意常数）。约 10 行，不新增依赖。

### 7.3 预算与停机

- **固定评估预算**：所有四条臂**同一预算**（建议 200 次 `design_se` 调用；实测 0.08 s/次 ⇒ 单臂约 16 s，四臂约 1 min，**完全可接受**）。
- 报告 `best-J-so-far` **vs 预算**的曲线（不是只报终点值）——否则"GP 更好"可能只是它多试了几个点。

## 13. ③ 设计空间搜索结果与 2026-02 交稿约束（D109）

**结论先行**：保留现行 P 方案 `0/8/32/120`；`tau_P` 从「可估参数」降为**探索性**；
组人数按 `beta_T` 的 **37–43 人/组** 规划（不是 150+）。

### 13.1 为什么改判（上一轮说「须 161 人/组」是错的）

`mapping.drift_magnitude` 对幅度取 `max(0, ·)`，而 `design_fim.TRUTH` 的 `beta_P=1.5`、`P_ref=120`：
P=0/8/32 的漂移被算成 **0.000 / 0.000 / 0.211**（P=120 才 0.700）。
⇒ 四个水平里只有 `{32, 120}` 与「线性 + 可正可负」的组层模型**自洽**，
其余两个水平的漂移被截断成 0/极小值，进了模型就是符号冲突。
上一轮把「三参数 + 两个自洽点」硬拟合，`pinv` 在秩亏方向上报 0 方差，
于是出现「`tau_P` 需 161 人」这种既吓人又无意义的数。**根因是模型口径不自洽，不是人数不够。**

### 13.2 保留方案下的真实需求（只对 `beta_T` 与 `beta_P` 两条判据求人数）

| 被试内设计 | 试次/人 | `beta_T` 需 N（≤10%） | `beta_P` 需 N（≤0.30） | 30 人/组时的实际精度 |
|---|---|---|---|---|
| `4T×3W r12`（现行） | 576 | **43** | 4–6（设计真值 `beta_P`=1.5 时信号很强） | `beta_T` ≈ 12%、`beta_P` ≈ ±0.28（相对 ±19%） |
| `4T×4W r9`（加 W=1400） | 144 | **37** | 4–6 | `beta_T` ≈ 11%、`beta_P` ≈ ±0.26 |
| `4T×2W r18`（省 W） | 144 | **40** | 3–5 | `beta_T` ≈ 11% |

读法：**`beta_T` 是唯一的硬约束**（它是被试内漂移敏感度，靠人数平均）；
`beta_P` 在设计真值下信噪比很高（P=32 与 P=120 的漂移差 0.49），几个人就到 0.30。

### 13.3 交稿约束下的处置（用户 2026-10-21 决定）

* **保留** `0/8/32/120`：改 P 方案会改已定稿的 `正式采集_候选设计_v2_定稿.md` 与采集程序，
  而交稿日 **2026-02-21** 已定、数据尚未收完 ⇒ 改设计的代价大于收益。
* **`tau_P` 降为探索性**：论文不报它的点估计与区间，只报「本设计无法估计饱和常数」并说明原因
  （§13.1 的截断机制）。这是**已知限制**，不是失败。
* **主检验**：`beta_P`（练习效应，组间）+ `beta_T`（刺激时长效应，被试内）。两者都不受截断影响。
* **报告方式改成「估计 + 区间」而不是「达标 / 不达标」**：人数不再是「够不够」，而是「区间有多宽」。
  30 人/组时 `beta_P` 的 95% 区间约为 ±0.28（真值 1.5 的 ±19%），足以支撑「有练习效应、量级中等」这类结论。

### 14.2 三条结论

1. **被试内设计的杠杆比 P 方案大。** P 方案换来换去只动 `beta_P`（6→4 人）和 `tau_P`（15→11 人），
   始终远低于 `beta_T`；真正压低总人数的是被试内结构（45 → 39）。
2. **「加一个 W 水平（1400 ms）」是唯一免费的改进**：人均试次不变（576），人数少 6（−13%）。
   加重复（`r12→r18`）或加 T 水平都要多付 14–18% 试次，反而更贵。
3. **30 人/组落在判据线上方 2 个百分点**（12.2% vs 10%）。这个差距是「区间宽度」而不是「研究没意义」——
   与 D109 的口径一致：报区间、报效应量，不报「达标/显著」。
