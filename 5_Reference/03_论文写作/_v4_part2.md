# 第8章 研究四：新设计下的两阶段掩蔽模型与 SPE 的通道归因

## 8.1 研究问题与定位

研究一至研究三确定了三件事：短 W 会把 SPE 压掉，遗漏率高时漂移率会被扭曲，六个设计点撑不起 GP 层。这三点合起来给出一条约束：**要谈 SPE 的参数归因，必须换一个 W 足够长、遗漏可建模、并且复杂度受可识别性约束的设计**。

本章使用的设计 v4.1 针对这三点做了修改：W 取 800 / 1200 / 1800 ms（均高于研究一给出的 800 ms 下限），T 取 100 / 150 / 250 ms，P 取 0 / 8 / 32 / 120% 四档，共 576 试次。模型改为两阶段掩蔽扩散（§4.3）：刺激期内漂移率为 v，掩蔽期内衰减为 ρ·v，遗漏用精确 deadline 似然处理。身份通过两个通道进入：漂移通道（beta_S、beta_ST）与判据通道（dz_S）。

本章回答两个问题：

- **Q3（可识别性）**：ρ 与新模型的其他参数，在这个设计下能否被数据识别？
- **Q4（机制）**：观测到的 SPE 应当归因到哪一个通道？它是单一成分还是双成分？

## 8.2 方法

**被试**。17 名被试（15 男、2 女；年龄 M = 22.5、范围 20–25；全部右利手），按 P 分为四组（P = 0%：4 人；8%：5 人；32%：4 人；120%：4 人）。剔除抢按试次后共 7,144 个有效响应试次（自我 3,619、他人 3,525）。

**估计**。层级贝叶斯，群体分布为多元正态，超参用 EM 更新、被试级后验用 Laplace 近似。自由参数为 8 个：d_ref、beta_T、beta_S、beta_ST、a_ref、delta_a、t0、dz_S；z_ratio 锚定在 0.50，不估计。比较两个模型：M-T1（ρ 自由，9 参数）与 M-T3（ρ = 1，退化为单阶段，8 参数）。

**判据**。主判据为逐试次 ELPD（留一预测），配合 Pareto-k 诊断；可识别性用超参 Hessian 是否正定判定；拟合质量用后验预测检验（PPC）的分位数偏差与正确率覆盖。

## 8.3 结果

### 8.3.1 行为层：SPE 存在但量级偏小

17 名被试总正确率 0.786，RT 中位 692 ms（p10 475、p90 995）。自我条件正确率 0.818、他人 0.752（ΔACC = +0.067）；RT 中位自我 671 ms、他人 704 ms（ΔRT = +33 ms，配对 t = 4.76、p = 0.0002；17/17 全为负向差）。分位差随分位增大而增大：p10 +5、p25 −18、p50 −33、p75 −47、p90 −37 ms。

需要如实记录一个分布特征：有 4.9% 的试次 RT ≤ 400 ms，其正确率仅 0.541，远低于 400 ms 以上试次的 0.798。这一「快带」无法由模型复现（模型的 t0 下界即 0.19–0.29 s），是本轮拟合的主要失配来源之一（见 §8.3.3）。

### 8.3.2 可识别性：ρ 不可估，ρ = 1 可估

M-T1（ρ 自由）在四组中**四组的超参 Hessian 均非正定**（n_flipped = 1），ρ 的点估计在 x 空间为 0.002–0.604 而标准误高达 1.40–21.45，即完全未识别。这意味着「掩蔽期漂移是否衰减」这个问题，在 17 人 × 576 试次的当前样本下无法回答，任何关于 ρ < 1 的推断都不可信。

M-T3（ρ = 1）四组全部正定。逐试次 ELPD 为 −1688.8 ± 32.7、−1074.9 ± 52.4、−1667.7 ± 35.1、−1955.3 ± 35.9（组 1–4），p_loo/n 为 0.00145、0.00140、0.00173、0.00172，Pareto-k 全部为 0（无一个超过 0.7）。由于 M-T1 不可识别，**两模型之间的 ΔELPD 不可引用**——这不是「M-T3 更好」，而是「M-T1 的参数根本没有被数据约束住」。

### 8.3.3 拟合质量：RT 分布过散，正确率被高估

PPC 显示模型系统性地产生「更散」的 RT 分布。17 名被试平均的「预测 − 观测」分位差为：p10 −99.3 ms、p25 −97.1 ms、p50 −48.3 ms、p75 +62.6 ms、p90 +184.5 ms。即模型预测的分布左端比数据快约 100 ms、右端比数据慢约 185 ms。用相对离散度衡量，(p90 − p10)/p50 在预测中为 1.20–1.30，在观测中为 0.54–0.76，相差 1.7–2.2 倍。

正确率则被系统性高估：模型预测 0.978 / 0.946 / 0.951，观测 0.932 / 0.891 / 0.888（组 1/2/3 的部分单元）。我们尝试用三种方式修补：一是给似然加「污染项」（以概率 λ 产生一个与证据无关的反应），窄窗版本在 3 名被试上给出 Δℓ = −12.9 / +1.0 / −10.9，几乎处处为负，说明污染项不是缺失成分；二是把 t0 上界放开，结果 t0 迅速贴到上界（组 2 四名被试 0.517–0.570，上界 0.60），决策时间被压缩到 0.15–0.35 s；三是检查「快带」是否代表独立猜测通道，结论是否定的（4.9% 的占比无法支撑 33 ms 的位移）。

因此本章的绝对拟合结论只用于参数排序，不用于断言「模型正确」。这是本文的既定口径（§4.4），也是研究三留下的同类问题的延续。

### 8.3.4 SPE 的匹配专属性

把试次按「身份 × 是否匹配」拆成四格后，SPE 的结构发生质变。四格的池化 RT 中位为：自我-匹配 643 ms、自我-非匹配 732 ms、他人-匹配 724 ms、他人-非匹配 750 ms。据此：

- **匹配试次**：ΔRT = +59.3 ± 10.6 ms（t = 5.59、p < 0.001；16/17 为正向）、ΔACC = +14.4 ± 3.4 个百分点（t = 4.21、p = 0.0007；14/17 为正向）。
- **非匹配试次**：ΔRT = +16.3 ± 7.9 ms（t = 2.07、p = 0.055；10/17）、ΔACC = −0.9 ± 2.2 个百分点（t = −0.43、p = 0.67；8/17）。
- **交互**：RT 交互 t = 4.40、p = 0.0004；正确率交互 t = 5.90、p < 0.0001；2×2 方差分析中身份 F = 22.53（p = 0.0002）、匹配 F = 28.11（p = 0.0001）、交互 F = 19.36（p = 0.0004）。

[[FIG:图8-1]]

信号检测分解进一步指出这不是单纯的判据效应：命中率自我 0.862 / 他人 0.718，虚报率 0.230 / 0.221，即虚报几乎不变而命中大幅提高。逐被试配对得 Δd′ = +0.50（t = 2.95、p = 0.0095；13/17 提高）、Δc = −0.29（t = −6.15、p < 0.0001；15/17 更宽松）。**辨别力提高与判据放松同时存在**，这是双成分解释的行为学基础。

### 8.3.5 参数层面的来源：判据通道而非漂移通道

四组拟合（M-T3）给出的身份通道参数为：beta_S = +0.275 / +0.043 / −0.152 / −0.332（组 1–4，符号相反），dz_S = +0.007 / +0.038 / +0.032 / +0.056（**四组全为正**）。也就是说，漂移通道的方向在组间不稳定，而判据通道的方向稳定。

为判断「SPE 到底来自哪个通道」，我们在组 2 的组均值参数（d_ref = 1.187、beta_T = 3.428、beta_S = 0.043、beta_ST = −0.645、a_ref = 1.827、delta_a = −0.055、t0 = 0.555、dz_S = 0.038）上做了解析模拟，逐个「关掉」通道看交互是否消失：

| 条件 | 匹配 ΔRT | 非匹配 ΔRT | 匹配 ΔACC | 非匹配 ΔACC |
|---|---|---|---|---|
| 全部通道 | −19 ms | +18 ms | +0.054 | −0.038 |
| 关掉 dz_S（dz_S = 0） | +9 ms | −2 ms | +0.019 | +0.006 |
| 关掉 beta_S | −16 ms | +19 ms | — | — |
| 关掉 beta_ST | −19 ms | +15 ms | — | — |
| 全部关掉 | +10 ms | −1 ms | — | — |

结论明确：**匹配专属性由判据通道 dz_S 产生**。关掉 dz_S 后，自我—他人的差异在两个试次类型上都退到 ±10 ms 以内，交互消失；而关掉漂移通道几乎不改变交互。这与 §8.3.4 的 d′ 结果需要并列理解：d′ 的提高说明存在真实的辨别力成分，但它在当前参数化下没有落到 beta_S 上（beta_S 组间反号），而是隐含在「匹配试次的正确率」与「判据偏移」的联合模式中。

## 8.4 讨论

本章的结论有三层。

第一，**可识别性必须先于模型比较**。ρ 在四组中四组不可估，如果仅凭拟合优度或 ΔELPD 就宣称「两阶段优于单阶段」，会得到一个无法复现的结论。这一教训在研究三（GP 层）中已经出现过一次，本章是第二次，说明它不是偶然。

第二，**SPE 的量级问题有一半是模型问题**。实测的 ΔRT/ΔACC 比（33 ms 对 6.7 个百分点）约为纯漂移通道所能产生的比值的 2 倍：解析扫描显示，漂移参数由 0.148 增至 0.59 时 ΔRT 从 −12 变到 −43 ms，但 ΔACC 同时从 +0.052 涨到 +0.158。我们据此做了真值校准，发现在 beta_S 与 dz_S 的网格上不存在同时命中 (−33 ms, +0.067) 的组合：最接近的点 (beta_S = 0.30, dz_S = 0.02) 给出 ΔRT −24 ms 但 ΔACC +0.119；而 (0, 0.04) 给出 ΔRT −21 ms、ΔACC +0.063 却丢掉了 RT 效应。这一「无解」本身是结论：**单靠这两个通道的模型族无法同时解释实测的 RT 与正确率效应**，需要第三个自由度（如漂移的跨试次变异），而该自由度在当前设计下同样不可估。

第三，**匹配专属性把理论问题从「多少」变成「哪里」**。如果 SPE 只在自我被掩蔽且判断为匹配时出现，那么它就不是一个「自我加工更快」的全局优势，而更接近「自我标签提高了匹配证据的累积效率，同时把判据推向匹配」。这一解读与 d′ + c 的双成分结果一致，也与文献中「SPE 随试次组成变化」的零散观察一致，但需要独立实验（例如系统操纵匹配/非匹配比例）才能确证。

# 第9章 研究五：多源验证与跨研究基准

## 9.1 研究目的

本章做三件事：把 96 个公开数据集重算到统一口径，给出 SPE 的跨研究分布；把本项目的读数放进该分布中定位；用 CRF 与机制仿真检查「判据通道」的行为学旁证是否成立。

## 9.2 方法

**跨研究重算**。数据来自 SPE_Database 仓库的 51 个数据集目录（96 个 `*_Clean.csv` 分片），统一口径为：只保留匹配判断试次；只用正确且已反应的试次计算 RT；RT 修剪 150–3000 ms 并对每个「被试 × 身份」单元做 MAD 3.5 倍修剪；每个单元至少 5 个试次；身份取被匹配图形的标准化身份（`Shape_Standardized_Identity`）而非刺激标签。最终得到 92 个逻辑数据集、87 个可用（5 个因缺少身份变量或无自我单元被跳过）、8,634 个「被试 × 身份」单元。

**本项目重算**。同一口径应用于本项目的 17 名被试（7,144 试次），另对 87 名旧被试做展示性重算（不进基准）。

**CRF 与仿真**。沿用旧数据的滑动窗口分析（匹配键反应比例随 RT 窗口变化），并用 Euler–Maruyama 与 Stim-Coding 两套生成器做判据偏移的机制对照。

**练习效应**。从数据库中筛出含「练习 / 正式」双水平的数据集（13 个数据集、17 个数据集×水平），比较两水平的 SPE。

## 9.3 结果

### 9.3.1 跨研究分布：中位 76 ms，方向高度一致

陌生人对比的 71 个可算数据集给出：ΔRT 均值 79.0 ms、中位 75.9 ms、IQR 45.8–103.2、5–95% 区间 0.4–192.1、最小 −109.5、最大 241.0；**95.8% 为正**。ΔACC 中位 0.072、IQR 0.029–0.124、92% 为正。三个负值数据集为 Hu_2023_psyarxiv_Exp3b（−109.5）、Wang_2016 Exp2（−36.9）、Wang_2016 Exp1（−19.9）。

[[FIG:图9-1]]

### 9.3.2 身份梯度：Close 反而小于 Stranger

按数据集级中位 ΔRT 排序：Celebrity 77.7（3 个数据集）、Stranger 75.9（72）、NonPerson 60.0（9）、**Close 42.8（50）**、Acquaintance 15.3（2）。这一结果不支持「亲密度越高、优势越大」的单调梯度，反而显示亲密他人的效应小于陌生人。可能的解释是任务差异（Close 条件多采用面孔或名字，Stranger 条件多采用图形联结）与被试内设计的不同，但现有元数据不足以分离这些因素，本文只作描述。

### 9.3.3 本项目的位置

本项目 17 人的 +33 ms 位于文献分布的第 **18.3** 百分位，ΔACC +0.067 位于第 **46.5** 百分位。即：**正确率效应处于典型水平，RT 效应偏小**。这与 §8.3.5 的模型诊断一致——实测的 RT/ACC 比本身就不是「典型 SPE」的形状，而更接近「判据主导」的模式。

作为对照，生成侧的两个版本差异极大：旧版 v2.4 生成器（单阶段，SPE 写在漂移乘法里，自我 ×2.5、陌生人 ×0.6，理论漂移比 4.17 倍）给出 ΔRT 221 ms、ΔACC 0.258（分别位于第 98.6 与第 100 百分位）；新模型真值 TRUTH_LIN 给出 ΔRT 8 ms、ΔACC 0.054（第 7.0 与第 39.4 百分位）。三者与实测的关系说明：**生成器的「像不像人」不取决于理论是否精致，而取决于真值参数是否落在文献分布内**。

旧数据的滑动窗口分析显示，自我—陌生人的匹配键正确率差在约 234–780 ms 的 RT 窗口内显著为正，峰值约 0.19（约 440 ms 处）。

### 9.3.6 练习效应

13 个数据集、17 个「数据集 × 水平」中，有 5 个数据集同时具备练习与正式两个水平。其中 4 个的练习阶段 SPE 大于正式阶段（Hu_YQ Exp1：35.1 → 68.3 ms；Exp2：17.1 → 24.5；Hu_2023 Exp3a：−3.3 → 15.8；Exp3b：−119.2 → −49.1），1 个相反（Haciahmet：106.5 → 92.1）。样本太薄，只能作为「练习可能放大而非削弱 SPE」的描述性证据。

## 9.4 讨论

本章的三点结论都指向同一个方向：**SPE 的「大小」是一个分布问题，不是一个点估计问题**。文献中位 76 ms 与本项目的 33 ms 之间的差距，一部分来自被试群体（本项目每组 4–5 人，样本小、区间宽），一部分来自试次组成（本项目的匹配/非匹配比例与多数文献不同，而 SPE 恰恰是匹配专属的），还有一部分来自模型能解释的部分（判据主导的模式使 RT 效应偏小而正确率效应正常）。

生成侧的对照给出了一个方法论提醒：旧版生成器之所以「看起来像有 SPE」，是因为它把漂移比开到了 4 倍以上，代价是正确率差达到 26 个百分点——这在真实数据中从未出现。新模型的真值虽然「看不出分离」，但它的 ΔRT 与 ΔACC 都落在文献分布的下半区，与实测更接近。**用「图上分不分得开」判断生成器好坏是错的判据**，正确的判据是「两个行为指标是否同时落在文献分布内」。

# 第10章 总讨论

## 10.1 核心发现回顾

本文的五项研究给出五条结论：

1. **W 截断**：反应窗由 300 ms 增至 1500 ms，被试级 ΔRT 由 −3.3 ms 单调升至 +62.6 ms，超时率由 85.8% 降至 12.9%（第 5 章、§9.3.4）。短 W 下的「无 SPE」是截断产物。
2. **遗漏失真**：遗漏率超过 15% 后，Censor 与 Drop 均使漂移率产生系统性偏倚，覆盖率远低于名义 95%（第 6 章）。
3. **复杂度上限**：六个设计点下，纯 Sigmoid（LOCV 1.135）优于 Sigmoid+GP（1.232），GP 层恢复自身生成模型的比例为 0/40（第 7 章）。
4. **可识别性与通道归因**：ρ 在四组中四组不可估；ρ = 1 时四组正定，但 PPC 显示 RT 过散、正确率被高估；身份效应落在判据通道 dz_S（四组全正）而非漂移通道 beta_S（符号反号）（第 8 章）。
5. **匹配专属性**：SPE 只在自我被掩蔽且判断为匹配时出现（ΔRT +59 ms、ΔACC +14.4 pt），非匹配试次消失；Δd′ = +0.50 与 Δc = −0.29 并存（§8.3.4）。

## 10.2 四层口径的统一

把五条结论放在一起，可以看到它们分别锁住了四层口径中的一层：

| 层 | 无口径时的后果 | 本文的处理 | 章节 |
|---|---|---|---|
| 设计 | W 太短 ⇒ 慢试次被剪，SPE 被压缩或反号 | W ≥ 800 ms 的处方 | 第 5 章 |
| 似然 | 遗漏剔除 ⇒ 漂移率偏倚 | 带 deadline 的精确似然 | 第 6 章 |
| 模型 | 复杂度失控 ⇒ 不可复现的「更好」 | 可识别性先行（ρ、GP、形状族） | 第 7、8 章 |
| 基准 | 数字不可比 ⇒ 文献分歧 | 96 数据集统一重算 | 第 9 章 |

这张表是本文的核心贡献：它把「SPE 是多少」这个看似实证的问题，转化为「在什么口径下测得的 SPE」这个可操作的问题。

## 10.3 双成分理论

匹配专属性与 SDT 分解共同支持一个双成分解释：SPE = 证据累积加速（d′ 提高）+ 匹配判据放松（c 降低）。这一解释有三个可检验推论：

- **推论一**：改变匹配/非匹配比例应当改变 SPE 的量级，因为判据成分只在匹配试次上兑现。这与文献中「SPE 随试次组成变化」的零散观察一致。
- **推论二**：在只有判据成分的场景（如高 P、低 T）中，SPE 应表现为 RT 效应小而正确率效应大；在漂移成分为主的场景（如低 P）中则相反。§9.3.3 的分组数据显示了类似的趋势（P = 0 组 ΔRT 最强、P ≥ 8 组衰减）。
- **推论三**：模型若要同时拟合 RT 与正确率效应，需要第三个自由度（如漂移的跨试次变异）。本文的真值校准显示两通道无解，正是这一推论的间接证据。

## 10.4 方法论贡献

三点。第一，**可识别性先行**：先问「这个参数能不能被这个设计估出来」，再问「它等于多少」。本文在 ρ、GP 层、形状族三处重复了这一纪律，每次都以「不可裁定」作为有效结论。第二，**基准化**：把单点数字改写为百分位，使跨研究比较成为可能。第三，**反直觉的经验**：图的「分离度」不是生成模型好坏的判据，两个行为指标同时落在文献分布内才是。

## 10.5 局限与未来方向

**样本量**。研究四的 17 名被试是阶段样本，四组各 4–5 人，组层参数区间较宽。按 AIPE 口径每组需 13–16 人、总计 55 人，当前完成约 31%。在补足之前，本文的组层比较只能作为趋势，不能作为确证。

**绝对拟合**。PPC 显示 RT 过散、正确率高估，说明模型族本身有系统性失配。本文已排除三种修补（污染项、t0 上界、快带猜测通道），下一步的方向是引入漂移的跨试次变异或非决策时间的变异。

**不可裁定的问题**。ρ 是否小于 1、形状族（指数 / 线性 / Sigmoid / 幂函数）哪一族正确、GP 层是否有价值，在当前设计下都不可裁定。L1 分析显示四族在当前设计上的行为层差异最大仅 8.8 ms（小于 2 个标准误 16 ms），外推到 T = 400 ms 也只有 17.7 ms，因此改程序（加一个 T 档）是不划算的；这三个问题应作为「设计分辨率边界」写入限制，而不是继续加复杂度。

**身份层级**。本文的模型只覆盖自我与陌生人两格。文献库中 Close 的效应反而小于 Stranger，提示身份不是一个单调维度，未来需要把「身份距离」作为一个连续变量建模，而不是分成四格。

**试次类型的系统操纵**。匹配专属性目前是从现有数据的事后分解中得到的。要确证它，需要独立实验系统操纵匹配/非匹配比例，并检验 SPE 是否随之变化。

# 第11章 结论

本文以「SPE 到底有多大」为起点，最终给出的是一个方法论答案：SPE 的可观测值与参数归因由设计、似然、模型与基准四层口径共同决定。用 87 名被试的旧数据，本文证明短反应窗会把 SPE 压到零甚至反号，而这一点足以解释文献中大量看似矛盾的报告；用 17 名被试的新数据与新模型，本文证明在锁好的口径下，SPE 存在于正确率（+0.067）与反应时（+33 ms）两个指标，但它的结构不是「自我加工全局更快」，而是**匹配专属的判据放松加上有限的辨别力提高**；用 96 个公开数据集的重算，本文证明本项目的读数位于文献分布的第 18.3 与第 46.5 百分位，即正确率效应典型、RT 效应偏小。

方法上，本文给出的三条可复用结论是：（1）反应窗 W 应不低于 800 ms，否则 SPE 不可观测；（2）遗漏应以带 deadline 的精确似然处理，遗漏率超过 15% 时剔除与删失都会扭曲漂移率；（3）模型复杂度必须由可识别性约束——ρ、GP 层、形状族在当前设计下均不可裁定，把它们写进「设计分辨率边界」比强行比较更有价值。

理论上，本文把 SPE 从单点数字改写为「带口径的分布 + 双成分结构」，并提出了三条可检验推论。下一步的工作是补足 55 人的样本、引入漂移的跨试次变异以修复过散问题，并用独立实验操纵匹配比例来确证匹配专属性。
