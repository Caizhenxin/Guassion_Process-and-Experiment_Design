## 第0节 一分钟版：这个研究到底在干什么

**打一个比方。** 假设我们想知道"什么条件下人最容易表现出自我优势（看到和自己有关的图形时反应更快更准）"。
传统做法是：挑几个条件各测一批人，然后比较平均反应时谁快谁慢——就像**只在几个固定地点采样，比较哪个点温度高**。

本研究想做的是：把实验的"旋钮"（练习次数 P、刺激呈现时间 T、反应窗口 W）当成一个**三维空间里的坐标**，
在这个空间里采了 8 个点，然后尝试建立一条**"旋钮 → 大脑内部决策参数 → 行为表现"的换算链**，
这样就能预测**没测过的坐标**上会发生什么（这正是"实验设计优化"的意义）。

换算链分三步，本文的每一张图表都对应其中一步：

```
①实验设计参数          ②潜在心理参数（DDM）              ③可观测行为
  P(练习)                      v 漂移率（累积证据多快）         RT 反应时
  T(呈现时间)     ────→        a 边界（多谨慎/多保守）  ────→   ACC 正确率
  W(反应窗口)                  t 非决策时间（编码+按键）        omission 无反应
                               z 起始点（先验偏向）
```

**三个必须让同门听懂的关键词：**
1. **DDM（漂移扩散模型）**：把"做一次二选一判断"想象成**一个有噪声的醉汉从起点往两条边界之一走**，走到哪条边界就按哪个键，走的时间就是反应时。走得快不快=v，两条边界离得远不远=a，起点偏哪边=z，还没开始走的时间=t。
2. **SPE（自我优势效应）**：自我条件下的反应比陌生人条件更快（SPE_RT<0）或更准（SPE_ACC>0）。
3. **omission（遗漏/无反应）**：反应窗口内没按键的试次。**这些试次不是"垃圾"，而是信息**——它说明决策没能在截止前完成。本研究的方法学贡献之一就是量化它。

## 第1节 图清单（逐图说明：画什么 → 怎么读 → 判断标准）

### 图4-1 实验设计空间与 8 组取点　`F4-1_design_space.png`
- **画的是什么**：8 个实验条件在 (P,W) 与 (T,W) 两个平面上的位置；颜色代表数据质量分档（灰=排除、橙=谨慎、蓝=核心）。
- **怎么读**：每个点=一个实验条件（如 G5 = 练习 8 次、呈现 100 ms、窗口 1100 ms）。点越分散，说明实验覆盖的设计空间越广。
- **判断标准**：① 覆盖范围是否包含极端的"时间紧张"角落（G1/G2 就是，训练不足+窗口极短）；② 是否存在"点挤在一起"（G7/G8 都在 W=800，只差 T，说明该区域采样较密）。
- **要记住**：本研究只有 8 个点、P 只有 3 个水平（0/8/120），这是后文"模型外推困难"的根本原因。

### 图5-1 被试级 SPE 分布　`F5-1_spe_subjects.png`
- **画的是什么**：左图=每名被试的 SPE_RT（自我−陌生人，负值表示自我更快）；右图=每人的 SPE_ACC；箱线图上方标注该条件的遗漏率。
- **怎么读**：每个小点=一名被试，黑菱形=该条件的被试平均。看三点：**中位数偏离 0 的方向**（是否出现自我优势）、**箱体高度**（个体差异大小）、**跨条件的移动**（设计参数是否在调控它）。
- **判断标准**（本领域惯例）：SPE_RT 中位数在 −20 ~ −60 ms 属典型；方向为正（自我更慢）说明该条件下效应反转或数据不可靠；个体间差异大是常态（本文组内 SD 远大于组间差异）。
- **实测**：G5 = −47.9 ms、G6 = −65.9 ms（效应最强）；G1 = +4.3 ms（反转，且遗漏率 72%）；G3 = +13.8 ms（正号，与其 DDM 参数 SPE_v=−0.16 一致）。
- **要记住**：**效应不是恒定常数，而是设计参数的函数**——这就是全文的核心主张。

### 图5-2 HDDM 群体层参数与 95% CI　`F5-2_hddm_params_forest.png`
- **画的是什么**：三幅"森林图"（A: v_self；B: v_stranger；C: a），每个条件是横线上的一个点（后验均值）＋横线（95% 可信区间）。
- **怎么读**：横线不跨 0 = 该参数显著偏离 0；两个条件的横线**不重叠** = 差异可靠；横线越长 = 估计越不确定（样本少/遗漏多）。**重点关注 G1–G3 的横线极长**——这正是"参数不可靠"的视觉信号。
- **判断标准**：CI 宽度超过参数本身量级（如 v 的 CI 从 −8 到 +2）说明**不可辨识**，不能用于理论解释；此时正确做法是排除或标注为谨慎，而不是硬解释。
- **要记住**：**参数估计本身可能不可靠——所以必须先做"参数恢复"来证明估计流程可信**（见第3节与图6-3~6-5的说明）。

### 图6-1 Censor 与 Drop 的参数差异随遗漏率变化　`F6-1_omission_delta.png`
- **画的是什么**：横轴=该条件的遗漏率，纵轴=Censor 与 Drop 两种处理方式得到的参数之差（左 v_self、中 a、右 SPE_v）；圆点=两种方式的 95% CI 不重叠（差异可靠），方点=重叠；黄色阴影=15%–35%（本数据没有条件落在这个区间）。
- **怎么读**：点越往右（遗漏率越大）差异越大 → 说明**处理遗漏的方式会实质改变结论**。
- **判断标准**：若 Δ 的绝对值与参数本身量级相当（如 G1 的 Δv=6.81，而 v 本身约 ±3），则结论不可信；SPE_v 的 Δ 很小（<0.1）说明**相对效应比绝对水平稳健**。
- **要记住**：**遗漏率超过约 35% 时，两种处理方式给出根本不同的参数**；同理，约 15% 以下两种方式基本一致。

### 图6-2 OPN 第一版的预测表现　`F6-2_opn.png`
- **画的是什么**：一个"小神经网络"预测"给定 DDM 参数与截止时间时，被试有多大概率不反应"的准确度散点。
- **怎么读**：点越贴近对角线（预测=真实）越准；本图 R²≈.99（训练）/ .986（测试），MAE≈.017。
- **判断标准**：测试集 R² > .9 即可认为"这个代理模型可用"；但它只说明**网络能模仿仿真器**，不代表模型对真人行为的刻画正确（后者要看 PPC）。
- **要记住**：这是**概念验证（proof of concept）**，仅 4,699 个训练样本的快速版；正式路线是复用 Leng et al. (2026) 的官方 OPN 网络。

### 图6-3 / 图6-4 / 图6-5 参数恢复（已实测）　`F6-3_param_recovery_scatter.png` / `F6-4_omission_bias_curve.png` / `F6-5_recovery_coverage.png`
- **画的是什么**：图6-3=已知真值的仿真数据被重新估计后"真值 vs 估计"散点（虚线=完美恢复）；图6-4=遗漏率与参数偏倚的曲线（含 15%/35% 参考线）；图6-5=各参数 95% CI 的覆盖率。
- **怎么读**：点贴对角线=无偏；曲线越陡=偏倚随遗漏率增长越快；覆盖率柱越接近 95% 虚线越好。
- **实测（每条件 3 次重复，共 36 次拟合）**：
  - **漂移率绝对水平不可恢复**：Censor 系统性低估（偏倚 −1.34），Drop 系统性高估（+0.73）；95% CI 覆盖率仅 17% 与 0%。
  - **自我优势的相对效应几乎完美恢复**：SPE_v 偏倚 ≤0.05、RMSE ≤0.19、**覆盖率 100%**、跨条件 r = .97（Censor）/ .91（Drop）。
  - 曲线显示偏倚随遗漏率**单调增大**：<10% 时 |Δv| < 0.2；10–15% 时 0.26–0.40；>25% 时 0.6–1.0；>50% 时 1.6–3.2。而 SPE_v 偏倚在任何遗漏率下都 ≤0.11。
  - 条件差异：G6（遗漏 1.2%）偏倚极小（−0.03），G8（v≈2.8、a≈2.4、遗漏 30.7%）最大（Censor −2.28 / Drop +3.67）。
- **判断标准**：覆盖率 ≈95%、偏倚 ≈0 才算"参数可信"。因此本文的结论是——**绝对参数水平不宜作实质解释，条件间的相对比较（SPE_v）是可靠的**。
- **要记住**：这是全文最重要的一块"地基证据"：它解释了"为什么遗漏处理会改变结论，但我们的核心结论仍然成立"。
- **对论文的影响**：把原先"遗漏率 >35% 不可接受 / <15% 可靠"的经验分档，修订为"<10% 偏倚可忽略；10–35% 需谨慎；>35% 绝对水平不可解释；相对方向始终稳定"。

### 图7-1 / 图7-2 in-sample 拟合与留一条件交叉验证（LOCV）　`F7-1_insample.png` / `F7-2_locv.png`
- **画的是什么**：图7-1=在**训练用过的**6 个条件上，模型预测值与真实 HDDM 参数的重合程度；图7-2=**每次留出一个条件**、用其余 5 个条件训练后再预测被留出条件的表现。
- **怎么读**：图7-1 几乎完美（r≈1）**不要高兴太早**——那只是"背下了答案"（插值）；关键是图7-2：点散乱、相关接近 0 甚至为负。
- **判断标准**：LOCV 的 r > .5 才算具备外推能力；本文 v_self 的 r = −0.03 → **外推不成立**。原因不是方法错，而是**只有 6 个设计点**（相当于用 6 个点去猜整条三维曲线）。
- **要记住**：**"拟合得好"≠"预测得准"**。这是全文最重要的一句方法学提醒。

### 图7-4 / 图7-5 / 图7-6 后验预测检验（PPC）三张　`F7-4_ppc_interval.png` / `F7-5_ppc_coverage.png` / `F7-6_ppc_qp.png`
- **画的是什么**：把估计出的参数**重新拿去仿真被试行为**，然后问："仿真出来的行为，和真实被试的行为对得上吗？" 图7-3=逐格子的观测值 vs 预测区间；图7-4=覆盖率柱状图；图7-5=RT 分位数 × 正确率（QP 图，DDM 领域的标准验证图）。
- **怎么读**：红叉（观测）应落在蓝线（95% 预测区间）内；覆盖率柱子应接近 95%。
- **判断标准**：覆盖率 ≥ 90% 算通过；本文实测仅 **17%–33%** → **未通过**。
- **实测与含义**：模型倾向于"高估长时限条件下的正确率、严重低估遗漏率"（G6：观测遗漏 5.6% vs 预测 0.8%）。这说明为"恒定边界 DDM"在含截止时间的任务里**模型本身不够用**——需要加入跨试次变异、注意脱失（lapse）、以及允许边界随时间塌缩的模型（ANGLE/WEIBULL）。
- **要记住**：这条"没通过"的结果**不是失败，而是有价值的发现**：它把"为什么需要更复杂的模型"从文献猜测变成了本文自己的证据。

### 图7-3 模型比较与模型恢复　`F7-3_model_comparison.png`
- **画的是什么**：左=四个候选模型预测误差对比（越小越好）；右=混淆矩阵（"用模型 A 造的数据，被判别程序认成了哪个模型"）。
- **怎么读**：左图看排序（本文：纯 Sigmoid 1.135 < Sigmoid+GP 1.232 < 均值 1.269 ≪ 线性 8.535）；右图看对角线是否亮（越亮=越能区分模型）。
- **判断标准**：模型比较要配"模型恢复"才算合规——如果混淆矩阵全是乱的，说明"你的实验设计根本区分不了这些模型"，此时的比较结论无效。
- **实测含义**：① **线性模型灾难性失败** → "必须用非线性"是铁证；② **纯 Sigmoid 反而略优于混合模型** → 在当前 6 个点下，GP 残差层**没有**提升预测，其价值只在"给出不确定性"；③ 线性、GP 的对角率都是 0 → **设计功效不足以判别模型**，这也是"必须增加设计点"的证据。

### 图7-7 候选设计点（探索性）　`F7-7_candidates.png`
- **画的是什么**：在设计空间里，哪些区域模型的预测**最不确定**（颜色越深越不确定），top-20 候选点及其不确定性分解。
- **怎么读**：不确定性高的地方=我们最不了解的地方；下一轮实验优先补这些点最"划算"（信息量最大）。
- **判断标准**：候选点不能只看不确定性——还需考虑可行性（如 W=300 ms 的区域在真实数据中对应高遗漏，实际做实验可能测不到干净数据）。本文因此把它标为"**探索性提示**"，不说"最优设计"。

### 图8-1 内部数据的滑动窗口分析　`F8-1_sliding_window.png`
- **画的是什么**：把反应时按窗口（100–400 ms 滑动）切开，看每个窗口内"自我 vs 陌生人"的正确率差。
- **怎么读**：曲线显著高于 0 的区间=自我优势出现的反应时范围（本文约 234–780 ms，峰值约 0.19@440 ms）。
- **判断标准**：峰值位置与该任务的主流 RT 分布应吻合；**注意这是内部 88 人数据的结果，不能写成"跨研究"结论**。

### 图8-2 Stim-Coding 仿真的 CRF 曲线　`F8-2_stimcoding_crf.png`
- **画的是什么**：人为设定"起点偏向"（z=0.50/0.55/0.60/0.65）后，用两套引擎（自写欧拉法 / HDDM 官方生成器）仿真出的条件反应函数（CRF：不同 RT 分位上的正确率）。
- **怎么读**：偏向越大，早期（快反应）正确率优势越明显——这就是"自我优势可能来自起点偏向"的机制演示。
- **判断标准**：两套引擎形态一致=实现无误（交叉验证）；与真实 CRF **叠加对比**才算定量证据（目前是定性一致，v3 中标注待补）。

## 第3节 指标词典（一句话解释 + 判断标准）

### 实验与行为
| 指标 | 含义 | 典型/判断标准 |
|---|---|---|
| **P / T / W / M** | 练习次数 / 刺激呈现时间 / 反应窗口 / 总可用时间 M=T+W | 本文 P∈{0,8,120}、T∈{30,80,100,500} ms、W∈{300,…,1500} ms |
| **RT** | 正确反应的反应时（ms） | 越短=加工越容易；本文正确 RT 均值约 390–945 ms |
| **ACC** | 正确率 | 区分两种口径：acc_all（遗漏计为错误）、acc_responded（仅反应试次） |
| **omission** | 截止前未按键的比例 | 本文 6.7%–72.3%；>35% 时参数估计不可靠 |
| **SPE_RT** | 自我−陌生人的正确 RT 差 | 负值=自我更快；本文 −66 ~ +14 ms |
| **SPE_ACC** | 自我−陌生人的正确率差 | 正值=自我更准；本文多为 +0.06 ~ +0.13 |

### DDM 参数
| 指标 | 含义 | 判断标准 |
|---|---|---|
| **v（漂移率）** | 证据累积速度；越大越快而准 | 经验范围约 0.1–3；本文 G1–G3 出现负值且 CI 极宽 → 不可靠 |
| **a（边界分离）** | 决策谨慎度；越大越慢但更准 | 本文 1.09–2.42（G8 最大） |
| **t（非决策时间）** | 编码+按键耗时（秒） | 本文 0.26–0.66 s |
| **z（起始点）** | 起始偏向（边界比例，0.5=无偏） | 本文 0.45–0.75 |
| **SPE_v** | v_self − v_stranger | 本文 −0.16 ~ +0.71；是"参数层的自我优势" |
| **CI / 95% CI** | 参数的不确定范围 | 跨 0=不显著；两条件 CI 不重叠=差异可靠 |

### 统计与验证
| 指标 | 含义 | 判断标准 |
|---|---|---|
| **η² / f** | 效应量（方差解释比例 / Cohen's f） | η²≈.20、f≈.50 属中等；f_min 是"当前样本量能测到的最小效应" |
| **BF₁₀** | 贝叶斯因子（支持 H₁ 相对 H₀ 的证据倍数） | <3 仅"轶事级"；3–10 中等；>10 强。本文 2.83–3.29 = 刚过线 |
| **G\*Power f_min** | 80% 功效下可检测的最小效应 | 观察 f 必须明显大于 f_min 才算可靠；本文 .500 vs .465 = 安全边际极窄 |
| **LOCV** | 留一条件交叉验证（预测未参与训练的设计点） | **r>.5 才算具备外推能力**；本文失败 → 说明需更多设计点 |
| **参数恢复** | 用已知真值的仿真数据检验估计流程 | r>.9、偏差≈0、95% CI 覆盖率≈95% 才算通过 |
| **模型恢复 / 混淆矩阵** | 用已知生成模型的数据检验模型比较程序 | 对角率越高越好（>0.8 良好）；非对角多=实验设计判别力不足 |
| **PPC（后验预测检验）** | 用估计参数仿真行为，与真实行为逐项比较 | 观测值落在 95% 预测区间的比例应≈95%；本文 17–33% → 模型误配 |
| **Cohen's d** | 标准化效应量 | <0.2 小、0.5 中、>0.8 大；本文 G1 的 omission 相关效应 d≈9（极端） |
| **R-hat / ESS** | MCMC 收敛诊断（是否采样可靠） | R-hat<1.01、ESS>400 才算收敛；**本文尚缺，必须补** |

## 第4节 判断标准速查：什么算"好/通过/失败"

| 环节 | 通过 | 警告 | 失败 |
|---|---|---|---|
| 行为层效应 | p<.05 且 η²≥.14 | p 接近 .05、BF 3–10 | p>.05 且 BF<1 |
| 参数估计 | CI 窄且不跨 0 | CI 宽但方向一致 | CI 极宽或跨 0（如 G1–G3 的 v） |
| 参数恢复 | r>.9、偏差≈0、覆盖率≈95% | 中高遗漏条件下偏差增大 | 覆盖率远低于 95% 或系统性偏差 |
| 模型外推（LOCV） | r>.5 | 0<r<.5 | r≤0（本文） |
| 模型判别（恢复） | 对角率>.8 | .5–.8 | <.5（本文 M2/M4 = 0） |
| 模型验证（PPC） | 覆盖率≥90% | 70–90% | <70%（本文 17–33%） |
| 遗漏处理 | 两方案 Δ 小且 CI 重叠 | Δ 中等 | Δ 与参数量级相当（G1 Δ=6.81） |

## 第5节 同门最可能问的 8 个问题（附一句话回答）

1. **为什么不直接比较反应时，非要搞个 DDM？**
   → 因为反应时是"结果"，DDM 把结果拆成可解释的成分（累积快慢 v / 谨慎程度 a / 起始偏向 z）。两个条件反应时一样，可能是"更快但更草率"，也可能是"更慢但更准"——只看 RT 分不清。

2. **为什么有的条件必须排除？**
   → 那些条件里 36%–72% 的试次被试根本没按键。删掉它们或把它们当错误，会让参数估计相差 6.81（图6-1）——同一批人得出完全相反的结论，所以不能用于建模，只能作为"数据质量"的证据。

3. **"6 个点"到底是什么意思？**
   → 主口径只有 6 个实验条件，等于只用 6 个坐标去拟合一条三维曲线。参数层外推（图7-2）因此失败——这是**设计问题，不是方法问题**。

4. **那模型还有什么用？**
   → 两点：① 它把"设计参数→心理参数"的理论假设变成了**可校准、可检验的数量关系**（如"自我优势约 +86%""时间压力降低边界"）；② 它给出**下一个实验该测哪里**（图7-7 的不确定性区域）。

5. **为什么"行为重建 r=.97"后来又不算数了？**
   → 那个 r 是"跨条件的趋势相关"（条件数一变少、条件本身就少），属于自己拟合自己（in-sample）。严格的做法是后验预测检验（图7-4~7-6），结果显示行为分布层面并没有对上。

6. **PPC 没通过，论文是不是就废了？**
   → 不是。它恰好说明本文的方法学主张是对的：含截止时间的任务需要更复杂的模型（跨试次变异、注意脱失、塌缩边界）。**发现模型不够用，本身就是一个结论。**

7. **SPE 数据库那部分为什么要强调"实际样本量"？**
   → 因为数据库全库自述是 44 篇/3603 人，但本地可获得的是子集（63 个数据集、约 3,327 人）。论文里必须写"我实际分析了多少"，否则外审一查就对不上。

8. **这篇论文最核心的一句话是什么？**
   → **"自我优势不是固定常数，而是实验设计空间的函数；而且这个函数必须用非线性模型来描述。"** 前半句是理论贡献，后半句是方法学贡献。

### 图6-6 HDDM 后验收敛诊断　`F6-6_convergence.png`
- **画的是什么**：24 次拟合（8 次主拟合 + 16 次敏感性拟合）后验迹线的收敛指标分布：左为 Split-R̂、右为有效样本量 ESS（对数）。
- **怎么读**：R̂ 越接近 1 越好（虚线为阈值 1.01），ESS 越大越好（虚线为 400）。柱子偏右（R̂）或偏左（ESS）说明抽样不足。
- **判断标准**：核心参数需 R̂ ≤ 1.01 且 ESS ≥ 400。**实测**：Censor 敏感性拟合 100% 达标；主拟合中 G5/G6/G7 全达标，但 **G3 严重不收敛**（z 的 ESS 仅 8.6）、G8 的起始点参数也不达标（ESS 22）。
- **要记住**：这篇论文里"哪些参数可以放心解释"现在有了客观依据；G3、G4、G8 的参数（尤其 z）须标注为"收敛不充分"。
- **方法局限**：历史拟合保存的是单链，本文用"切 4 段的 Split-R̂"近似；严格做法是重跑并保存多条链。

### 图8-3 模拟与实测 CRF 的定量叠加对比　`F8-3_crf_overlay.png`
- **画的是什么**：(A) 实测 CRF（88 人）：自我 vs 陌生人在不同反应时段的"按匹配键反应比例"；(B) 4 个起始点偏向（z=0.50/0.55/0.60/0.65）× 两套仿真引擎的 CRF，叠加实测曲线；(C) 差异曲线对比。
