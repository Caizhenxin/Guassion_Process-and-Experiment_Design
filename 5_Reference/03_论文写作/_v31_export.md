# 摘要

自我优势效应（self-prioritization effect, SPE）指与自我相关联的刺激获得更快、更准加工的稳健现象，但已有研究通常只在少数离散条件上比较效应大小，缺乏对"实验参数—潜在心理过程—行为表现"这一映射链条的系统建模。本研究以自我匹配任务（self-matching task, SMT）为载体，将练习试次数（P）、刺激呈现时间（T）与反应窗口（W）形式化为三维实验设计空间 Ω，以漂移扩散模型（drift diffusion model, DDM）参数（漂移率 v、边界分离 a、非决策时间 t、起始点 z）作为连接实验设计与行为数据的中介变量，构建"Sigmoid 理论先验 + 高斯过程（Gaussian process, GP）残差"的混合生成模型，并通过真实实验数据、方法学检验、外部数据库与机制仿真进行多源验证。

研究一在课题组前期采集的 88 名被试、8 组实验设计数据上检验设计空间对 SPE 的调控。行为层面，SPE_RT 在 8 个设计单元间差异显著，F(7, 80) = 2.79, p = .012, η² = .196，而 SPE_ACC 差异不显著，p = .183；参数层面（主口径 6 个条件），漂移率层面的自我优势 SPE_v 差异在历史参数配置下显著（F(5, 59) = 2.95, p = .019, BF₁₀ = 2.83–3.29），但该配置存在收敛不足（G3 的 ESS 仅 8.6）与 p_outlier 设置冲突；改用修正配置（p_outlier = 0、4 条链 × 8,000 draws、2,000 burn-in，核心参数 ESS ≥ 9,400、R̂ ≤ 1.000）后，该差异不再显著（F(5, 59) = 1.72, p = .145, BF₁₀ = 1.03）。P、T、W 的线性回归几乎无解释力（R² = .051，BF₁₀ = 0.73），提示设计参数的作用具有强非线性，需要非线性映射建模。

研究二系统评估遗漏（omission）处理方式对 DDM 参数估计的影响（8 组 × 2 方案共 16 次层级贝叶斯拟合），并在已知真值的仿真数据上完成参数恢复检验。结果显示：遗漏试次的处理方式主要改变漂移率的绝对水平——在遗漏率超过约 35% 的条件下（G1–G4），两方案估计差异超出 95% 可信区间的重叠范围（G1 的 v_self 相差 Δ = 6.81），而自我优势的相对方向（SPE_v）保持稳定；在遗漏率低于约 15% 的条件下（G5–G8），两方案基本一致。仿真数据上的参数恢复进一步显示，{待填：恢复偏差与 95% CI 覆盖率}，并且遗漏率–偏倚曲线为"约 15% / 约 35%"的经验分档提供了仿真支持。据此确立"排除高遗漏组、以高质量条件为主口径"的数据策略。此外，本研究训练了适用于本范式的省略概率网络（omission probability network, OPN）概念验证版本（测试集 R² = .986）。

研究三在主口径 6 个条件上校准并验证 Sigmoid+GP 混合生成模型，并补充了模型比较、模型恢复与后验预测检验三项严格验证。差分进化校准（修正参数配置）给出 α₁ = 0.153（自我条件的漂移率增益仅约 +15%）、β₁ = −0.631（高总可用时间条件下边界反而更低，方向与假设相反）与 RMSE = 0.704；该结果表明：当参数估计更可靠时，理论与数据的偏离更为清晰，Sigmoid 假设需要修正。模型比较表明：线性模型的预测误差高出一个数量级（聚合 RMSE = 8.535，而纯 Sigmoid 为 1.135、Sigmoid+GP 为 1.232、均值基线为 1.269），说明非线性映射不可或缺；但在仅 6 个设计点的条件下，GP 残差层未提升跨设计点的预测精度（其价值体现在预测不确定性的量化与候选设计点识别）。留一条件交叉验证（LOCV）显示参数层外推不成立（v_self 的 r = −0.03），模型恢复的混淆矩阵进一步表明当前设计对模型判别的功效不足。后验预测检验显示，模型在跨条件趋势上与真实数据一致，但在行为分布层面存在系统性失配（五个统计量的 95% 预测区间覆盖率仅为 .17–.33；例如长时限条件的遗漏率观测为 .056 而预测为 .008）。这一结果表明恒定边界 DDM 在含截止时间的 SMT 任务中存在模型误配，指向跨试次变异、注意脱失与塌缩边界（ANGLE/WEIBULL）以及遗漏的显式似然建模（LAN+OPN 路线）等改进方向；据此本研究将模型定位为"设计空间趋势模型"而非"可逐条件复现行为分布的模型"。

研究四将上述发现与更大范围证据对照：基于课题组 SPE 数据库的可获得子集（全库自述 44 篇文献/70 数据集/3,603 人；本文实际分析 {待填：数据集数} 个数据集、{待填：被试数} 名被试）考察 SPE 的跨研究分布及其与呈现时间、试次数等设计变量的关系；并通过条件反应函数（conditional response function, CRF）分析与 Stim-Coding 仿真建立"起始点偏向—行为模式"的生成链条，对由实测 CRF 反推 DDM 参数的可辨识性进行可行性分析。需说明的是，数据库层面的设计变量关系与内部数据的方向存在不一致，本文对此进行专门讨论。

综上，本研究构建了从实验设计参数经 DDM 参数到行为表现的完整映射框架，系统揭示了设计空间对 SPE 的调制规律及其边界条件，并通过参数恢复、模型比较/模型恢复、后验预测检验构成完整的验证链，明确了该框架的适用边界：理论映射是不可或缺的，设计空间外推需要更多设计点，行为分布层面的复现需要更复杂的模型形式。

# Abstract

The self-prioritization effect (SPE) refers to the robust finding that self-associated stimuli are processed faster and more accurately than other-associated stimuli. Yet most studies compare effect sizes across only a few discrete conditions and lack a systematic model of the mapping from experimental parameters, through latent cognitive processes, to observable behavior. Using the self-matching task (SMT) as a testbed, this thesis formalizes the number of practice trials (P), stimulus duration (T), and response window (W) into a three-dimensional experimental design space Ω, employs drift diffusion model (DDM) parameters (drift rate v, boundary separation a, non-decision time t, starting point z) as latent mediators, and develops a hybrid generative model combining a theoretical Sigmoid prior with Gaussian process (GP) residual learning, validated through empirical data, methodological checks, an external database, and mechanistic simulations.

Study 1 examined how the design space modulates SPE in data from 88 participants across eight designs collected by the laboratory. Behaviorally, SPE in RT differed across design cells, F(7, 80) = 2.79, p = .012, η² = .196, whereas SPE in ACC did not (p = .183). At the parameter level (six high-quality conditions), SPE in drift rate differed significantly under the historical estimation configuration (F(5, 59) = 2.95, p = .019, BF₁₀ = 2.83–3.29), but that configuration suffered from inadequate convergence (ESS = 8.6 for one parameter in G3) and a p_outlier setting incompatible with censored omissions; with the corrected configuration (p_outlier = 0; 4 chains × 8,000 draws; ESS ≥ 9,400; R̂ ≤ 1.000) the difference was no longer significant (F(5, 59) = 1.72, p = .145, BF₁₀ = 1.03). Linear regressions of P, T, and W explained almost no variance (R² = .051, BF₁₀ = 0.73), motivating nonlinear mapping.

Study 2 evaluated how omission handling affects DDM parameter estimation (16 hierarchical Bayesian fits across 8 designs × 2 schemes) and added a parameter-recovery test on synthetic data with known ground truth. The treatment of omissions mainly shifted the absolute level of drift rate: where omission rates exceeded ~35% (G1–G4), the two schemes differed beyond 95% credible-interval overlap (Δ = 6.81 for v_self in G1), while the relative SPE direction remained stable; below ~15% omission (G5–G8) the schemes converged. Parameter recovery on synthetic data showed {to be filled}, and the omission-rate–bias curve provides simulation support for the empirical ~15%/~35% benchmarks. A proof-of-concept omission probability network (OPN) was trained for this paradigm (test R² = .986).

Study 3 calibrated and validated the Sigmoid+GP hybrid model on the six primary conditions and added model comparison, model recovery, and posterior predictive checks. Differential-evolution calibration under the corrected configuration yielded α₁ = 0.153 (a self-advantage gain in drift rate of only about +15%) and β₁ = −0.631 (a lower boundary under generous time budgets, opposite to the time-pressure hypothesis), with RMSE = 0.704, indicating that the Sigmoid assumption needs revision. Model comparison showed that a linear model performed an order of magnitude worse (aggregate RMSE = 8.535 vs. 1.135 for pure Sigmoid, 1.232 for Sigmoid+GP, and 1.269 for a mean baseline), establishing the necessity of nonlinear mapping; however, with only six design points the GP residual layer did not improve cross-design prediction (its value lies in uncertainty quantification and candidate-point identification). Leave-one-condition-out validation failed at the parameter level (r = −0.03 for v_self), and model recovery revealed insufficient design power for model discrimination. Posterior predictive checks showed consistency in cross-condition trends but systematic misfit at the level of behavioral distributions (95% predictive-interval coverage of only .17–.33; e.g., observed omission rate .056 vs. predicted .008 in the long-deadline condition). This indicates misspecification of the constant-boundary DDM for deadline-based SMT and points to across-trial variability, attentional lapses, collapsing boundaries (ANGLE/WEIBULL), and explicit omission likelihood modeling (LAN+OPN). Accordingly, the model is positioned as a design-space trend model rather than a trial-level behavioral replicator.

Study 4 confronted these findings with broader evidence: using the accessible subset of the lab's SPE database {to be filled}, it examined cross-study SPE distributions and their relations to stimulus duration and trial counts, and used conditional response function (CRF) analyses plus Stim-Coding simulations to link starting-point bias to behavioral patterns, with a feasibility analysis of reverse inference from empirical CRFs to DDM parameters. Inconsistencies between database-level and internal design-variable relationships are discussed explicitly.

In sum, this thesis constructs a complete mapping framework from experimental design parameters through DDM parameters to behavioral outcomes, characterizes how the design space modulates SPE and its boundary conditions, and—through parameter recovery, model comparison/recovery, and posterior predictive checks—delimits the framework's scope: the theoretical mapping is indispensable, design-space extrapolation requires more design points, and trial-level behavioral replication requires richer model forms.

Keywords: self-prioritization effect; self-matching task; experimental design space; drift diffusion model; Gaussian process; omission; parameter recovery

# 第1章 引言

## 1.1 研究背景与动机

自我相关信息（姓名、面孔、与自我联结的几何图形等）在知觉与注意加工中享有优先地位。Sui、He 和 Humphreys（2012）提出的自我匹配任务（self-matching task, SMT）通过"图形—标签联结学习 + 匹配判断"将"自我相关性"操作化，并稳定地观察到自我优势效应（self-prioritization effect, SPE）：与陌生人相关刺激相比，自我相关刺激获得更快、更准的反应（Sui & Humphreys, 2015）。

然而，SMT 看似简单，其实验结构却存在巨大的自由度：联结学习的练习次数 P、刺激呈现时间 T、反应窗口 W 等参数在不同研究中取值各异。已有综述与数据库编码工作表明，既有研究在这些维度上的采样存在系统性偏差，大量参数区域未经探索（温佳慧, 2025）。更一般地，认知建模传统上把实验设计当作需要"控制"的背景条件，而非理论结构的一部分，导致模型预测的适用边界常常难以界定（刘逸康, 胡传鹏, 2023）。本研究延续课题组"实验设计—认知过程—数据结果"的研究纲领，将 SMT 的实验设计形式化为三维空间 Ω = (P, T, W)，系统考察该空间如何通过潜在决策过程调节 SPE，并据此优化实验设计。

## 1.2 研究思路与目标

本研究以漂移扩散模型（drift diffusion model, DDM; Ratcliff, 1978; Ratcliff & McKoon, 2008）参数化 SMT 中的决策过程，提出并检验四条理论假设：练习次数提升证据积累速率 v（P→v）；刺激呈现时间影响信息质量进而影响 v（T→v）；总可用时间 M = T + W 通过时间压力调节决策边界 a（M→a）；上述映射具有 S 型（Sigmoid）形式。在此基础上构建"Sigmoid 理论先验 + 高斯过程（Gaussian process, GP）残差"的混合生成模型，对任意 (P, T, W) 预测 DDM 参数，并在行为层面重建被试的 RT、ACC 与遗漏模式。

需要在一开始就明确模型的承诺边界：本研究对漂移率 v 与边界 a 建立了理论映射；对非决策时间 t 与起始点 z，模型仅采用基线加残差的柔性处理，未建立理论映射。因此本文的"参数预测"应理解为"对 v 与 a 的理论映射 + 对 t 与 z 的经验插值"。

本研究的总问题是：实验设计参数 (P, T, W) 如何通过改变潜在决策过程（DDM 参数 v, a, t, z），进而影响 SPE 的行为表现（RT、ACC、omission）与稳定性？具体研究问题及其对应章节如表 1-1。

# 第2章 文献综述（一）：自我优势效应与证据积累模型

## 2.1 Self-Matching Task 与自我优势效应

### 2.1.1 SMT 范式与 SPE 的测量

SMT 由 Sui、He 和 Humphreys（2012）提出。典型流程分两阶段：(1) 联结学习——将几何图形与身份标签（自我/陌生人/他人等）配对；(2) 匹配判断——呈现图形与标签组合，被试判断是否匹配。SPE 通常以匹配试次中自我条件与对照条件（如陌生人）的 RT/ACC 之差衡量：自我条件反应更快（RT 差为负）且更准。

### 2.1.2 SPE 的行为特征与影响因素

自 2012 年以来，SMT 已被广泛用于健康人群与临床样本，SPE 的稳健性得到大量重复（Sui & Humphreys, 2015）。已有综述性分析显示 SPE 的效应量在跨研究间存在变异，这一变异既可能反映被试群体差异，也可能反映实验设计参数差异——这正是本研究把 (P, T, W) 作为核心自变量并系统扫描设计空间的动机。

## 2.2 漂移扩散模型（DDM）

### 2.2.1 基本理论与参数含义

DDM 将二择一决策建模为有噪声的证据累积过程，直至累积量触及上/下边界之一而做出反应（Ratcliff, 1978；Ratcliff & McKoon, 2008）。其核心参数：漂移率 v（证据累积速率，反映刺激质量与任务难度）、边界分离 a（反应谨慎度，反映速度—准确性权衡）、起始点 z（先验偏向）、非决策时间 t（t0/Ter，反映刺激编码与运动执行）。在包含正确/错误两类反应的数据上，DDM 可同时解释 RT 分布与正确率。

### 2.2.2 参数的层级贝叶斯估计（HDDM）

个体水平参数估计噪声大、样本量需求高；层级贝叶斯框架将个体参数视为群体分布的抽取，可有效利用"个体—群体"双重信息（Wiecki et al., 2013）。本项目采用 Docker 化 HDDM 对 8 组实验数据进行层级拟合，参数以群体后验与个体后验形式输出，为跨条件比较提供统计基础。

### 2.2.3 参数的经验取值范围与可辨识性

DDM 参数并非无约束：Tran、van Maanen、Heathcote 和 Matzke（2021）对 158 篇文献的系统综述给出了各参数的典型取值与推荐先验；Matzke 和 Wagenmakers（2009）讨论了 ex-Gaussian 与扩散类模型的参数可解释性。这些经验范围在本研究中用于参数合理性诊断与 Sigmoid 校准的边界设定。需要强调的是，参数可辨识性依赖于实验设计：当设计点稀疏且高度共线时，v、a、z 之间的补偿效应会使个别参数无法可靠估计，本研究第 5 章将直接呈现这一现象。

## 2.3 DDM 中的 deadline 与 omission 问题（移至第3章）

# 第3章 文献综述（二）：遗漏反应建模、高斯过程与实验设计优化

## 3.1 含截止时间的决策任务与遗漏反应

含反应截止（deadline）的实验中，部分试次无反应（omission），常见处理是直接删除（drop）或把 RT 设为截止时刻并以错误反应编码（censoring）。Leng、Fengler、Shenhav 和 Frank（2026）用似然近似网络（likelihood approximation network, LAN）与新增的省略概率网络（omission probability network, OPN）证明：直接删除 omission 会系统性高估 v、低估 a，即使遗漏率处于中等水平；将 omission 作为观测联合建模可显著改善参数恢复，且该收益独立于 lapse（注意脱失）建模。该工作为本研究第二个研究问题提供了直接的理论出发点。

（写作提示：本节后续版本需补充该文的模型形式细节，以及"严格截尾似然"与本文近似处理之间的差异说明。）

## 3.2 高斯过程与实验设计优化

高斯过程回归是一种灵活的贝叶斯非参数方法，可对任意函数给出后验均值与不确定性（Schulz et al., 2018）。在认知建模与实验设计领域，基于模型不确定性的主动学习/自适应设计优化（Myung et al., 2013）主张：下一轮实验应选取当前模型"最不确定"的设计点，以最大化信息增益。本研究的建模策略与之一致：Sigmoid 提供可解释的理论均值函数，GP 捕捉其残差并量化预测不确定性，最后以不确定性引导候选设计点推荐。需要指出的是，GP 的泛化能力受设计点数量约束；本研究第 7 章将通过留一条件交叉验证与模型比较直接检验这一点。

## 3.3 SPE 数据库与大规模证据整合

SPE 数据库（Cai et al., in prep）由本课题组牵头建设，仿照 Confidence Database 的共享模式，收集 SMT 范式下已发表研究的试次级数据与元数据，当前全库自述规模为 44 篇文献、70 个数据集、3,603 名被试。本文实际使用本地可获得的子集，并在第 8 章报告去重与清洗后的精确样本量，不以全库自述数字代替实际分析规模。

## 3.4 CRF 与机制层面的决策研究

条件反应函数（conditional response function, CRF）刻画反应正确性随反应时间分位的变化，可在不拟合完整模型的情况下概览决策动态。结合 DDM 仿真（如通过起始点 z 的操作模拟偏向）可建立"参数→CRF 形态"的正向生成链，为机制解释提供中间层证据。由实测 CRF 反推 DDM 参数的逆向推断在理论上可行，但面临参数补偿（如 v 与 a、v 与 z）导致的可辨识性限制。

## 3.5 文献小结与研究空白

综上，现有文献存在三方面缺口：第一，缺少把 (P, T, W) 同时建模为 v、a 函数并对映射形式做经验校准的系统工作；第二，omission 处理缺少在真实数据上、且有仿真真值对照的定量评估；第三，模型导向的 SPE 研究大多缺少完整的验证链（参数恢复、模型比较/恢复、后验预测检验），因而难以界定模型适用边界。本研究以第 5–8 章四项研究逐一回应上述缺口。

# 第4章 研究框架与总体方法

## 4.1 实验设计空间与理论假设

本研究将 SMT 的三个可操控实验参数形式化为设计空间 Ω = (P, T, W)。物理世界与任务结构共同约束了参数取值：刺激呈现需高于知觉阈值（T ≳ 30 ms），反应窗口需大于最短反应所需时间（W ≥ 300 ms），练习次数需在可行实验时长内（本数据集 P ∈ {0, 8, 120}）。

四条理论假设：假设一（P → v）：练习通过提升刺激—标签联结的熟悉度提高 v，以 v_P(P) 的 S 型函数刻画（少量练习近乎无效、P ≈ 8–32 快速学习、P > 60 趋于饱和）。假设二（T → v）：T 主要影响知觉信息质量进而影响 v；将 T 映射至 v 而非 t 是一个有条件的建模选择，本研究允许 t 作为自由参数随条件变化，并报告其估计结果。假设三（M = T + W → a）：总可用时间 M 塑造时间压力进而调节 a；T 因此具有双重角色（既是信息质量来源，又是时间预算的组成部分），两条路径对 RT 的预测方向相反，构成模型内部的可检验约束。假设四：上述映射均采用 Sigmoid 形式，反映阈值—增长—饱和的心理物理模式（Luce, 1986）。

## 4.3 建模总体思路

本研究采用"Sigmoid 理论先验 + GP 残差"的混合策略：Sigmoid 函数族依据心理物理规律将 (P, T, W, M) 映射到 v、a，提供可解释的理论骨架；高斯过程学习"真实 DDM 参数 − Sigmoid 预测"的系统残差，提供数据驱动的柔性修正与预测不确定性。该策略的关键在于：即使设计点稀疏（GP 外推受限），Sigmoid 理论先验仍能保障行为层面的趋势重建；同时 GP 的不确定性可用于识别信息量最大的下一轮实验点。第 7 章将说明这一策略的两条边界：其一，GP 层在仅 6 个设计点时未提升跨设计点预测精度；其二，行为分布层面的复现需要比恒定边界 DDM 更丰富的模型形式。

# 第5章 研究一：实验设计空间对自我优势效应的系统性调控

## 5.1 研究问题与预期

• RQ0a：八个设计单元（G1–G8）之间，行为层 SPE（SPE_RT、SPE_ACC）是否存在差异？

• RQ0b：P/T/W 的线性连续模型能否解释 SPE 的变异？（预期：不能——为非线性建模提供依据）

• RQ0c：主口径（G3–G8）下，DDM 漂移率层面的 SPE（SPE_v）是否随设计单元变化？其稳健性如何？

## 5.2 方法

### 5.2.1 被试与实验设计

88 名健康成年被试（每组 10–12 人，总计 8 组）完成 SMT。刺激为几何图形（方/圆）与身份标签（自我/陌生人），试次分匹配（Matching）与不匹配（NonMatching），反应有截止时限。8 组条件构成本研究的设计空间，各组人数、遗漏率与质量分档见表 4-1。P = 0 的条件无练习试次，P > 0 的条件包含相应数量的练习试次；正式试次每人 520 个（260 Matching + 260 NonMatching）。

### 5.2.2 变量定义

行为指标（正式试次、Matching 试次）：SPE_RT_ms = 正确试次下自我条件平均 RT − 陌生人条件平均 RT（个体水平）；SPE_ACC = 自我条件平均正确率 − 陌生人条件平均正确率，其中 omission 计为错误。参数指标：HDDM 层级拟合后取被试级 SPE_v = v_self − v_stranger（个体后验均值）。

### 5.2.3 分析计划

单因素方差分析（ANOVA）＋η²；JZS 贝叶斯因子（组别哑变量回归形式，先验尺度 r = 0.5 与 1.0；实现与验证见 Rouder et al., 2009, 2012）；G*Power 敏感性分析（80% 功效下可检测的最小效应 f）；多元线性回归 SPE_v ~ P + T + W 及其 JZS BF。需要说明的是，由于设计点高度共线（P 仅三个水平且与 T/W 混杂），线性回归的系数不应作独立效应解释，本文仅将其作为"线性可加模型是否充分"的检验。

## 5.3 结果

### 5.3.1 行为层面：SPE_RT 与 SPE_ACC

### 5.3.3 线性模型的检验

以 P、T、W 为连续预测变量的线性回归对 SPE_v 几乎无解释力（R² = .051, BF₁₀ = 0.73，指向零假设），且系数方向不稳定（该结果已按冻结口径校正 G7 坐标）。该负结果与组间差异显著形成对照，说明 (P, T, W) 对 SPE 的作用并非线性可加。第 7 章的模型比较将以预测误差的形式再次确认这一结论。

## 5.4 讨论

第一，设计空间对 SPE 存在系统调控，且作用是非线性的：行为层 SPE_RT 显著、SPE_ACC 不显著，参数层 SPE_v 显著但证据边际。第二，效应存在但证据强度有限（BF₁₀ ≈ 3、G*Power 安全边际极窄），可解释为中等组间效应被大幅个体差异稀释（组内标准差远大于组间差异）。第三，SPE 主要出现在"足够知觉时间 + 宽松反应窗口"的设计区；极短窗口导致反应僵化甚至方向反转。第四，稳健子集（G5–G8）不显著有两种解读——效应依赖较宽参数范围，或子集功效不足；本文倾向后者并据实报告，同时将其作为"增加样本量"的直接理由。

# 第6章 研究二：Omission 处理方法对 DDM 参数估计的影响

## 6.1 研究问题

RQ1a：在真实 SMT 数据上，Censor 与 Drop 两种 omission 处理方案得到的 DDM 参数是否存在系统性差异？差异量级如何随遗漏率变化？

RQ1b：是否存在可接受的遗漏率边界？

RQ1c：能否用仿真数据（已知真值）检验参数估计流程本身的可靠性（参数恢复）？

RQ1d（初步）：自研省略概率网络（OPN）能否近似"参数→omission 概率"映射？

## 6.2 方法

### 6.2.1 Censor 与 Drop 的系统对比

对 8 组数据实施两种处理方案，共 16 次独立的 HDDM 层级拟合（Docker hcp4715/hddm；MCMC 3,000 draws、500 burn-in）：Censor 方案将 omission 试次的 RT 设为 deadline（T + W）、反应编码为 0，作为观测参与拟合（p_outlier = 0）；Drop 方案直接删除 omission 试次（p_outlier = 0.05）。比较指标为各参数（v_self、v_stranger、SPE_v、a、t、z）两种方案的差异 Δ、95% 可信区间是否重叠，以及 Cohen's d。

术语说明：本实现中的"Censor"准确含义是"把 omission 编码为截止时刻的错误反应参与拟合"，并非严格的右截尾似然；严格截尾建模（LAN+OPN 路线）列为未来方向。

### 6.2.2 参数恢复设计

以主口径六个条件（G3–G8）的 HDDM 群体后验均值作为参考真值，使用与研究完全一致的 Euler–Maruyama 仿真器（dt = 2 ms、deadline = T + W、未在截止前触界者记为 omission）生成合成数据：每个条件的被试人数取该条件实际人数，每名被试含 130 个自我试次与 130 个陌生人试次。随后对合成数据分别施加 Censor 与 Drop 两条流程并重新拟合（每条件重复 3 次）。恢复质量以偏差、RMSE、95% 可信区间对真值的覆盖率与跨条件相关衡量。

为刻画遗漏率的影响，另以六条件参数的均值为真值，通过二分搜索设定 deadline，使合成数据的遗漏率达到 5%、10%、15%、20%、25%、35%、50%、70% 八个水平（每水平重复 2 次、两种方案各拟合一次），得到"遗漏率–偏倚"曲线。

### 6.2.3 自研 OPN（第一版）

仿真器为带 deadline 的 DDM 试次生成器（Euler–Maruyama，批量版 simulate_ddm_batch_vectorized）。训练数据在参数空间与 deadline 网格上采样 4,699 组 (v, a, t, z, deadline)，以仿真得到的 omission 比例作为标签；网络为 MLP（128-64-32，sklearn），输出 omission 概率，输入特征做标准化。本版为快速模式的小样本概念验证；正式路线为复用 Leng et al.（2026）的官方 ddm_opn.onnx 并接入 HSSM。

## 6.4 讨论与展望

第一，Leng et al.（2026）的偏倚机制在真实数据上得到印证：丢弃 omission 对漂移率的绝对水平影响强烈，且影响随遗漏率增大而加剧；但自我优势的相对方向（SPE_v）在两种方案下保持稳定，说明"遗漏处理"主要威胁参数绝对水平的解释，而条件间比较相对稳健。

第二，数据清洗决策（排除 G1/G2、G3/G4 谨慎解释、G5–G8 为核心）由此获得实证依据，支撑全文的主口径。

第三，自研 OPN 仅为概念验证，正式路线是复用官方 ddm_opn.onnx 接入 HSSM 完成端到端联合似然估计；考虑到工具成熟度与条件数限制，本文将其列为未来方向（只用 ddm_opn；angle_opn 存在 θ 梯度冲突问题）。

# 第7章 研究三：Sigmoid + 高斯过程的混合生成模型

## 7.1 研究问题与定位

RQ2：在六条件（G3–G8）上，(a) Sigmoid 理论映射能否经差分进化校准拟合真实 HDDM 参数？(b) 校准后的混合模型能否在行为层重建被试的 RT/ACC/omission/SPE？(c) GP 预测不确定性能否提供下一轮实验的候选点？

定位声明（据实际结果修订）：本文对 v 与 a 建立理论映射，对 t 与 z 采用基线加残差。行为层验证采用严格的后验预测检验，而非仅报告聚合相关；参数层外推（LOCV）受限于 6 个设计点，其结果作为"需更多设计点"的结构性证据；候选点仅为探索性输出。

## 7.2 方法

### 7.2.1 建模输入

主口径六条件（G3–G8）的 HDDM 群体后验均值（v_self、v_stranger、a、t、z）；每个条件对应 10–12 名被试、每身份约 1,300–1,560 个 Matching 试次。

### 7.2.2 Sigmoid 参数化

v(T, P, condition) = v_T(T) × v_P(P) × base_scale_v × (1 + 条件调制 α₁/α₂)，其中 v_T、v_P 均为 Sigmoid（拐点与陡度取心理物理固定值，T₀ = 100 ms 等）；a(M) = Sigmoid(M; M₀ = 600) × base_scale_a × (1 + 边界调制 β₁/β₂)，M = T + W；t 与 z 在 Sigmoid 层取训练条件均值基线（t₀ = 0.420, z₀ = 0.550），由 GP 学习其残差。差分进化联合优化 7 个自由参数（α₁、α₂、β₁、β₂、γ、base_scale_v、base_scale_a），目标为预测与真实参数的 RMSE。

### 7.2.3 GP 残差层

对 v_self、v_stranger、a、t、z 各训练一个独立 GP（核：ConstantKernel × RBF + WhiteKernel），学习目标为"真实 HDDM 参数 − Sigmoid 预测"；最终预测 = Sigmoid + GP 残差。

### 7.2.4 验证策略

① in-sample 拟合指标；② 留一条件交叉验证（LOCV，6 折）；③ 模型比较：在同一预测任务上比较四个候选模型（均值基线、线性回归、纯 Sigmoid、Sigmoid+GP），以 LOCV 的聚合 RMSE 为指标，四个模型的差分进化预算一致；④ 模型恢复：对每个生成模型用其预测值加噪声生成合成真值表，完整执行一次四模型 LOCV 比较并记录胜出模型，得到混淆矩阵（需说明：本恢复在设计—参数映射层面进行，检验的是六个设计点能否区分四种映射形式）；⑤ 后验预测检验（PPC）：从各条件的 HDDM 迹线中联合抽样被试水平参数 200 次，按真实被试数、每身份 130 试次与真实 deadline 重新仿真，以与真实数据完全相同的方式计算统计量（acc_all、acc_responded、遗漏率、正确 RT 均值与分位数、SPE_RT、SPE_ACC），报告 95% 预测区间覆盖率与尾概率；⑥ 候选设计点：25×25×25 网格上的 GP 预测不确定性 top-N，剔除邻近已有设计点的区域。

## 7.3 结果

### 7.3.1 Sigmoid 校准

修正配置（配置 C，见 §6.3.4）下的最优参数为：α₁ = 0.153、α₂ = −0.335、β₁ = −0.631、β₂ = −0.245、γ = 0.939、base_scale_v = 1.112、base_scale_a = 4.086；拟合 RMSE = 0.704，差分进化收敛。与历史单链配置（α₁ = 0.862、β₁ = +0.328、RMSE = 1.090）相比，拟合优度显著改善（RMSE 下降 35%），但参数含义发生实质变化。

据此更新解读：① α₁ = 0.153 意味着自我条件的漂移率增益仅约 +15%（远低于初始假设的 +150%，也低于历史配置给出的 +86%）；② β₁ 为负（−0.631），即高总可用时间条件下边界反而更低，方向与"时间压力—决策边界"假设相反；这一"符号反转"在早期 8 条件版本中曾被观察到，后被判定为低质量数据伪影，但在收敛良好的修正配置下再次出现，因此应被视为该数据对该假设的真实偏离，而非伪影；③ base_scale_a = 4.086 不再触界。以上变化说明：当参数估计本身更可靠时，Sigmoid 理论映射与数据的偏离更为清晰，理论假设需要修正而非归因于数据质量问题。

## 7.4 讨论

第一，理论校准价值：排除低质量组后，映射方向与假设一致（练习提升 v；时间压力降低 a），但幅度低于默认先验——Sigmoid 参数化因此可被视为"可检验的理论仪器"，本研究给出其经验取值。

第二，模型比较的结论要求重新表述混合模型的贡献：Sigmoid 理论先验是不可或缺的（把预测误差从线性模型的 8.5 降到 1.1），而 GP 残差层在当前数据下的价值在于预测不确定性的量化与候选点识别，而非预测精度。

第三，后验预测检验的失败（覆盖率 .17–.33）提示模型误配，指向跨试次变异、lapse 与塌缩边界（ANGLE/WEIBULL）以及 omission 的显式似然建模。这一结果并不否定研究一至研究三的核心发现，但限定了其适用范围：模型适用于条件间比较与设计空间趋势预测，尚不足以宣称能逐条件复现行为分布。

第四，局限与改进：6 个设计点（LOCV 失败）、恒定边界 DDM、行为验证为基于后验的绝对检验但受模型形式限制；改进路径为更多设计点（尤其 P 的中间水平）与更丰富的模型形式。

# 第8章 研究四：SPE 数据库、CRF 与机制仿真的多源验证

## 8.1 研究目的

研究一至研究三的证据均来自课题组 88 人数据集。为考察"设计空间调控 SPE 及其参数化机制"这一结论的外部效度，本章将行为/参数层面的发现与更大范围的独立证据对照：一是课题组构建的 SPE 数据库，二是条件反应函数（CRF）分析与 Stim-Coding 机制仿真。

透明声明：SPE 数据库为课题组在研基础设施，全库自述规模为 44 篇文献、70 个数据集、3,603 名被试；本章报告实际使用的子集规模（⏳【待填】数据集数、被试数、去重后试次数），并说明清洗规则。数据库的构建与标准化详见 Cai et al.（in prep）及课题组文档。

## 8.2 方法

SPE 数据库分析。对纳入数据集统一提取匹配试次的 RT 与 ACC，按身份（自我 vs 陌生人）计算 SPE；在数据集层面考察 SPE 的整体分布，并探索 SPE 与刺激呈现时间、试次数等设计变量的关系（相关与自举置信区间）。

CRF 与滑动窗口分析。基于内部 88 人匹配试次（22,880 试次），计算条件反应函数（按 RT 分位考察正确率）以及"以匹配键为条件的自我—陌生人正确率差"随反应时间窗口的变化（窗口 100–400 ms 滑动）。

Stim-Coding 机制仿真。以起始点 z 模拟自我—陌生人偏向（neutral 0.50 / small 0.55 / medium 0.60 / large 0.65），分别用 Euler–Maruyama 数值积分与 HDDM 生成器两套引擎，每条件 30 被试 × 150 试次（共 18,000 × 2 试次）生成仿真数据并计算 CRF；另按真实 RT 分布校准仿真参数。

逆向推断可行性。采用"最小化仿真 CRF 与实测 CRF 差异"的思路考察由实测 CRF 反推 DDM 参数 (v, a, t, z) 的可行性，并分析参数补偿（v–z、a–v）对可辨识性的影响。

## 8.3 结果

CRF 与窗口分析。内部数据的滑动窗口分析显示，自我—陌生人的匹配键正确率差在约 234–780 ms 的反应时间窗口内显著为正，峰值出现在约 434–459 ms（Δ ≈ 0.18–0.21）。需要强调：该发现基于内部 88 人数据，不得表述为"大规模跨研究发现"。

## 8.4 讨论

第一，SPE 的跨研究存在性得到数据库层面的支持，但效应量受设计参数与任务结构共同调制——这与研究一/研究三的核心论断一致：SPE 不是固定不变的常数，而是设计空间的函数。

第二，呈现时间等变量与 SPE 的关系在不同口径下方向存在差异（内部数据 vs 数据库元回归），提示任务结构异质性必须被显式建模；同时说明本文的外部验证是"受限的"，不能过度宣称。

第三，CRF/Stim-Coding 为"偏向机制→行为模式"提供了生成式证据，但逆向推断的补偿效应要求以模型比较与先验约束（而非单纯反推）作为最终解释手段。

# 第9章 总讨论

## 9.1 核心发现回顾

第一，设计空间对 SPE 的调控在行为层面稳健：SPE_RT 在 8 个设计单元间差异显著（F(7, 80) = 2.79, p = .012）而 SPE_ACC 不显著；P/T/W 的线性模型几乎无解释力（R² = .051），模型比较进一步显示线性模型的预测误差比均值基线高一个数量级。但参数层面的组间差异不稳健：在修正参数估计配置后，SPE_v 的组间差异不再显著（F(5, 59) = 1.72, p = .145, BF₁₀ = 1.03），早期显著结果（p = .019）主要来自收敛不足与 p_outlier 配置冲突。

第二，遗漏试次的处理方式是一阶的方法学问题。Censor 与 Drop 在遗漏率超过约 35% 的条件下给出显著不同的漂移率绝对估计（Δ 最大 6.81），仅在相对方向（SPE_v）上保持稳定；在遗漏率低于约 15% 时两者基本一致。

第三，Sigmoid+GP 混合模型具备"理论可校准、行为趋势可重建"的性质，但需限定其贡献：校准结果显示边界参数方向与时间压力假设一致（β₁ = +0.328），自我漂移率增益约 +86%；模型比较显示理论映射不可或缺（纯 Sigmoid 1.135 < 线性 8.535），但 GP 层未提升跨设计点预测；参数层 LOCV 失败；后验预测检验显示行为分布层面存在系统失配（覆盖率 .17–.33）。

第四，多源证据在"SPE 的方向性、条件依赖性"上总体一致，但外部数据库与内部数据在设计变量关系上的方向不一致，提示任务结构异质性的作用。

## 9.2 理论贡献

本研究将"自我优势是自动的、固定的加工优势"这一常见直觉，修正为"自我优势的表现形式与强度是实验设计参数的函数"，并给出其在设计空间中的量化边界；通过经验校准，把"练习提升漂移率""时间压力降低决策边界"等经典假设落到 SMT 范式的具体参数取值上；同时诚实报告了校准结果与初始假设的偏离（自我增益约 +86% 而非 +150%）。

## 9.3 方法论贡献

第一，提出并检验了"Sigmoid 理论先验 + GP 残差"的混合生成框架，并界定了其贡献边界：理论先验承担主要预测功能，GP 承担不确定性量化功能。

第二，为 DDM 应用中的 omission 处理选择提供了基于真实数据与仿真真值的双重证据，并把"可接受遗漏率"从经验分档推进到偏倚曲线的量化刻画（⏳待参数恢复结果回填）。

第三，建立并执行了完整的验证链：参数恢复、模型比较、模型恢复、后验预测检验。其中后验预测检验揭示的模型误配，本身就是对"含截止时间任务需要更丰富模型形式"这一主张的实证支持。

第四，开发了完整、可复现的分析工具链（HDDM 拟合 → 参数提取 → Sigmoid 校准 → GP 建模 → LOCV → 模型比较/恢复 → 后验预测检验 → 候选点推荐），并整理为脚本化产物与数字锁定表。

## 9.4 局限与未来方向

第一，设计点稀疏：主口径仅 6 个设计条件，P 只有三个水平，制约了 GP 外推与参数辨识；未来应在高不确定区域（如 T ≈ 500 ms、W ≈ 300–350 ms，含中间 P 水平）补充设计点，并以独立实验验证模型预测。扩充每个条件的被试量（如补至每条件 ≥20 人）可提升条件内估计精度与检验功效，并使"留出被试验证"成为可能；但需注意：改善的是条件内精度，而非设计空间外推。

第二，模型形式：当前采用恒定边界 DDM，未纳入跨试次变异与塌缩边界（ANGLE/WEIBULL）；后验预测检验的结果明确指向这一扩展方向。遗漏试次的严格截尾似然建模（HSSM + 官方 ddm_opn 的 LAN+OPN 路线）可替代当前"截止处错误反应"的近似处理。

第三，数据归属：88 人数据为课题组前期采集，作者的独立贡献集中于全部建模、分析与验证（见第 4.2 节声明）；未来工作的数据采集可作为独立贡献补充。

第四，外部验证的深度：SPE 数据库分析目前依赖课题组自建库的可用子集，不同任务口径间的可比性有限；更严格的外部验证应在统一的任务结构与参数报告标准下开展。

第五，NonMatching 试次：本文仅建模匹配试次，不匹配试次的决策机制可提供额外约束，留待后续研究。

# 第10章 结论

本研究以自我匹配任务中的自我优势效应为载体，将练习次数（P）、刺激呈现时间（T）与反应窗口（W）形式化为三维实验设计空间，并以漂移扩散模型参数为中介，系统回答了"实验设计参数如何通过潜在决策过程调控心理现象"这一核心问题。主要结论如下：

第一，设计空间对 SPE 存在系统且非线性的调控：行为与 DDM 参数层面的 SPE 差异主要来自长时限、低遗漏的设计单元，P/T/W 的线性模型无法解释该变异（模型比较中线性模型的预测误差比均值基线高一个数量级），须借助非线性、生成式的建模。

第二，遗漏试次的处理方法会实质影响 DDM 参数估计：绝对漂移率在 Censor 方案下被系统性低估、在 Drop 方案下被系统性高估（参数恢复：偏倚 −1.34 与 +0.73，95% CI 覆盖率 17% 与 0%），而「自我 vs 陌生人」的相对效应几乎完美恢复（SPE_v 覆盖率 100%，r = .97/.91）；遗漏率–偏倚曲线进一步显示绝对偏倚随遗漏率单调增大（>50% 时达 1.6–3.2），而相对方向在所有水平下保持稳定。

第三，Sigmoid+GP 混合生成模型的贡献需按修正配置重新界定：理论先验（Sigmoid）承担主要预测功能（纯 Sigmoid 的 LOCV 误差 1.135，线性模型 8.535），GP 残差层在 6 个设计点下未提升外推预测；在校正参数估计后，校准得到 α₁ = 0.153（自我增益约 +15%）与 β₁ = −0.631（方向与时间压力假设相反），拟合优度改善（RMSE 由 1.090 降至 0.704）但 v_self 与 SPE_v 的留一条件交叉验证仍不成立（r = −0.10、−0.36）；后验预测检验显示行为分布层面仍存在系统失配（95% 预测区间覆盖率 .00–.39）。

第四，多源证据（内部实验、跨研究数据库、机制仿真）在 SPE 的条件依赖性上总体一致，支持将 SPE 视为"设计空间函数"的研究视角；同时，本研究的验证链明确界定了该框架的适用边界——理论映射不可或缺，设计空间外推需要更多设计点，行为分布的复现需要更复杂的模型。
